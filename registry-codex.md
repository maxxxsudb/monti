## 1. Расширение монтихолла

| Заявление | Проверка | Статус |
|---|---|---|
| Скрытый приз до отбора: stay=1/N, switch=(N−1)/N | Верно для выбора до информированного сохранения единственной чужой двери; вероятности усреднены по раскрытию. Для конкретных названных дверей нужны правила разрешения ничьей. | ИЗВЕСТНО: Монти Холл |
| Приз генерируется равномерно между двумя оставшимися: 1/2 | Верно; это другое распределение приза, не следствие одного времени генерации. Можно заранее сгенерировать скрытый случайный бит и получить то же. | ВЕРНО; НЕ_МОНТИ как самостоятельный парадокс |
| Смесь p_switch=λ(N−1)/N+(1−λ)/2; Δ=λ(N−2)/N | Закон полной вероятности. При N=3 таблица λ=0,.25,.5,.75,1 даёт .5,.5416667,.5833333,.625,.6666667. | ВЕРНО; ИЗВЕСТНО: смесь Монти |
| λ=NΔ/(N−2) | Верно только при N>2 и заданных обоих механизмах. Без известного открытого распределения λ не идентифицируется по Δ. | ВЕРНО УСЛОВНО |
| p_stay=λ/N+(1−λ)φ; Δ=λ(N−2)/N+(1−λ)(1−2φ) | Верно, если φ описывает генерацию относительно первого выбора, одинаковую при обеих конечных стратегиях. Если действие после раскрытия меняет генератор, нужны разные φ_stay и φ_switch. | ВЕРНО УСЛОВНО |
| φ=1, N=3: λ_c=3/4, при пороге оба шанса 1/2 | p_stay=1−2λ/3, p_switch=2λ/3. Общий порог при φ>1/2: λ_c=(2φ−1)/(2φ−1+(N−2)/N). | ВЕРНО; известная смесь/компенсация |
| Исход фиксируется → вмешательство невозможно | Верно по определению фиксации относительно разрешённых действий. Время генерации само этого не гарантирует: уже лежащий приз можно переместить. | ТАВТОЛОГИЯ/НЕ_МОНТИ |
| Защита делает выживание слабее свидетельством качества | Нужны модель качества и различие likelihood; направление не универсально при иных priors и побочных эффектах защиты. | ИЗВЕСТНО: отбор/ошибка выжившего |
| История полезна при грубом описании настоящего | Корректно: разные условные распределения при недостаточной статистике. | ИЗВЕСТНО: условная вероятность/достаточность |
| Рекомендательная система смешивает предпочтения и собственное влияние | Возможная причинная обратная связь; численного парадокса и протокола фильтра нет. | НЕ_МОНТИ |

Метафизическое чтение «сила Монти измеряет существование будущего» текстом частично отозвано и экспериментально из этих формул не следует.

## 3. Сонет: проверка формального основания

| Заявление | Итог |
|---|---|
| Posterior K_i/ΣK, A/(A+B), критерий A/k=B/(N−k) | ВЕРНО при положительном знаменателе и 0<k<N. Это Байес и алгебра. |
| «Полная обменность достаточна» | ОШИБКА без точного определения и гарантии сохранения цели. Контрпример: N=3,k=m=1; оставить случайную чужую дверь независимо от τ. Механизм полностью симметричен, но P(τ∈Y|S)=1/3 и P(τ=j|S)=1/3, а не 2/3; исключённая цель возможна. Если требуется не исключать цель и эквивариантность относительно всех перестановок O, инвариант действительно следует. |
| Контрпример N=4,S={2,3} | ВЕРНО: совместимы только τ=1,2, равные priors → 1/2. Подмножества здесь именно survivors, не открытые двери. |
| p_j=(N−k)/(Nm), R=(N−k)/m | ВЕРНО при сохранении массы и одинаковых likelihood внутри наблюдаемых survivors; общее правило не следует из одного размера. |
| N=100,k=20,m=5: 16% против условных 16/17 | ВЕРНО при указанных предпосылках. |
| Цепочка BF и сложение log BF | ВЕРНО при последовательных условных likelihood и ненулевых знаменателях. |
| Сигмоида R/(1+R) | ВЕРНО для бинарного события при равных prior odds; общая формула posterior odds=prior odds·R. |
| q(N−2)+1 | ВЕРНО для протокола: знающий оставляет цель среди N−1 чужих, слепой оставляет одну равномерно, условие — все раскрытые пусты. Тогда K_y=1/(N−1), K_j=q+(1−q)/(N−1). Само словосочетание «частичная осведомлённость» протокол не задаёт. ИЗВЕСТНО: Monty Fall / смесь ведущих. |
| Γ(N−1)Γ(2−β)/Γ(N−β) | ВЕРНО как вероятность, что выбранная плохая клетка с Exp(1−β) доживёт дольше N−2 других плохих клеток Exp(1), при одной неуничтожимой хорошей. Интеграл a∫e^(−at)(1−e^(−t))^(N−2)dt=aB(a,N−1), a=1−β. Без описания неуничтожимой цели и остановки при двух оставшихся формула неоднозначна. |
| ∂J/∂u | ВЕРНО после деления приведённого числителя на p(1−p), если p_F не зависит от u. |
| Максимум F там, где d lnκ/dt=h | ОШИБКА как заявление о F=∂J/∂u: пропущен меняющийся множитель 1/[p(1−p)]. Это условие стационарности сырой чувствительности ∂p/∂u=(1−λ)κ, не логарифмической; также не гарантирует максимум. |
| W=ΔJ=ln BF есть причинная работа | ОШИБКА. Датчик наблюдает заранее зафиксированный бит: odds изменились, ни одно вмешательство не совершено. Численное ΔJ=ln BF — информационное обновление при одинаковых priors, не причинный закон. |
| Posterior p_t — мартингал | ВЕРНО для одного фиксированного события и растущей информации: p_t=E[1_H|F_t]. |
| Заголовок «мартингальная природа I» и I — накопленная вариация | ОШИБКА. log BF не posterior и обычно не мартингал; имеет дрейф, зависящий от истинной гипотезы. Вариация — ещё другая величина. |
| λ=1 — момент остановки posterior-мартингала | ОШИБКА. Приз уже лежит за дверью (λ=1), но последующее чтение точного местоположения переводит posterior 1/3 в 0 или 1. Генерация исхода не обязана быть stopping time наблюдателя; остановка выбранного процесса не запрещает получать новую информацию. |
| Уверенность/дисперсия только накапливается | ОШИБКА потраекторно: противоречащее свидетельство уменьшает уверенность. В среднем posterior variance фиксированного события уменьшается в ожидании, но posterior-p как случайная переменная может расширять распределение. |
| λ=1⇒F=0 | ВЕРНО как определение полностью фиксированной части, если λ=1 остаётся при рассматриваемых изменениях u. Это не эмпирическая теорема. |
| I_A=I_B не ⇒ F_A=F_B | ВЕРНО как отсутствие необходимой связи; мартингальный аргумент в тексте неверен, новизна не следует. |
| dP/dI=ln2·P(1−P) | ВЕРНО для бинарных log odds. Фраза «каждый следующий бит даёт меньший сдвиг» ОШИБОЧНА при P<1/2: приближение к 1/2 сначала повышает чувствительность. Максимум производной действительно при 1/2. |
| I(B:A)=−I(A:B) | ВЕРНО для одного evidence и одной пары моделей. Различие posterior предпочтений возможно также из-за разных priors, даже при одинаковом знаке BF. |
| F падает, I растёт «по умолчанию» | Не теорема; ни монотонность I, ни убывание чувствительности без динамики не доказаны. |

Источники первичного уровня: [Gill, 2010](https://arxiv.org/abs/1002.0651), [Berkeley: Monty Hall](https://www.stat.berkeley.edu/pub/users/stark/SticiGui/Text/montyHall.htm), [Fong et al.: Martingale posterior distributions](https://academic.oup.com/jrsssb/article/85/5/1357/7597700). Последний источник подтверждает связь posterior с растущей информацией, не отождествление фиксации исхода с остановкой наблюдения.

## 4. Сильнейший кандидат из проверенного материала

### K-P1-01. Поздний приз отменяет совет Монти
Условие (3 предложения): Есть три двери, и вы выбираете первую. С вероятностью 3/4 приз уже случайно размещён, а с вероятностью 1/4 его поставят за первоначально выбранную дверь после подсказки. Знающий ведущий открывает пустую чужую дверь и предлагает поменять выбор.

Вопрос: Какова вероятность выиграть, если поменять дверь?

Интуитивный ответ: 2/3. Верный ответ: **1/2**.

Механизм Монти: в первой ветви ведущий сохраняет чужую цель и открывает только пустую чужую дверь; во второй ветви обе чужие двери пусты и первое решение создаёт поздний приз.

Точный расчёт: P(switch)=3/4·2/3+1/4·0=1/2; P(stay)=3/4·1/3+1/4·1=1/2. Симуляция: `sims/r0_p1_temporal.py`, 10^6 испытаний: stay=0.500173, switch=0.499827.

Отличие от известных: раскрытие сочетается с зависимой от первого решения генерацией. **Но это не доказанная новизна: ответ полностью сводится к смеси классического Монти и детерминированного позднего размещения. По строгому чёрному списку кандидат следует отклонить как вариацию Монти / СЛАБО (подогнанная компенсация).** Не представляю его новым открытием; это самый короткий и сильный проверенный эффект в назначенных файлах.

Стартовый вывод П1: ни один готовый парадокс из этих трёх файлов пока не проходит критерий (e). Для раунда 1 нужно новое свойство самого взаимодействия фильтра и вмешательства, а не новая декорация, смесь режимов или переименование log BF.

## Ошибки теоретического основания

1. Концептуально.txt, начало: λ=1 не является автоматически stopping time наблюдательской фильтрации. Физическая фиксация скрытого результата и остановка наблюдений — разные события. Теорема об optional stopping этого не доказывает.
2. I=log2R не равно дисперсии/квадратичной вариации мартингала: I бывает отрицательным, quadratic variation неотрицательна. Условная дисперсия скрытого индикатора p(1-p) в среднем убывает, дисперсия самих posterior в среднем растёт; смешивать их нельзя. Астрон фраза о стремлении дисперсии к нулю требует полного раскрытия события и уточнения, о какой дисперсии речь.
3. Вмешательство не обязано нарушать мартингальность: нулевое/компенсирующее вмешательство может её сохранить. Отсутствие дрейфа не доказывает отсутствие воздействия.
4. Критерий A/k=B/(N-k) — условие сохранения массы конкретной группы, не необходимое условие принадлежности к классу Монти. Асимметричный информированный ведущий по-прежнему Монти.
5. Концептуально §3 смеси должны использовать posterior веса режима; исходное λ достаточно только когда P(e|F)=P(e|O) либо речь о безусловном результате политики. астра2 исправляет это через w.
6. Концептуально §4.3 использует F=Sκ, хотя ранее F=∂logit(p)/∂u. Точная формула G=Sκ, F=G/[p(1-p)]; оптимумы разные. Астрон исправляет формулу, но стационарность сама по себе не доказывает максимум.
7. Универсальные Control↑⇒influence↑ и Control↑⇒diagnostic↓ не теоремы: журнал вмешательств может раскрывать качество, чрезмерное воздействие может вредить. астра2 §12 справедливо ограничивает тезис.

## Сильнейший кандидат — только как учебный, голос ПРОТИВ новизны

### K-П2-1. Преждевременная смена лидера
Условие (3 предложения): За четырьмя дверями одна машина; ведущий знает её место и равновероятно открывает козу, не трогая выбранную дверь. После первого открытия можно сменить выбор, и ведущий далее защищает новую выбранную дверь. После второго открытия вы обязательно переходите к другой закрытой двери.
Вопрос: Какова вероятность выигрыша, если сменить выбор уже после первого открытия?
Интуитивный ответ: 3/4 или больше, поскольку первая смена улучшает текущий шанс.
Верный ответ: 5/8.
Механизм Монти: ранняя смена переносит иммунитет на дверь с posterior 3/8; второй отбор концентрирует дополнение к нему, 5/8. При сохранении защиты первой двери дополнение равно 3/4.
Отличие от известных: отсутствует; это точно известный многоступенчатый Монти. Предложение в пул новизны запрещено.
Проверка: точный расчёт 1-3/8; sims/r0_p2.py, 10^6 игр.

## Источники проверки новизны

- [Harvard Math 191, 2004, Outline 3, p.6](https://people.math.harvard.edu/archive/191_fall_04/outlines/Conditional3.pdf): различимые козы; если есть выбор, показывать меньшую. Отображение меньшая коза↔золотая коза точное. Опровергает новизну Астрон §4.
- [Four-door Monty Hall, one by one, 2017](https://math.stackexchange.com/questions/2236219/four-door-monty-hall-problem-but-two-doors-are-opened-one-by-one): исходное обсуждение того же протокола и точное 5/8. Это свидетельство существования задачи, не замена собственного расчёта.
- [A new version of the Monty Hall Dilemma with unequal probabilities, 2000](https://www.sciencedirect.com/science/article/pii/S0376635799000662): первичная публикация неравных априоров, против заявления об общем новом механизме аутсайдера.

## Существенные ограничения и исправления

1. Для конкретной показанной двери политика ведущего важна даже при guaranteed-goat. Классический switch выигрыш 2/3 в среднем не гарантирует такой же posterior после каждого конкретного сообщения при фаворитизме по меткам. Это корректно признано в «Оптимизации».
2. Другая методика анализа сама по себе не делает Монти ложным. Существенно K(e|H), а не одинаковость названия/признака теста. И исход «в будущем» не исключает Монти: можно заранее случайно назначить будущий исход и информированно фильтровать по этому назначению.
3. λ в формулах смеси должен быть весом режимов после доступного наблюдения. Если наблюдение имеет разную вероятность в двух режимах, априорный λ надо обновить: λe=λP(e|F)/[λP(e|F)+(1−λ)P(e|O)]. По одним stay/switch нельзя вне жёсткой смеси восстановить универсальную «степень фиксации».
4. Если switch после N дверей означает выбрать один оставшийся, ведущий должен убрать N−2 дверей. Без этого (N−1)/N — масса всех невыбранных, не вероятность одного нового выбора.
5. Производная смеси корректна только при ∂pF/∂u=0. При смене состава фиксированной группы pF может зависеть от u; тогда нужен член λ∂pF/∂u. Требуется явная причинная модель вмешательства, меняющего λ.
6. Точная сила из «Некст»: F=Sκ/[p(1−p)] при b=0. Поэтому внутренний экстремум положительного F удовлетворяет κ'/κ=h+d ln[p(1−p)]/dt. Равенство κ'/κ=h оптимизирует Sκ=∂p/∂u, а F — только при постоянном знаменателе или допустимом приближении. Даже для Sκ стационарная точка не обязательно максимум, и крайние точки надо проверить.
7. Утверждение «одинаковый дополнительный бит сильнее всего меняет вероятность около 50/50» верно локально. Для целого положительного бита максимум Pпосле−Pдо достигается при oddsдо=1/√2, то есть Pдо=√2−1≈.4142, а не .5.
8. В «Оптимизации» исправление про мартингал верно: E[pслед|Fт]=pт не означает pслед=pт. Физически фиксированный исход допускает дальнейшее обновление знания. Там же верно исключено тождество observational log-BF и causal work.

# Раунд 0 — К2 (Codex)

## Независимая проверка центральных утверждений

1. Временная смесь: при заданных режимах stay = λ/N + (1−λ)φ, switch = λ(N−1)/N + (1−λ)(1−φ). Арифметика верна; N=3, φ=1 дают порог λ=3/4. Это закон полной вероятности, не доказательство новизны.
2. После конкретного сообщения E вес режима равен P(F|E), а не автоматически исходному λ=P(F). Если сообщение имеет разную вероятность в двух режимах, нужна байесовская перевзвеска.
3. ОШИБКА в достаточности «полной обменности» в тексте «монтихол от сонет»: N=3,k=m=1, ведущий оставляет один из двух чужих объектов случайно независимо от цели. Механизм обменен внутри групп, но масса своего объекта 1/3, каждого оставшегося также 1/3, а не 2/3. Недостаёт требования сохранять цель, если она в чужой группе. Равенство средних ядер само по себе задаёт только массу группы, не индивидуальное равенство survivors.
4. ОШИБКА: фиксация исхода не останавливает апостериорный мартингал. Монета брошена до наблюдений: p0=1/2; после раскрытия p1∈{0,1}. Исход уже фиксирован в обеих точках, posterior продолжает меняться. Теорема об остановке не отождествляет фиксацию с раскрытием.
5. ОШИБКА: I=log2 BF не мартингал и не мартингальная вариация. Мартингалом является условная вероятность фиксированного события относительно растущей информации.
6. ОШИБКА: W=ln R нельзя назвать причинной работой без дополнительной модели вмешательства. В классическом Монти R=2, но ведущий не меняет размещение приза; причинное изменение размещения нулевое.
7. ОШИБКА: «каждый следующий бит даёт меньший сдвиг» верно лишь после прохождения p=1/2 в выбранном направлении. До p=1/2 производная p(1−p) растёт. Сигмоида с I=log2 BF также требует равных исходных бинарных шансов; иначе log odds = log prior odds + I ln2.
