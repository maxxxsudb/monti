- [Характеризация target-invariant](research/COUNTERINTUITION-TARGET-INVARIANT-2026-10-19.md) — «только если»: цель не зависит от априора при всех априорах \(\iff\) условные распределения совпадают.
- [Доминирование вопросов](research/COUNTERINTUITION-QUESTION-DOMINANCE-2026-10-19.md) — уточнение разбиений, покрытие шести пар, target+price не идентифицирует, set cover по стоимости.
