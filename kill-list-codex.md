# Kill-list Codex — для слияния модератором

> Архив прежних отказов. Текущая классификация: [research/STATUS.md](research/STATUS.md). Ошибка, известность точного протокола и исследовательская слабость — разные основания. Общий ярлык без конкретного сведения не считать установленным отсутствием новизны.

| Конструкция | Причина отказа | Условие пересмотра |
|---|---|---|
| Бытовые переименования трёх дверей | ИЗВЕСТНО: классический Монти | Новый самостоятельный протокол |
| Случайная отрицательная проверка как 2/3 | ОШИБКА: при равных априорах ответ 1/2, Monty Fall | Изменённые и явно заданные likelihood |
| Текущий лидер, ранняя смена защиты | ИЗВЕСТНО: многоступенчатый Монти, 5/8 против 3/4 | Механизм вне вариантов Монти |
| Ремонт до/после отбора E∨G | ИЗВЕСТНО: Берксон, 1/2 против 2/3 | Несводимость к collider selection |
| Смеси λ и φ, порог 3/4 | Верная смесь известных правил, новизна не показана | Дополнительный самостоятельный эффект |
| Шпаргалка: два кандидата, один профессионал, оба сдали | ОШИБКА: если любитель может сдать только на защищённом месте, второй профессионал с вероятностью 1 | Другой полный протокол |
| Двойное молчание: 95,24% при независимых задержках | ОШИБКА: в указанной независимой модели 80%; 95,24% требует общей задержки | Явная другая совместная модель |
| Превентивный ремонт без чувствительности | Число не определено | Полный prior и матрица теста |
| Информация = причинная работа | ОШИБКА: наблюдение фиксированного исхода меняет odds без изменения исхода | Явная причинная модель и иной вывод |
| Фиксация = остановка posterior | ОШИБКА: последующее раскрытие меняет posterior фиксированного события | Развести генерацию, наблюдение и остановку |
| Максимум log-odds-силы κ'/κ=h | ОШИБКА: пропущена производная знаменателя p(1−p) | Исправленная задача оптимизации |

Ссылки, расчёты и ограничения: `registry-codex.md`, `rounds/r0-*.md`. Отказ в новизне отдельного кандидата не доказывает невозможность найти новый парадокс.
