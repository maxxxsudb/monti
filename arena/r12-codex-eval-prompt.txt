(1) P19. Ведущий открывает ровно k коз. Без запрета он выбирает их равновероятно среди всех дверей с козой, включая вашу; с классическим запретом — среди чужих. Априоры (p0, p, ..., p), p0 >= p.
- Без запрета: W = p0 + p·k/(N−k). С запретом: W = max(p0, p(N−1)/(N−1−k)).
- Запрет выгоден ⇔ p0/p < T(k) = 1 + k/((N−1−k)(N−k)). При N=3 это p0 < 3/7; при (1/2, 1/4, 1/4) шанс 5/8 → 1/2.
- Наибольший вред k(N−1−k)/((N−1)(N−k)^2), верхняя грань 1/4. При N=10, k=8: 13/18 → 1/2.
- T(k) растёт по k, поэтому у фаворита знак эффекта меняется по ходу открытий ровно один раз. Пример N=10, r=2: k=6 — вред 1/22, k=7 — польза 1/66.
