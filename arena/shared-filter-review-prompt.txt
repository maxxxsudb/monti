Общий коллайдер/Берксон и комплементарность известны — нас интересует именно теорема ниже. Не соглашайтесь из вежливости.

n>=2 деталей до проверок независимы, каждая исправна с вероятностью p. Устройство работает iff все исправны. Скрытый параметр общего прибора Theta∈[0,1]: хорошая деталь всегда проходит, плохая проходит с вероятностью Theta; результаты условно независимы при фиксированных Theta и качествах. Все n старых деталей прошли один общий прибор. Есть n запасных из того же исходного источника; каждая прошла свой отдельно и независимо выбранный прибор с тем же законом Theta. Других наблюдений и повреждений нет. Заменяют заранее выбранные r старых деталей, оценка устройства только после завершения замен.

S=p+(1-p)Theta, mu=E S, Z=E S^n. Утверждаем:
V_r=(p^n/Z)E[(S/mu)^r]. Поэтому V0=V1, каждая запасная строго лучше старой по отдельности при VarTheta>0, но любая одиночная замена вообще не улучшает устройство. V_(r+2)-2V_(r+1)+V_r=(p^n/Z)E[(S/mu)^r*(S/mu-1)^2]>0. При одинаковой линейной цене замены оптимально либо менять всё, либо ничего. Выигрыш всего пакета может приближаться к1 при нулевой пользе каждого одиночного шага: Theta=1 с вероятностью1/n, иначе0, p=1-1/sqrt(n), n→∞; V0=V1→0,Vn→1.

Простой случай n2,p1/2,Theta0/1 с равными шансами: старая деталь исправна3/5, запасная2/3; надёжность без замен2/5, с любой одной2/5, с двумя4/9.
