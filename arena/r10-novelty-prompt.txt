Setting: n options, exactly one target, equal priors. Each option can be given one test; results are conditionally i.i.d. given the target location, with outcome law g1 at the target and g0 elsewhere; l(x) = g1(x)/g0(x) is the likelihood ratio (an untested option has l = 1).

(1) Forced choice of one option: P(correct) = (1/n) E_0[max_i l_i]. The LAST test (all other options already tested) has zero value IF AND ONLY IF l takes at most two values (an effectively binary test); with three or more values it is strictly valuable for every n >= 2. The same zero holds for any rank-only objective (pick k of n, any ranking reward).

(2) With a walk-away option (+1 correct, -2 wrong, 0 walk away) that same last binary test becomes strictly valuable whenever playing is ever profitable; for a test that never errs on the target and misses a non-target with probability q <= 1/2, it multiplies the expected payoff exactly by n.

(3) Monty Hall form ("coin Monty"): the host knows where the car is; over every goat door he flips a coin and opens it on heads, never opening the car. Allowing him to open YOUR door too changes nothing under forced choice (win probability (1+q+q^2)/3 for 3 doors both ways, 7/12 at q=1/2), whereas in classic Monty Hall protecting your door is exactly what creates 2/3 vs 1/2. With the walk-away option, the host's access to your door triples the expected payoff (1/12 -> 1/4).
