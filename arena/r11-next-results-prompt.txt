Проверьте критически три конкретных результата. Не соглашайтесь из вежливости: найдите ошибку или дайте короткое независимое доказательство. Затем оцените научную новизну каждого точного утверждения по собственным знаниям, отдельно от известности общего Байеса/ценности информации. Если знаете предшественника — точное название/теорема; отсутствие известного вам источника не равно доказательству новизны. Интернет для этой оценки не нужен. Ответьте по-русски.

A. Одна равновероятная цель среди n>=2 мест, собственный тест каждого места. Условно на цель тесты независимы и одинаковы; P1<<P0, L=dP1/dP0>=0, E0 L=1. Выбираем ровно одно место, выплата 1 при попадании. Оптимальная точность со всеми n тестами V_n=E0 max(L1,...,Ln)/n; без последнего V_(n-1)=E0 max(1,L1,...,L_(n-1))/n. Алфавит произвольный, в том числе непрерывный.
Утверждаем: (i) Delta=V_n-V_(n-1)=0 iff L принимает <=2 значения почти наверное; (ii) точный супремум Delta по всем таким тестам равен B_n=(n-1)/n^2*n^(-1/(n-1)), но не достигается. Почти предельный тест: P0(L=0)=a, P0(L=1)=1-a-eps, P0(L=1+a/eps)=eps, a=n^(-1/(n-1)), eps->0. Для него Delta=[a(1-eps)^(n-1)-a^n]/n. Тот же супремум у непрерывных законов L. Проверьте особенно универсальность верхней границы, недостижимость и реализацию закона как допустимого теста.

B. Два места, одна цель. У каждого независимый условно на цель бинарный тест, который правильно различает цель/нецель с вероятностью 3/4. p=P(цель в A)>=1/2. Утверждаем: один тест даёт V1=max(3/4,p), оба V2=max(p,(9+6p)/16). Поэтому при p=1/2 последний тест имеет нулевую ценность; предварительная подсказка p=2/3 делает его полезным, 3/4 -> 13/16. При p>=9/10 он снова бесполезен. Проверьте точную карту, а не только идею взаимодополняемости информации.

C. Следующий точно заданный отбор деталей. Ровно по одному прибору каждого типа: W обе части исправны; P плохое питание/хорошая лампа; C хорошее питание/плохая лампа. Шесть размещений равновероятны. A откладывают. Из двух остальных мастер удаляет неисправный D, оставляет S; если оба неисправны, удаляет C с вероятностью r, P с вероятностью 1-r. Сообщается только какой удалён, диагноз и дополнительное время не сообщаются. Собирают лампу A с батареей D либо S. Исходные успехи x_D=(1+r)/3, x_S=(2-r)/3. Теперь плохую лампу A ремонтируют с вероятностью beta, хорошую не портят; условно на старую исправность операция независима от доноров, результат диагностики/ремонта игроку не сообщают. Утверждаем: оптимальный шанс из двух доноров V(beta)=max((1+r)/3,(2-r+beta)/3). Для 1/2<r<1 весь интервал beta<=2r-1 даёт нулевую ценность реального улучшения лампы; потом лучший донор меняется. Ремонт никому не вредит, цель не меняется. Проверьте плато и точный смысл ограничения информации. Предложите одну более простую корректную историю с тем же механизмом, если можете.

В конце отдельно для A(ii), B, C: Scientific novelty: YES / NO / UNCERTAIN, и по одной причине. Не подменяйте новизну строгого частного результата известностью общего метода.
