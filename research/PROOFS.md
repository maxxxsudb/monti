# Короткие доказательства и границы

Дата: 2026-10-15. Выводы ниже устанавливают математическую верность заданных моделей. Историческая новизна ими не устанавливается.

## P1. Один бинарный тест можно пропустить

Из n>=2 вариантов ровно один целевой, все положения равновероятны. У цели P(pass)=a, у прочих P(pass)=b, 0<=b<=a<=1. При заданной цели тесты независимы. После наблюдений обязательно выбираем один вариант с одинаковой наградой за успех.

Для 0<b<a<1 веса проверенного прошедшего, непроверенного и провалившегося пропорциональны a/b, 1, (1-a)/(1-b). Поэтому оптимально выбрать любого прошедшего, а при отсутствии прошедших — любого непроверенного. Крайние значения параметров получаются непрерывностью конечных сумм вероятностей.

Для k<=n-1 допустимо выбрать первого прошедшего в заранее установленном порядке, а при всех провалах — одного конкретного непроверенного. Если цель на проверяемой позиции j, успех имеет совместную вероятность a(1-b)^(j-1)/n. При выбранной непроверенной цели все k проверок провалятся с вероятностью (1-b)^k. Итого

    P_k = [a sum(j=0..k-1, (1-b)^j) + (1-b)^k]/n.

При проверке всех n аналогичная стратегия даёт

    P_n = [a sum(j=0..n-1, (1-b)^j) + (1-a)(1-b)^(n-1)]/n
        = [a sum(j=0..n-2, (1-b)^j) + (1-b)^(n-1)]/n
        = P_(n-1).

Отсюда для 1<=k<=n-1:

    P_k-P_(k-1) = (a-b)(1-b)^(k-1)/n;
    P_n-P_(n-1) = 0.

Более сильное объяснение равенства: после n-1 тестов выбранный прошедший остаётся оптимальным при обоих исходах последнего теста; если все провалились, выбранный непроверенный также остаётся оптимальным при обоих исходах. Последний тест может создать только ничью с уже выбранным.

При a=1,b=1-q:

    P_k = [sum(j=0..min(k,n-1), q^j)]/n.

Нулевой вклад не означает нулевой информации о вероятностях. Результат относится к одной функции качества — точности выбора одного варианта.

### Почему слово «бинарный» обязательно

«Бинарный» — с точностью до достаточной статистики; точное условие дано в P11.

У теста три исхода. Их вероятности для цели (1/5,2/5,2/5), для нецели (2/5,2/5,1/5). Есть два равновероятных положения единственной цели; тесты условно независимы. Один тест даёт оптимальную точность 3/5, оба — 16/25. Последний тест добавляет 1/25. Перебор девяти исходов дан в `../sims/review_exact.py`.

Таким образом, утверждение о «любом одинаковом шумном тесте» без бинарности неверно. Неодинаковые априоры, разные тесты и зависимость ошибок также могут нарушить равенство; контрпримеры есть в `../rounds/r3-codex-critique-noise.md`.

### P11. Точное условие: зазор Йенсена на изломе огибающей (добавлено 2026-10-16)

Условия P1, но тест с любым конечным числом исходов: g1 — закон исхода у цели, g0 — у нецели, g0(x)>0, отношение правдоподобия l(x)=g1(x)/g0(x). У непроверенного варианта l=1. Совместная вероятность «исходы x, цель i» равна (1/n)·Π_j g0(x_j)·l(x_i). Значит, при любой функции выигрыша u(действие, положение цели)

    V = (1/n) E_0[ max_a Σ_i u(a,i) l_i ],

где E_0 — ожидание, когда все исходы распределены по g0. Огибающая под знаком E_0 выпукла и кусочно-линейна по каждому l_i.

**Обязательный выбор:** V=(1/n)E_0[max_i l_i]. Пусть M — максимум l по первым n-1 вариантам. Ценность последнего теста

    ΔV = (1/n) E_0[ E_0 max(M, l_n) − max(M, 1) ] ≥ 0,

так как E_0 l_n = 1 (неравенство Йенсена для max(M,·)). Равенство при данном M — тогда и только тогда, когда носитель l_n не лежит строго по обе стороны от M. Каждое значение s из носителя l достигается как M с положительной вероятностью (все n-1 исходов равны s). Поэтому:

**Последний тест бесполезен ⇔ l принимает не более двух значений.** Направление «двузначное l ⇒ ноль» следует из P1 по достаточности: отношение правдоподобия — достаточная статистика, и тест с двумя значениями l эквивалентен бинарному. Содержательна обратная часть: при трёх и более значениях l ценность последнего теста строго положительна при любом n≥2. Контрпример из «Почему слово „бинарный“ обязательно» — частный случай.

**Право отказа (+1/−2/0):** огибающая max(0, 3·max_i l_i − 2·Σ_i l_i) имеет дополнительные изломы. Двузначное l может по ним проходить, и последний тест получает положительную ценность (R02). Обе части R01/R02 — один механизм: ценность проверки равна зазору Йенсена на изломах огибающей решения. Выпуклость ценности информации — известный общий факт. По сравнению с P1 добавлено точное условие для последней проверки; его приоритет не проверен.

Проверка: `../sims/r10_envelope.py` — тождество для V, равенство нулю ровно при двузначном l (6 тестов, n=2..4, точные дроби). Открытый вопрос: может ли многозначный тест, полезный при обязательном выборе, стать бесполезным при праве отказа нетривиально, то есть когда играть иногда выгодно? Найденные нули при отказе пока тривиальны — там играть невыгодно никогда. Перебор трёхисходных тестов со знаменателем 6 при n=3,4 нетривиальных зеркал не нашёл (`../sims/r10_mirror.py`).

**Следствие (ранговые цели).** Если награда зависит только от места цели в выбранном порядке (угадать одну, выбрать k из n, взвешенный рейтинг с убывающими весами), оптимально упорядочить по l, и огибающая Σ_r w_r·l_(r) ломается только в значениях l остальных вариантов. После n−1 тестов эти значения — атомы того же двузначного закона. Двузначный носитель не лежит строго по обе стороны от собственного атома, поэтому последний тест бесполезен при любой ранговой цели. Порог (право уйти) добавляет изломы вне атомов. Проверка: `../sims/r10_rank.py`, три цели, n=3,4.

## P2. Право отказа и множитель n

Берём P1 при a=1,b=1-q. Правильный выбор +1, неправильный -2, отказ 0. После всех тестов закрыты цель и случайное число неправильных. Если закрыт ровно один вариант, он точно целевой и играть выгодно. Если закрыто хотя бы два, лучший posterior не превосходит 1/2 и играть невыгодно. Поэтому

    U_n = q^(n-1).

При одном непроверенном варианте, если все остальные провалились, цель установлена; совместная вероятность этого события q^(n-1)/n.

Если прошёл ровно один проверенный, его posterior равен 1/(2-q). Его условный ожидаемый выигрыш (2q-1)/(2-q), а вероятность такого отчёта (n-1)(2-q)q^(n-2)/n. При двух или более прошедших posterior не достигает порога 2/3, и оптимален отказ. Итого

    U_(n-1) = q^(n-1)/n + (n-1)q^(n-2)max(2q-1,0)/n.

Для 0<q<=1/2 получаем U_n/U_(n-1)=n. Для q=0 оба значения нулевые. Для q>1/2 дополнительный член нельзя отбрасывать. Штраф фиксирован и равен 2; его изменение требует другого порога и расчёта.

Это доказывает R02 для всех n>=2, а не только для трёх дверей.

## P3. Донор и смена границы сборки

Типы: W — всё исправно, P — плохое питание и хороший процессор, C — хороший источник питания и плохой процессор. Ровно по одному каждого; шесть размещений равновероятны. A не проверяют. Из двух других мастер удаляет неисправный D, оставляет B. При двух неисправных он выбирает C с вероятностью r и P с вероятностью 1-r. Игроку сообщает только удалённый экземпляр, не диагноз. Извлечение деталей их не повреждает.

| Тип A | Вероятность | Хорошее питание B | Хорошее питание D | Сборка с B | Сборка с D |
|---|---:|---:|---:|---:|---:|
| W | 1/3 | 1-r | r | 1-r | r |
| P | 1/3 | 1 | 1 | 1 | 1 |
| C | 1/3 | 1 | 0 | 0 | 0 |

Усреднение трёх строк даёт

    Quality_B = 1-r/3;       Quality_D = (1+r)/3;
    Success_B = (2-r)/3;     Success_D = (1+r)/3.

Поэтому

    Quality_B - Quality_D = 2(1-r)/3;
    Success_D - Success_B = (2r-1)/3.

Первое положительно при r<1, второе — при r>1/2. Следовательно, весь открытый интервал 1/2<r<1 даёт строго худшую деталь D и строго лучшую сборку с D. Дополнительная исправность B в строке A=C бесполезна: процессор уже плохой.

При r=1/2 качества 5/6 и 1/2, успехи обеих сборок 1/2. При r=1 качества равны 2/3, но успехи 1/3 и 2/3. Эти крайние случаи нельзя описывать как «деталь D строго хуже»: строгость относится к открытому интервалу.

## P4. Помощь двум кандидатам: устойчивый линейный эффект

Три равновероятных положения одного профи. Независимые тесты проходят с вероятностью g для профи и b для прочего, 0<=b<g<=1. Для A и B каждый провал независимо заменяется зачётом с вероятностью h; исходных результатов и признака замены работодатель не видит. Качество людей не меняется. C не получает такой помощи.

Обозначим g_h=g+(1-g)h, b_h=b+(1-b)h. Оптимальное правило: C прошёл — выбрать C; иначе выбрать первого прошедшего A/B; если все провалились, выбрать C. Его оптимальность следует из ранжирования likelihood, приведённого в r3-codex-critique-noise.md.

Вероятность правильного найма:

    V(h) = [g + (1-b)g_h(2-b_h) + (1-g)(1-b_h)^2]/3
         = [1+(g-b)(2-b-h(1-b))]/3.

Поэтому V(0)-V(h)=h(g-b)(1-b)/3. Падение строго при h>0 и g>b. Это модель скрытой маскировки отчёта; обучение, повышающее реальную квалификацию, не описывается этим каналом.

## P5. Один отчёт бесполезен для найма, но полезен для вопроса об A

В P1 берём n=3,a=3/4,b=1/4. Найм с двумя и тремя тестами имеет точность 5/8.

Теперь цель — оптимально ответить «квалифицирован ли A». После провалов B,C совместные веса гипотез «A профи» и «A не профи» равны 3/16 и 1/8. Без теста A отвечаем «да». Если A тоже провалился, веса становятся 3/64 и 3/32; с тестом отвечаем «нет». Прирост точности в этой ветви 3/32-3/64=3/64. В остальных ветвях восстановление A не меняет оптимальный бинарный ответ. Точный перебор даёт 149/192 против 35/48, разница 3/64.

Для полноты веса до просмотра A по исходам B,C: оба прошли — (1/48,1/8); один прошёл — (1/16,5/24) для каждого порядка; оба провалились — (3/16,1/8). В первых трёх ветвях даже положительный результат A с отношением правдоподобий 3 не перевешивает гипотезу «A не профи». Поэтому улучшение действительно только в указанной четвёртой ветви.

Значит, равная ценность двух отчётов для одной задачи не доказывает их информационную эквивалентность для всех задач.

## P6. Свидетельство принадлежит совместимости

В модели `r4-boundary-p1.md` старый контроллер имеет бит A. У B,C независимые честные биты. Эксперт показывает один несовместимый с контроллером, при двух выбирает равновероятно. Он показал C. Два возможных случая «B совместим» и «B несовместим» имеют одинаковые исходные массы, но likelihood сообщения 1 и 1/2. Поэтому B совместим со старым контроллером с вероятностью 2/3.

Новый контроллер имеет независимый честный бит. Для любого фиксированного бита B шанс совпасть с ним равен 1/2. Усреднение по любому posterior о B оставляет 1/2. Перенос всей пары «B + прежний контроллер» сохранил бы 2/3. Меняется совместная система, а не внутренняя запись B.

## P7. Два профессиональных фильтра

Полные протоколы: `../rounds/r4-boundary-p2.md`.

- R07: после двух отказов C остаются только размещения (A инженер,B дизайнер,C новичок) и (A дизайнер,B инженер,C новичок). Likelihood совместных отказов равны 1/4 и 1, priors одинаковы. Второй вариант имеет вероятность 1/(1+1/4)=4/5.
- R08: первый назвал C. После запрета повторять C второй отдел может назвать только A. Его обязательный «пас» означает, что A — дизайнер. C не инженер по первому сообщению; значит, инженер B, новичок C. Вероятность правильного перекрёстного назначения 1.
- R09: первый инженерный фильтр удаляет дизайнера с шансом 1/2. Только в этой ветви новичок может дойти до финала; второй фильтр выбирает между инженером и новичком и оставляет новичка с шансом 1/2. Итого 1/4. Если первым удалён новичок, конечный новичок невозможен.

В R09 гарантия второго «сохраняю дизайнера, если он присутствует» условна. Утверждение «оба гарантируют присутствие своего специалиста в финале» было бы другой, несовместимой с этим протоколом посылкой.

## P8. Раннее и позднее создание: одинаковые наблюдения

Для конечных скрытого состояния X и сообщения M:

    P(X,M)=P(X)P(M|X)=P(M)P(X|M).

Первую факторизацию можно реализовать генерацией X до M, вторую — M до X. Нулевые условные события задаются произвольно: они не влияют на совместный закон. При одном законе и одинаковых доступных решениях любая фиксированная стратегия имеет одинаковую вероятность успеха.

Это не утверждение о равенстве эффектов вмешательства. Два генератора имеют разное направление причинных стрелок. И время само по себе не запрещает статистической зависимости раннего исхода и позднего наблюдения: позднее может зависеть от раннего. Обратное причинное действие на уже неизменяемое прошлое в модели запрещено.

Фраза «эффект Монти существует тогда и только тогда, когда есть зависимость» слишком сильна. Зависимость может менять posterior, но не менять лучший выбор или не давать преимущества переключению. Числа определяются полным протоколом и целью.

## P9. Когда закон сжатия действительно доказан

Равномерная цель среди N объектов. Заранее выбрана защищённая группа Y размера k; её не удаляют. Среди остальных L=N-k объектов оставляют множество T фиксированного размера m>=1, никогда не удаляя цель. Правило эквивариантно всем перестановкам внешних меток; дополнительных сигналов не наблюдаем.

Если цель в Y, любое T имеет вероятность 1/C(L,m). Если цель j вне Y, допустимы только содержащие j множества T; по симметрии вероятность каждого 1/C(L-1,m-1). Для конкретного наблюдённого T нормировка равна

    k/[N C(L,m)] + m/[N C(L-1,m-1)] = 1/C(L,m).

Следовательно, каждая защищённая позиция имеет posterior 1/N, а каждая внешняя выжившая — L/(Nm). Масса группы Y остаётся k/N, внешней — L/N. Множитель одной внешней позиции относительно одной защищённой — L/m.

Без запрета удалять цель доказательство не работает. При случайном удалении одного чужого объекта без проверки оставшийся имеет исходный шанс 1/3, и цель может оказаться удалённой. Если дополнительно наблюдать, что удалённый был пуст, получаем уже другое условие и шанс 1/2. Эти два опыта нельзя смешивать.

## P10. Отбор говорит о том свойстве, от которого зависит результат

Пусть H — нужное свойство, p=P(H), E — наблюдаемый исход. Учитываем известный режим защиты в этих вероятностях. Обозначим u=P(E|H), v=P(E|не H). При положительной вероятности E:

    P(H|E)-p = p(1-p)(u-v)/[p u+(1-p)v].

Это следует из вычитания p из формулы Байеса. При 0<p<1 свидетельство увеличивает шанс H ровно при u>v; при u=v не меняет. «Случайность» внешнего толчка ничего не говорит о равенстве u и v.

Для безопасного типа с интенсивностью отказа 0 и опасного с интенсивностью lambda, при щите, умножающем интенсивность на r, survival likelihood равны 1 и exp(-r lambda t). Поэтому

    P(H|жив к t) = p/[p+(1-p)exp(-r lambda t)].

При интенсивностях alpha и gamma вместо нулевой/ненулевой Bayes factor выживания равен exp(r(gamma-alpha)t). Защита снижает диагностичность в этой модели при alpha<gamma и одинаковом множителе r; для произвольных щитов направление не универсально.

Для двух обычных одинаковых непрерывных часов и одного защищённого места, при первом взрыве C в точный t, likelihood пустых A и B пропорциональны f(t)S(t) и f(t). Поэтому P(B пусто|C первым в t)=1/(1+S(t)). Если время не сообщают, интеграл fS равен 1/2, интеграл f равен 1, и возвращается 2/3. Интервал времени требует интегрирования, а не подстановки его середины.

## Отдельно: содержание сообщения и протокол

Пусть сообщение m правдиво означает X∈A. На положительном prior протокольный posterior пропорционален P(X=x)P(m|x), наивный — P(X=x) для x∈A. Они равны тогда и только тогда, когда P(m|x) постоянно на совместимых состояниях с положительным prior. Это простой критерий для данного сообщения и носителя prior; общее CAR-утверждение по всем сообщениям требует оговорить весь механизм.

Критерий объясняет ошибку наивного пересчёта. Сам по себе он не доказывает научной новизны конкретной задачи и не определяет полезность информации для любого решения.

## P12. Защита как вычёркивание; квота; граница по априору

Связь с P11: P11 закрывает шумные тесты при независимых проверках (последний тест бесполезен ⇔ двузначное l). P12 — аналог для зависимых открытий ведущего (квота, классика), о котором P11 говорит «формула с E_0 неприменима напрямую», и для неравных априоров.

Проверка: `sims/r10_deletion.py` (точные дроби).

**Модель.** Двери 0..N−1, машина в c с априором p_c, вы держите 0. Ведущий знает c и выбирает план S ⊆ {двери с козами} с вероятностью P(S|c); ваша дверь может входить в S. Без защиты открывает S. *Защита-вычёркивание:* открывает S∖{0}, то есть запрет вычёркивает вашу дверь из того же плана. Выбор обязательный, награда только за машину.

**Лемма вычёркивания.** Пусть план перестановочный: P(S|c)=L(|S|) для всех S, не содержащих c. Пусть p_0 ≤ p_d для всех d≠0. Тогда оптимальный шанс выиграть с защитой и без неё одинаков.

*Доказательство.* Наблюдению O с защитой соответствуют две ветви без защиты: S=O (дверь 0 закрыта) и S=O∪{0}.
- В обеих ветвях закрытые двери кроме 0 — одно и то же множество, и при c=d правдоподобие внутри ветви одинаково для всех таких d (зависит лишь от |S|). Значит, в обеих ветвях оптимальна одна и та же дверь d* — закрытая дверь d≠0 с наибольшим p_d.
- С защитой P(c=d*, O) = p_{d*}[L(|O|)+L(|O|+1)] ≥ p_0 L(|O|) = P(c=0, O), так что d* оптимальна и здесь.
- Знание, открыта ли дверь 0, не меняет оптимального действия ни при каком O, поэтому выигрыши равны. Если закрытых d≠0 нет, ветвь O∪{0} невозможна, и единственная закрытая дверь 0 выбирается в обоих случаях. ∎

Вычёркивание — функция от S, то есть огрубление наблюдения. Поэтому по Блэкуэллу оно никогда не помогает (известно). Без перестановочности возможна строгая потеря. Пример: ведущий бросает монетку только над вашей дверью; с защитой 1/3, без неё 1/2.

**Охват.** Лемма обобщает Монти-случай P1/R01 (машину не открывают никогда) с монеток на любой перестановочный план, включая квоту «ровно k». Шумные тесты P1, где «прошёл» возможно и у пустого варианта, лемма не покрывает: их обобщение на перестановочные тесты открыто.

**Разложение классики.** Квота k (ровно k дверей с козами, равновероятно).
- Без защиты: 1/(N−k).
- Вычёркивание: тоже 1/(N−k) (лемма).
- *Перепланирование:* если машина не у вас, ведущий открывает равновероятное k-подмножество из N−2 доступных дверей. Шанс (N−1)/(N(N−1−k)) — известная формула многодверного Монти.

Вся польза классической защиты — эффект перепланирования, вычёркивание даёт ноль. Ручка λ (с вероятностью λ ведущий перепланирует, иначе вычёркивает) при N=3, k=1 даёт **1/2 + λ/6**, линейно от 1/2 до 2/3. Для планов с квотой ответ на запрет определяет одно — **сохраняет ли ведущий квоту** (перепланирование) или просто вычёркивает вашу дверь. Монетка квоты не имеет, и её естественная защита — вычёркивание; отсюда ноль R01. Линейность ручки автоматическая: при каждом наблюдении оптимальное действие в обоих протоколах одно и то же. Непрерывный путь 1/2↔2/3 в архиве уже есть («минное поле», r0-B, ИЗВЕСТНО).

**Граница по априору (N=3, монетка q, априор (p₀, p, p), p=(1−p₀)/2).** Ведущий бросает монетку над каждой дверью с козой.

*С защитой* дверь 0 всегда закрыта. Совместные веса (машина в 0 / 1 / 2) по наблюдениям:
- ничего не открыто: p₀(1−q)², p(1−q), p(1−q);
- открыта одна чужая дверь (два симметричных случая): p₀q(1−q) и pq у оставшейся закрытой;
- открыты обе: только p₀q².

Итого W_prot = max(p₀(1−q)², p(1−q)) + 2·max(p₀q(1−q), pq) + p₀q².

*Без защиты:*
- ничего не открыто: все три двери с весом (1−q)² — max(p₀,p)(1−q)²;
- открыта только 0: pq(1−q);
- открыта одна чужая дверь (два случая): max(p₀,p)q(1−q);
- открыты две: pq², pq², p₀q².

Итого W_unp = max(p₀,p)(1−q²) + pq(1+q) + p₀q².

Вычитание даёт **потерю от защиты = (1+q)·max(0, min((1−q)(p₀−p), qp))**:
- ноль тогда и только тогда, когда p₀ ≤ 1/3 (ваша дверь не фаворит) или p₀ = 1;
- линейный рост до излома p₀ = 1/(3−2q), затем линейный спад до нуля при p₀=1;
- максимум q(1−q²)/(3−2q) (при q=1/2 это 3/16 в точке p₀=1/2).

Получается «палатка». Равные априоры R01 стоят ровно на её левом краю. Механизм изломов — стандартная геометрия ценности информации (Howard): ценность ноль, пока оптимальное действие не меняется. Новое только в конкретной форме. Точная проверка при q=1/5, 1/3, 1/2, 3/4 — `sims/r10_deletion.py`.

**Сведение к двум дверям (монетка q, любое N, любые априоры).** С защитой наблюдение — множество C закрытых чужих дверей, m=N−1−|C| чужих открыто. Обозначим P = max_{d∈C} p_d.
- Веса с защитой: машина в 0 — p₀q^m(1−q)^{|C|}; машина в d∈C — p_d q^m(1−q)^{|C|−1}.
- Без защиты наблюдение то же C плюс бит «открыта ли 0». Если 0 закрыта, веса p₀q^m(1−q)^{|C|} и p_d q^m(1−q)^{|C|}. Если открыта — p_d q^{m+1}(1−q)^{|C|−1}.
- Разность оптимумов при данном C равна q^m(1−q)^{|C|−1}·[max(p₀(1−q), P(1−q)) + Pq − max(p₀(1−q), P)] = q^m(1−q)^{|C|−1}·φ(p₀,P), где **φ(p₀,P) = max(0, min(qP, (1−q)(p₀−P)))**. При C=∅ веса совпадают.

Итого **потеря = Σ_{C≠∅} q^{N−1−|C|}(1−q)^{|C|−1}·φ(p₀, max_{d∈C} p_d)**. Цена защиты — сумма двухдверных скобок: ваша дверь против лучшего уцелевшего соперника.

*Следствия.*
1. **Обращение P12 для монетки.** При 0<q<1 защита бесплатна тогда и только тогда, когда p₀ ≤ p_d для каждого d с p_d>0. Если p₀>p_d>0, слагаемое C={d} положительно. Достаточность для любых перестановочных планов дана выше; необходимость — для монетки.
2. **Равные соперники**, p=(1−p₀)/(N−1): потеря = (1−q^{N−1})/(1−q)·max(0, min(qp, (1−q)(p₀−p))). Излом в p₀*=1/(1+(N−1)(1−q)), максимум по p₀ равен q(1−q^{N−1})/(1+(N−1)(1−q)). При N=3 получается формула выше.
3. **Скачок производной.** При равных априорах односторонняя производная потери по p₀ прыгает с 0 до N(1−q^{N−1})/(N−1). При N=3, q=1/2 это 9/8>1: каждый пункт преимущества фаворита стоит защите больше пункта вероятности выигрыша.
4. **Непрерывный предел.** Пусть 1−q = x/(N−1), то есть ведущий оставляет закрытыми в среднем x чужих дверей (в пределе это Пуассон(x)). При N→∞ потеря → (1−e^{−x})·min(p₀, (1−p₀)/x). Максимум достигается в x*, где e^{−x}=1/(2+x), то есть x*≈1,146 и p₀*=1/(1+x*)≈0,466, и равен **1/y* ≈ 0,3178, где y* = −W₋₁(−e^{−2}) ≈ 3,146** (W₋₁ — нижняя ветвь функции Ламберта). Конечные максимумы растут к пределу численно: N=3: 0,2232; 10: 0,2906; 100: 0,3152; 10⁴: 0,3178. **Теорема (граница).** При равных соперниках потеря от защиты < 1/y* для всех N, q, p₀, и 1/y* — точная верхняя грань (достигается только в пределе).

*Доказательство.* Положим m=N−1, u=1−q, a=e^{−u}, b=1−u, тогда a ≥ b.
- a^m − b^m = (a−b)·Σ_{k<m} a^{m−1−k}b^k ≤ (a−b)·Σ_{k<m} b^k, так как a ≤ 1.
- a−b = e^{−u}−1+u ≤ u²/2.
- u(1−b^m) = u²·Σ_{k<m} b^k.
- Значит e^{−mu} − (1−u)^m ≤ u(1−(1−u)^m), то есть q − q^N = 1−u−(1−u)^N ≤ 1−e^{−mu}.
- Максимум потери по p₀ равен q(1−q^m)/(1+mu) ≤ (1−e^{−x})/(1+x) при x=mu.
- Функция (1−e^{−x})/(1+x) достигает максимума 1/y* в точке x*. Неравенство строгое при u>0. ∎

В [NEXT-PRIOR-BOUND-2026-10-16.md](NEXT-PRIOR-BOUND-2026-10-16.md) обрезание априоров и линейная оптимизация сводят любые priors к равным ненулевым соперникам. При m=N-1 фиксированных соперниках и q точный sup по априорам равен max_(1<=k<=m) q*(1-q^k)/(1+k*(1-q)). Поэтому тот же глобальный потолок 1/y*≈0.3178444329 верен для любых априоров. ## P13. Зазор у атомов соперника: общий критерий нуля (объединяет P11 и P12)

Проверка: `sims/r11_gap.py` (точные дроби; 72 случая, в том числе неравные априоры, непроверенные двери, трёх-значные тесты).

**Модель.** n дверей, одна цель, априор p_i (любой). Двери из множества T проверяются независимыми одинаковыми тестами с конечным числом исходов: g1 — у цели, g0 — у прочих, g0>0, l=g1/g0, S — множество значений l. Обязательный выбор. Вопрос: сколько стоит дополнительно проверить дверь 0 (её тест — «последний», а вычёркивание двери 0 из плана ведущего — это его отмена).

**Тождество** (тождество P11 коллеги, взвешенное априорами). Пусть y — исходы других проверок, M(y) = max_{j≠0} p_j·l_j(y), где l_j=1 для непроверенной двери. Тогда

    ценность проверки двери 0 = E_y[ E_0 max(M, p₀·l) − max(M, p₀) ] ≥ 0,

где E_y берётся по закону исходов у нецелей. *Доказательство.* Совместный вес «исходы, цель j» равен Π g0(исходов)·p_j·l_j. Суммирование максимума по исходу двери 0 даёт E_0 max(M, p₀l), без проверки — max(M, p₀). Неравенство — Йенсен для выпуклой max(M,·), так как E_0 l=1. ∎

**Критерий.** Проверка двери 0 бесплатна ⇔ ни один атом M (значение с положительной вероятностью) не лежит строго внутри (p₀·min S, p₀·max S). Зазор Йенсена для max(s,·) положителен тогда и только тогда, когда носитель p₀l лежит строго по обе стороны от s.

Охват: только независимые тесты. Половина P12 о квоте и перепланировании (зависимые открытия) сюда не входит.

**Следствия.**
1. **P11 (коллега).** Равные априоры, остальные проверены: атомы M — это S. Бесплатно ⇔ ни одно значение l не лежит строго между min S и max S ⇔ |S| ≤ 2.
2. **P12 (монетка).** Открытие двери с козой — тест с S={0, 1/(1−q)}. Бесплатно ⇔ p₀ ≤ p_d у всех соперников, что совпадает с обращением P12.
3. **Шумный бинарный тест** (S={ℓ,h}, 0<ℓ<1<h), остальные проверены и равны, r=p₀/p. Бесплатно ⇔ r ≤ ℓ/h, или r=1, или r ≥ h/ℓ.
   - Равные априоры — **изолированный ноль**: любой сдвиг априора, и к фавориту, и к аутсайдеру, делает последнюю проверку полезной.
   - Пример n=3, тест 3/4 против 1/4 (h=3, ℓ=1/3): r=1/2 → 9/320, r=1 → 0, r=2 → 21/256; ноль снова при r ≤ 1/9 и r ≥ 9.
4. **Замкнутая формула для бинарного теста (a, b).** Обозначим h=a/b, ℓ=(1−a)/(1−b), Q=(1−b)^{n−1}. Остальные n−1 дверей проверены и равны, p=1/(n−1+r). С каждой стороны от r=1 работает один атом M, и ценность проверки двери 0 равна:
   - 0 при r ≤ ℓ/h;
   - Q·p·b·(rh − ℓ) на [ℓ/h, ℓ];
   - Q·p·(1−a)(1−r) на [ℓ, 1];
   - (1−Q)·p·a·(r−1) на [1, h];
   - (1−Q)·p·(1−b)(h − rℓ) на [h, h/ℓ];
   - 0 при r ≥ h/ℓ.

   Изломы в ℓ/h, ℓ, 1, h, h/ℓ. Односторонние наклоны при r=1 (по r, с учётом p): −Q(1−a)/n и (1−Q)a/n. При a=1, b=1−q получается ровно «палатка» монетки P12, включая наклон 9/8 по p₀. Проверено в 792 точках: `sims/r11_gap.py`.

   **Предел без шума (a→1, ℓ→0).** Нулевой отрезок (0, ℓ/h] исчезает. Интервал, где аутсайдер платит, (ℓ/h, 1), растёт к (0,1), но ценность на нём несут множители b·ℓ и (1−a), которые стремятся к 0. Поэтому **ценность непрерывна по шуму, а множество нулей меняется скачком**: при ℓ>0 это (0, ℓ/h] ∪ {1} ∪ [h/ℓ, ∞), при ℓ=0 — (0, 1] (справа излом h/ℓ уходит в бесконечность). Изолированный ноль r=1 шумного теста в пределе становится краем сплошного отрезка нулей монетки.
5. **Двугорбая кривая и экстремум.** По r ценность — два горба: (ℓ/h, 1) с вершиной в r=ℓ и (1, h/ℓ) с вершиной в r=h, между ними ноль в r=1. Ценность последней проверки неотрицательна и равна нулю при r=1. Поэтому для шумного бинарного теста **равные априоры — точка локального минимума (ноль)** ценности проверки по r. Это обратно эвристике «информация ценнее всего при полном незнании». Механизм — выпуклость ценности информации (известно), конкретная форма — нет.
6. **Зеркало R02 при неравных априорах** (вне модели P13: огибающая с отказом, тот же метод зазора). Codex доказал невозможность зеркала в iid-модели P11 с **равными** априорами и штрафом c>1 и сам указал, что для зеркала надо менять предпосылки, например априоры. Условие равных априоров у него существенно.
   - Пример с выплатами R02 (+1 / −2 / 0): три коробки, априоры (1/7, 3/7, 3/7), ваша — аутсайдер (r=1/3). Тест 2/3 против 1/6, чужие коробки проверены.
   - Обязательный выбор: проверка своей коробки даёт +5/108.
   - Право уйти: проверка даёт ровно 0, хотя играть иногда выгодно (средний выигрыш 19/63 с проверкой и без).
   - Эффект устойчив: остаётся при сдвигах r и штрафа на ±1/100 (точная проверка). Пример с выплатами +1/−1/0 лежит на границе c=1, где у Codex есть отдельный контрпример, поэтому заменён.
   - *Механизм.* При праве уйти огибающая по w₀=p₀l равна max(0, w₀−gW, (1+g)w_j−g(W+w₀)). Аутсайдер не дорастает до порога игры, поэтому все значения p₀l лежат на одном линейном куске: «играть за соперника» или «уйти». Зазор Йенсена равен нулю. При обязательном выборе излом «ваша против соперника» пересекается.
   - Вместе с R02: право уйти создаёт ценность проверки при симметрии (R02) и **может уничтожить** её у аутсайдера (на найденных интервалах).
   - Проверка: `sims/r11_gap.py`; 14 точных случаев на сетке тестов со знаменателем 6, все при r<1.

7. **Самый ценный бинарный тест — тест Монти** (n ≥ 3 дверей; **один и тот же тест у всех дверей, все соперники проверены и равны**). Условие существенно: если соперники не проверены, почти идеальный тест только своей двери при равных априорах поднимает шанс с 1/3 до (1+a−b)/3, то есть почти на 1/3 > 1/y*. По формуле п. 4 ценность проверки двери 0 максимальна в вершинах горбов, r=h и r=ℓ: с учётом p=1/(n−1+r) куски (rh−ℓ)/(n−1+r) и (r−1)/(n−1+r) возрастают по r, а (1−r)/(n−1+r) и (h−rℓ)/(n−1+r) убывают.
   - Правый горб: V_R = (1−Q)·a(a−b)/(b(n−1)+a). Для f(a) = a(a−b)/(b(n−1)+a) производная f′(a) = (a² + 2a·b(n−1) − b²(n−1))/(b(n−1)+a)² > 0 при a > b, поэтому V_R растёт по a и максимален при **a = 1** (детектор никогда не пропускает приз). При a=1 и b=1−q это ровно максимум монетки P12: q(1−q^{n−1})/(1+(n−1)(1−q)).
   - Левый горб: V_L = Q·ℓ(a−b)/(n−1+ℓ) ≤ (1−a)(a−b)/((1−b)(n−1)) ≤ (1−b)/(4(n−1)) ≤ 1/(4(n−1)) ≤ 1/8. Максимум монетки не меньше её значения при q = 1−1/(n−1): там (1−u)^{n−1} ≤ e^{−1} и 1+(n−1)u = 2, откуда максимум ≥ (1−1/e)·q/2 ≥ (1−1/e)/4 ≈ 0,158 > 1/8 при всех n ≥ 3.
   - Итог: среди всех бинарных тестов и всех r наибольшая ценность последней проверки достигается у теста Монти (a=1) с ложной тревогой b = 1−q*, и она равна максимальной потере P12. Верхняя грань по всем n — та же 1/y* ≈ 0,318 (P12).
   - Смысл: «цена запрета ведущему» и «ценность лучшей последней проверки» — одна и та же экстремальная величина. Тест Монти экстремален не только как ведущий (P16), но и как детектор.
   - Проверка: `sims/r11_gap.py` — сетка тестов со знаменателем 24, n=3..6.
   - *Гипотеза (подкреплена):* тест Монти самый ценный и среди тестов с любым числом исходов в той же постановке. Ценность — кусочно-дробная функция r с изломами в r = l_j/l_i (сравнение проверенной своей двери с соперником) и r = l_j (непроверенная своя дверь против соперника); на каждом куске она монотонна, поэтому достаточно этих точек (первая версия поиска брала только первое семейство — исправлено). Подъём из окрестности оптимума Монти и случайные старты (3 и 4 исхода, n=3 и 4, 25–60 стартов, ~1000 шагов) всякий раз сходились к самому тесту Монти: 0,223167 при n=3 и 0,247901 при n=4 — ровно его максимум, превышений нет. Доказательства нет.

## P15. Исход-исключение: зеркала R02 не бывает (номер P14 оставлен коллеге)

Проверка: `sims/r12_phase.py` (точные дроби).
- Монетка: N=3,4, неравные априоры, q ∈ {1/4, 1/2, 3/4}, штраф g ∈ {1/2, 1, 2, 4} — 816 случаев.
- Тесты с исключением со значениями l = {2, 0} и {2, 1, 0}, N=3 — 220 случаев.

**Модель.** Тест двери с конечным числом исходов, g0>0 везде, и есть **исход-исключение** x₀: g1(x₀)=0, то есть min l = 0. У ведущего с монеткой (0<q<1) это «дверь открыта». Все соперники проверены. Любые априоры. Выплаты: машина +1, коза −g (g>0), уход 0.

**Теорема.** Если проверка двери 0 (для монетки — снятие запрета) полезна при обязательном выборе, она полезна и при праве уйти. Значит, класс «полезно при обязательном выборе, бесполезно при праве уйти» (зеркало R02) пуст. Без исхода-исключения (min l > 0) зеркало бывает: P13, п. 6, min l = 2/5.

*Доказательство.*
1. По критерию P13 полезность при обязательном выборе даёт атом M = p_d·l(x) ∈ (0, p₀·max l).
2. Тождество P13 переносится на огибающую с отказом F₂(w) = max(0, max_j((1+g)w_j − gΣw)), однородную первой степени.
3. Возьмём исход y*: d показывает x, остальные соперники — x₀. Он имеет положительную вероятность, так как g0>0. В нём W = M, и по w₀ огибающая F₂ = max(0, M − g·w₀, w₀ − g·M).
4. Около 0 единственный максимум — кусок «играть за d». При w₀ = p₀·max l > M кусок «играть за 0» больше его. Значит, F₂ не аффинна на [p₀·min l, p₀·max l] = [0, p₀·max l].
5. Равенство Йенсена E F(X) = F(EX) для выпуклой F означает, что F аффинна на выпуклой оболочке носителя X: если взять опорную прямую в EX, то F − прямая ≥ 0 обязана обнуляться на носителе. Поэтому зазор при y* строго положителен, остальные ≥ 0. ∎

**Фазовые классы (монетка, сетка).** «0 / 0» — 195, «0 / +» (R02-тип) — 117, «+ / +» — 504, «+ / 0» — 0.

**Смысл.** Исход-исключение даёт определённость «остался один соперник». Она пересекает излом «ваша против соперника» при любой цели. У шумного теста такой определённости нет, и аутсайдер может целиком уйти на один линейный кусок. Граница точная в одну сторону: min l = 0 — зеркала нет, min l > 0 — зеркало возможно. Теорема о тестах с независимыми исходами; ведущий с квотой сюда не входит.


## P14. Проверка целого бесполезна для детали; порядок отказов — полезен (R25)

Фонарики R03: типы W (всё исправно), L (плохая лампа), B (плохая батарейка), по одному. Тип вашего фонарика A имеет любой априор (p_W, p_L, p_B), доноры 1 и 2 — оставшиеся два типа в случайном порядке. Лампу A сохраняем, батарейку берём у одного донора; цель — сборка работает.

- Без наблюдений: P = p_W/2 + p_B (при A=W нужная батарейка у одного донора из двух; при A=B обе донорские исправны; при A=L лампа плоха).
- **Идеальная проверка каждого донора целиком** («горит / не горит»): если W среди доноров, то A∈{L,B}. При A=B второй донор — L с хорошей батарейкой; при A=L сборка не работает ни с какой батарейкой. Обе батарейки дают одно и то же: p_B. Если оба донора не горят, то A=W, а L и B неразличимы: p_W/2. Итого p_W/2 + p_B — **ценность ровно 0 при любом априоре**.
- **Кто погас первым** (слабая лампа гаснет раньше слабой батарейки): погасший первым — L, если он есть среди доноров; у L батарейка исправна. P = p_W + p_B = P(лампа A исправна) — максимум, равный полной информации. Прирост p_W/2 (1/6 при равных априорах: 1/2 → 2/3).

Механизм (лемма Г): проверка целого разбивает доноров на {W} и {L,B}, а нужная деталь исправна у {W,L}. Разбиение не отделяет L от B — ровно то, что важно для батарейки. Порядок отказов отделяет: L и B ломаются по-разному во времени. Там, где проверка целого указывает на «хорошую» батарейку, вторая тоже хороша или лампа A всё равно плоха (ковариация).

Проверка: `../sims/r12_unit_test.py` — точный перебор шести размещений; пять видов наблюдения; нуль при равных априорах. Нуль при любом априоре следует из формул выше.

## P16. Любой перестановочный ведущий: формула потерь, «счётчик выдаёт вычеркнутое», монетка — худший ведущий

Проверка: `sims/r13_worst_host.py` (точные дроби).

**Модель.** P12, защита — вычёркивание. План перестановочный с законом размера w = (w_0, …, w_{N−1}), A_m = w_m / C(N−1, m). Любые априоры.

**Формула потерь.** Для непустого множества C закрытых чужих дверей положим m = N−1−|C| и P = max_{d∈C} p_d.
- Ветви без защиты: дверь 0 закрыта — веса p₀A_m и p_dA_m; дверь 0 открыта — p_dA_{m+1}.
- С защитой ветви слиты: p₀A_m против p_d(A_m + A_{m+1}).

Вычитание даёт

    потеря = Σ_{C≠∅} max(0, min(P·A_{m+1}, (p₀−P)·A_m)).

При монетке получается формула P12.

**Следствие 1: счётчик выдаёт вычеркнутое.** Если у закона w нет двух соседних размеров (w_m·w_{m+1} = 0 при всех m), вычёркивание бесплатно при **любых** априорах и любой цели. По числу открытых дверей видно, была ли ваша дверь в плане. Ведущий «ровно k коз» с вычёркиванием ничего не отнимает даже у фаворита. Фаворит платит только при случайном размере плана.

**Теорема (монетка — худший ведущий).** Равные соперники p = (1−p₀)/(N−1), p₀ > p. Среди всех перестановочных законов w потеря максимальна у монетки с q = 1 − p/p₀ и равна

    L* = (p₀ − p)·(1 − (1 − p/p₀)^{N−1}).

*Доказательство.*
1. Пусть n = N−1, d = p₀−p, q = d/p₀, b_m = C(n,m)q^m(1−q)^{n−m}, x_m = w_m/b_m.
2. Так как (m+1)/(n−m)·b_{m+1} = (q/(1−q))·b_m и pq/(1−q) = d, имеем потерю = d·Σ_{m<n} b_m·min(x_m, x_{m+1}) при условии Σ b_m x_m = 1.
3. Возьмём λ_k = 1 − b_n F_k/b_k, где F_k = Σ_{i≤k} b_i. Тогда min(x_k, x_{k+1}) ≤ λ_k x_k + (1−λ_k) x_{k+1}, и коэффициент при каждом x_j в сумме равен (1−b_n)·b_j. Значит, потеря ≤ d(1−b_n), с равенством при x ≡ 1, то есть при монетке.
4. Остаётся λ_k ≥ 0, то есть b_n·F_k ≤ b_k. Биномиальная последовательность лог-вогнута, поэтому для i ≤ k < n «внутренняя» пара больше «внешней»: b_i b_n ≤ b_k b_{n−k+i}. Суммируя по i ≤ k, получаем b_n F_k ≤ b_k·P(M ≥ n−k) ≤ b_k. ∎

*Единственность.* При 0<q<1 и k<n имеем P(M ≥ n−k) < 1, поэтому b_n F_k < b_k, и λ_k ∈ (0,1). Равенство в min(x_k,x_{k+1}) ≤ λ_k x_k + (1−λ_k)x_{k+1} требует x_k = x_{k+1} при всех k, то есть x ≡ 1 и w — биномиальный закон. Максимум достигается только у монетки с q = 1−p/p₀.

**Следствие 2.** Верхняя грань потерь по всем перестановочным ведущим, всем N и p₀ при равных соперниках та же, что у монетки: 1/y* ≈ 0,318 (P12).

**Неравные соперники.** Для монетки граница 1/y* при любых априорах доказана Codex (NEXT-PRIOR-BOUND-2026-10-16.md: обрезание априоров до s·p₀ и линейная оптимизация сводят задачу к k равным соперникам). Открытым остаётся только сочетание «любой перестановочный ведущий + неравные соперники». Простое сведение к Codex не работает: **при фиксированных неравных априорах худший ведущий не обязан быть монеткой** — подъём по закону размера плана находил превышение над лучшей монеткой до 0,019 (N=3..5, 150 случайных априоров на N; пример N=3, априоры ≈ (0,385, 0,243, 0,372): 0,0598 против 0,0421). Глобальный максимум (по ведущим и априорам вместе) численно по-прежнему у монетки с равными соперниками. Возможный путь: обрезание каждого w_j до max_c вершины h_c законно (за вершинами все h_c убывают), дальше — вогнутая сепарабельная задача по рангам, но не ЛП. *Гипотеза:* при любых априорах и любом перестановочном ведущем потеря не превосходит максимума для равных соперников при том же N. Сравнивать нужно глобальные максимумы: при фиксированном p₀ неравные соперники могут дать больше, потому что ваша дверь становится фаворитом против слабого соперника. Локальная оптимизация (40 стартов × 6000 шагов; N=3,4,5) нашла глобальный максимум ровно в точке «равные соперники + монетка»: 0,22314 / 0,24781 / 0,26222 против 0,22317 / 0,24790 / 0,26234. Доказательства нет.

**Временная форма.** Пусть ведущий открывает каждую дверь с козой в независимый момент с законом Exp(1), а вы выбираете в момент t, так что q = 1 − e^{−t}. При большом N среднее число закрытых чужих дверей равно x = (N−1)e^{−t}. Защита стоит фавориту дороже всего в момент t* = ln((N−1)/x*), когда в среднем закрыто **x* ≈ 1,146** чужих дверей. Худший для фаворита априор тогда p₀* = 1/(1+x*) ≈ 0,466, а цена ≈ 0,318. Это переформулировка P12 без новых вычислений.

**Смысл.** Вред фавориту требует случайного размера плана (два соседних размера с положительной вероятностью). Жёсткая квота его уничтожает: счётчик открытых дверей восстанавливает вычеркнутое. Максимум достигается только у монетки с q = 1−p/p₀. Это не значит, что любая корреляция уменьшает потерю: монетка с «неправильным» q может уступать коррелированным законам.

**Готовый парадокс (SURVEY, задача 6).** N=3, априоры (1/2, 1/4, 1/4).
- Ведущий A выбирает одну козу равновероятно среди всех, включая вашу; если выбрал вашу, а она под запретом, — не открывает ничего. Без запрета и с запретом выигрыш 5/8.
- Ведущий B бросает монетку q=1/2 над каждой дверью с козой: без запрета 11/16, с запретом 1/2. Это ровно худший ведущий P16 (q = 1−p/p₀ = 1/2, L* = 3/16).

## P18. Резонанс штрафа: при праве уйти защита бесплатна ровно при g = 1/k (номер P17 оставлен коллеге)

Проверка: `sims/r14_resonance.py` (точные дроби; N=3..6, q ∈ {1/3, 1/2, 4/5}, 15 значений g; 180 случаев; формула потерь совпала с прямым перебором).

**Модель.** Монетка Монти q (0<q<1), N ≥ 3 дверей, **равные** априоры p=1/N, защита — вычёркивание. Выплаты: машина +1, коза −g, уход 0.

**Теорема.** Защита ничего не стоит ⇔ 1/g — целое число или g ≤ 1/(N−1). Иначе она стоит строго положительную величину.

*Доказательство.* Как в P13: L = 1/(1−q), у своей двери w₀ ∈ {0, Lp} с вероятностями q и 1−q, среднее p. Пусть закрыто c ≥ 1 соперников. По w₀ огибающая с отказом равна max(0, R(w₀), w₀ − gcLp), где R(w₀) = (1+g)Lp − g(cLp + w₀) — кусок «играть за соперника». Кусок «играть за свою» не больше R на [0, Lp]: их разность равна (1+g)(w₀ − Lp) ≤ 0. Значит, огибающая равна max(0, R). Она не аффинна на [0, Lp] ⇔ R(0) > 0 > R(Lp) ⇔ **1/g < c < 1 + 1/g**. При c=0 огибающая max(0, w₀) аффинна. Зазор Йенсена положителен ровно при таких c ∈ {1, …, N−1}. Открытый интервал длины 1 содержит целое число, если только 1/g не целое; это целое c ≤ N−1, если 1/g < N−1. ∎

**Формула потерь.** Σ_{c=1}^{N−1} C(N−1,c)(1−q)^c q^{N−1−c} · [q·R(0)⁺ + (1−q)·R(Lp)⁺ − R(p)⁺] (с весами наблюдений; точная проверка в скрипте).

**Масштаб и честная оценка.**
- Нули в g = 1/k (1/(N−1) < 1/k ≤ 1) — **изолированные нули в изломах** (точки ничьей). При N=3, q=1/2 цена равна (2g−1)/12 на [1/2, 2/3], (1−g)/12 на [2/3, 1] и (g−1)/6 на [1, 2].
- Отрезок g ≤ 1/(N−1) — тривиальный режим «никогда не уходить», то есть снова R01.
- Половина g > 1 — теорема Codex для c > 1. Новое только в окне 1/(N−1) < g ≤ 1: там защита бесплатна ⇔ 1/g целое.
- Устойчиво (на открытых интервалах) другое: **немонотонность**. Рост штрафа с 2/3 до 9/10 удешевляет запрет с 1/36 до 1/120.

**Смысл.**
- Цена защиты как функция штрафа — «гребёнка»: нули в g = 1, 1/2, 1/3, … и на всём отрезке g ≤ 1/(N−1), положительные окна между ними.
- В точках g = 1/k порог ухода совпадает с ничьей «k закрытых соперников против вашей двери», и проверка своей двери никогда не меняет действие.
- Граница с Codex: его утверждение «при c>1 последний тест полезен» и контрпример при c=1 — это правый край гребёнки.

**Готовый парадокс (SURVEY, задача 8).** N=3, q=1/2: при штрафе 2/3 запрет стоит 1/36, при штрафе 9/10 — только 1/120 (на открытом интервале (2/3, 1) цена убывает по штрафу), при 2 — 1/6 (R02).

## P19. Классическая защита вредит фавориту: порог T

Проверка: `sims/r15_replan.py` (точные дроби; N=3..6, все квоты k, 400 случаев).

**Модель.** N дверей, априоры (p₀, p, …, p), p₀ ≥ p. Ведущий открывает ровно k коз.
- Без защиты он выбирает k-подмножество равновероятно среди всех дверей с козой, включая вашу.
- С защитой (классика, перепланирование) — среди чужих дверей с козой.
- Выбор обязательный.

**Формулы.**
- Без защиты при любом наблюдении S вероятность P(S | машина в c) одинакова для всех закрытых c. Значит, выбираем закрытую дверь с наибольшим априором: если ваша дверь закрыта, это она (p₀); если открыта — любой соперник. Получаем **W_unp = p₀ + p·k/(N−k)**.
- С защитой P(S | машина у вас) = 1/C(N−1,k), а P(S | машина у закрытого соперника) = 1/C(N−2,k). Получаем **W_prot = max(p₀, p·(N−1)/(N−1−k))**.

**Теорема.** Классическая защита выгодна ⇔ r = p₀/p < T, где

    T = (N−1)/(N−1−k) − k/(N−k) > 1,

и строго вредна при r > T. В априорной форме порог p₀* = T/(N−1+T): для (N,k) = (3,1), (4,2), (5,2) это 3/7, 2/5, 1/4. При r ≥ (N−1)/(N−1−k) вред равен p·k/(N−k).

**Экстремум.** Наибольший вред достигается при r = (N−1)/(N−1−k) и равен k(N−1−k)/((N−1)(N−k)²): 1/8 при (3,1), 1/6 при (4,2), 3/16 при (5,3), 2/9 при (10,8). Верхняя грань **1/4**: к ней подходят при k=N−2 и N→∞, но не достигают. История: ведущий открывает все чужие двери, кроме одной, p₀=1/2. Тогда без запрета шанс 1/2 + (N−2)/(4(N−1)), а с запретом 1/2. При N=10 это 13/18 против 1/2.

**Связь с P12/P16.** Защиту можно разложить на вычёркивание и перепланирование. Для квоты вычёркивание ничего не стоит (P16: счётчик выдаёт вычеркнутое), поэтому весь знак эффекта задаёт перепланирование: +1/6 при равных априорах (1/2 → 2/3) и −1/8 у фаворита с p₀=1/2 (5/8 → 1/2).

**Смысл.** Обязанность ведущего открыть именно чужую дверь создаёт преимущество Монти, но та же обязанность отнимает у ведущего возможность открыть вашу дверь, когда за ней коза. Для фаворита эта информация ценнее, чем концентрация открытий на чужих дверях.

**Готовый парадокс (SURVEY, задача 9).** Априоры 1/2, 1/4, 1/4, ведущий открывает ровно одну козу. Без запрета (может открыть и вашу) шанс 5/8, с классическим запретом 1/2. При равных априорах тот же запрет даёт 1/2 → 2/3.
