# Короткие доказательства и границы

Дата: 2026-10-15. Выводы ниже устанавливают математическую верность заданных моделей. Историческая новизна ими не устанавливается.

## P1. Один бинарный тест можно пропустить

Из n>=2 вариантов ровно один целевой, все положения равновероятны. У цели P(pass)=a, у прочих P(pass)=b, 0<=b<=a<=1. При заданной цели тесты независимы. После наблюдений обязательно выбираем один вариант с одинаковой наградой за успех.

Для 0<b<a<1 веса проверенного прошедшего, непроверенного и провалившегося пропорциональны a/b, 1, (1-a)/(1-b). Поэтому оптимально выбрать любого прошедшего, а при отсутствии прошедших — любого непроверенного. Крайние значения параметров получаются непрерывностью конечных сумм вероятностей.

Для k<=n-1 допустимо выбрать первого прошедшего в заранее установленном порядке, а при всех провалах — одного конкретного непроверенного. Если цель на проверяемой позиции j, успех имеет совместную вероятность a(1-b)^(j-1)/n. При выбранной непроверенной цели все k проверок провалятся с вероятностью (1-b)^k. Итого

    P_k = [a sum(j=0..k-1, (1-b)^j) + (1-b)^k]/n.

При проверке всех n аналогичная стратегия даёт

    P_n = [a sum(j=0..n-1, (1-b)^j) + (1-a)(1-b)^(n-1)]/n
        = [a sum(j=0..n-2, (1-b)^j) + (1-b)^(n-1)]/n
        = P_(n-1).

Отсюда для 1<=k<=n-1:

    P_k-P_(k-1) = (a-b)(1-b)^(k-1)/n;
    P_n-P_(n-1) = 0.

Более сильное объяснение равенства: после n-1 тестов выбранный прошедший остаётся оптимальным при обоих исходах последнего теста; если все провалились, выбранный непроверенный также остаётся оптимальным при обоих исходах. Последний тест может создать только ничью с уже выбранным.

При a=1,b=1-q:

    P_k = [sum(j=0..min(k,n-1), q^j)]/n.

Нулевой вклад не означает нулевой информации о вероятностях. Результат относится к одной функции качества — точности выбора одного варианта.

### Почему слово «бинарный» обязательно

У теста три исхода. Их вероятности для цели (1/5,2/5,2/5), для нецели (2/5,2/5,1/5). Есть два равновероятных положения единственной цели; тесты условно независимы. Один тест даёт оптимальную точность 3/5, оба — 16/25. Последний тест добавляет 1/25. Перебор девяти исходов дан в `../sims/review_exact.py`.

Таким образом, утверждение о «любом одинаковом шумном тесте» без бинарности неверно. Неодинаковые априоры, разные тесты и зависимость ошибок также могут нарушить равенство; контрпримеры есть в `../rounds/r3-codex-critique-noise.md`.

### P11. Точное условие: зазор Йенсена на изломе огибающей (добавлено 2026-10-16)

Условия P1, но тест с любым конечным числом исходов: g1 — закон исхода у цели, g0 — у нецели, g0(x)>0, отношение правдоподобия l(x)=g1(x)/g0(x). У непроверенного варианта l=1. Совместная вероятность «исходы x, цель i» равна (1/n)·Π_j g0(x_j)·l(x_i). Значит, при любой функции выигрыша u(действие, положение цели)

    V = (1/n) E_0[ max_a Σ_i u(a,i) l_i ],

где E_0 — ожидание, когда все исходы распределены по g0. Огибающая под знаком E_0 выпукла и кусочно-линейна по каждому l_i.

**Обязательный выбор:** V=(1/n)E_0[max_i l_i]. Пусть M — максимум l по первым n-1 вариантам. Ценность последнего теста

    ΔV = (1/n) E_0[ E_0 max(M, l_n) − max(M, 1) ] ≥ 0,

так как E_0 l_n = 1 (неравенство Йенсена для max(M,·)). Равенство при данном M — тогда и только тогда, когда носитель l_n не лежит строго по обе стороны от M. Каждое значение s из носителя l достигается как M с положительной вероятностью (все n-1 исходов равны s). Поэтому:

**Последний тест бесполезен ⇔ l принимает не более двух значений.** Важно число значений l, а не число исходов: тест с тремя или четырьмя исходами, но двумя значениями l, тоже бесполезен в последней позиции. Контрпример из «Почему слово „бинарный“ обязательно» — это l с тремя значениями.

**Право отказа (+1/−2/0):** огибающая max(0, 3·max_i l_i − 2·Σ_i l_i) имеет дополнительные изломы. Двузначное l может по ним проходить, и последний тест получает положительную ценность (R02). Обе части R01/R02 — один механизм: ценность проверки равна зазору Йенсена на изломах огибающей решения. Сама выпуклость ценности информации — известный общий факт; новое здесь только точное условие для последней проверки.

Проверка: `../sims/r10_envelope.py` — тождество для V, равенство нулю ровно при двузначном l (6 тестов, n=2..4, точные дроби). Открытый вопрос: может ли многозначный тест, полезный при обязательном выборе, стать бесполезным при праве отказа нетривиально, то есть когда играть иногда выгодно? Найденные нули при отказе пока тривиальны — там играть невыгодно никогда.

## P2. Право отказа и множитель n

Берём P1 при a=1,b=1-q. Правильный выбор +1, неправильный -2, отказ 0. После всех тестов закрыты цель и случайное число неправильных. Если закрыт ровно один вариант, он точно целевой и играть выгодно. Если закрыто хотя бы два, лучший posterior не превосходит 1/2 и играть невыгодно. Поэтому

    U_n = q^(n-1).

При одном непроверенном варианте, если все остальные провалились, цель установлена; совместная вероятность этого события q^(n-1)/n.

Если прошёл ровно один проверенный, его posterior равен 1/(2-q). Его условный ожидаемый выигрыш (2q-1)/(2-q), а вероятность такого отчёта (n-1)(2-q)q^(n-2)/n. При двух или более прошедших posterior не достигает порога 2/3, и оптимален отказ. Итого

    U_(n-1) = q^(n-1)/n + (n-1)q^(n-2)max(2q-1,0)/n.

Для 0<q<=1/2 получаем U_n/U_(n-1)=n. Для q=0 оба значения нулевые. Для q>1/2 дополнительный член нельзя отбрасывать. Штраф фиксирован и равен 2; его изменение требует другого порога и расчёта.

Это доказывает R02 для всех n>=2, а не только для трёх дверей.

## P3. Донор и смена границы сборки

Типы: W — всё исправно, P — плохое питание и хороший процессор, C — хороший источник питания и плохой процессор. Ровно по одному каждого; шесть размещений равновероятны. A не проверяют. Из двух других мастер удаляет неисправный D, оставляет B. При двух неисправных он выбирает C с вероятностью r и P с вероятностью 1-r. Игроку сообщает только удалённый экземпляр, не диагноз. Извлечение деталей их не повреждает.

| Тип A | Вероятность | Хорошее питание B | Хорошее питание D | Сборка с B | Сборка с D |
|---|---:|---:|---:|---:|---:|
| W | 1/3 | 1-r | r | 1-r | r |
| P | 1/3 | 1 | 1 | 1 | 1 |
| C | 1/3 | 1 | 0 | 0 | 0 |

Усреднение трёх строк даёт

    Quality_B = 1-r/3;       Quality_D = (1+r)/3;
    Success_B = (2-r)/3;     Success_D = (1+r)/3.

Поэтому

    Quality_B - Quality_D = 2(1-r)/3;
    Success_D - Success_B = (2r-1)/3.

Первое положительно при r<1, второе — при r>1/2. Следовательно, весь открытый интервал 1/2<r<1 даёт строго худшую деталь D и строго лучшую сборку с D. Дополнительная исправность B в строке A=C бесполезна: процессор уже плохой.

При r=1/2 качества 5/6 и 1/2, успехи обеих сборок 1/2. При r=1 качества равны 2/3, но успехи 1/3 и 2/3. Эти крайние случаи нельзя описывать как «деталь D строго хуже»: строгость относится к открытому интервалу.

## P4. Помощь двум кандидатам: устойчивый линейный эффект

Три равновероятных положения одного профи. Независимые тесты проходят с вероятностью g для профи и b для прочего, 0<=b<g<=1. Для A и B каждый провал независимо заменяется зачётом с вероятностью h; исходных результатов и признака замены работодатель не видит. Качество людей не меняется. C не получает такой помощи.

Обозначим g_h=g+(1-g)h, b_h=b+(1-b)h. Оптимальное правило: C прошёл — выбрать C; иначе выбрать первого прошедшего A/B; если все провалились, выбрать C. Его оптимальность следует из ранжирования likelihood, приведённого в r3-codex-critique-noise.md.

Вероятность правильного найма:

    V(h) = [g + (1-b)g_h(2-b_h) + (1-g)(1-b_h)^2]/3
         = [1+(g-b)(2-b-h(1-b))]/3.

Поэтому V(0)-V(h)=h(g-b)(1-b)/3. Падение строго при h>0 и g>b. Это модель скрытой маскировки отчёта; обучение, повышающее реальную квалификацию, не описывается этим каналом.

## P5. Один отчёт бесполезен для найма, но полезен для вопроса об A

В P1 берём n=3,a=3/4,b=1/4. Найм с двумя и тремя тестами имеет точность 5/8.

Теперь цель — оптимально ответить «квалифицирован ли A». После провалов B,C совместные веса гипотез «A профи» и «A не профи» равны 3/16 и 1/8. Без теста A отвечаем «да». Если A тоже провалился, веса становятся 3/64 и 3/32; с тестом отвечаем «нет». Прирост точности в этой ветви 3/32-3/64=3/64. В остальных ветвях восстановление A не меняет оптимальный бинарный ответ. Точный перебор даёт 149/192 против 35/48, разница 3/64.

Для полноты веса до просмотра A по исходам B,C: оба прошли — (1/48,1/8); один прошёл — (1/16,5/24) для каждого порядка; оба провалились — (3/16,1/8). В первых трёх ветвях даже положительный результат A с отношением правдоподобий 3 не перевешивает гипотезу «A не профи». Поэтому улучшение действительно только в указанной четвёртой ветви.

Значит, равная ценность двух отчётов для одной задачи не доказывает их информационную эквивалентность для всех задач.

## P6. Свидетельство принадлежит совместимости

В модели `r4-boundary-p1.md` старый контроллер имеет бит A. У B,C независимые честные биты. Эксперт показывает один несовместимый с контроллером, при двух выбирает равновероятно. Он показал C. Два возможных случая «B совместим» и «B несовместим» имеют одинаковые исходные массы, но likelihood сообщения 1 и 1/2. Поэтому B совместим со старым контроллером с вероятностью 2/3.

Новый контроллер имеет независимый честный бит. Для любого фиксированного бита B шанс совпасть с ним равен 1/2. Усреднение по любому posterior о B оставляет 1/2. Перенос всей пары «B + прежний контроллер» сохранил бы 2/3. Меняется совместная система, а не внутренняя запись B.

## P7. Два профессиональных фильтра

Полные протоколы: `../rounds/r4-boundary-p2.md`.

- R07: после двух отказов C остаются только размещения (A инженер,B дизайнер,C новичок) и (A дизайнер,B инженер,C новичок). Likelihood совместных отказов равны 1/4 и 1, priors одинаковы. Второй вариант имеет вероятность 1/(1+1/4)=4/5.
- R08: первый назвал C. После запрета повторять C второй отдел может назвать только A. Его обязательный «пас» означает, что A — дизайнер. C не инженер по первому сообщению; значит, инженер B, новичок C. Вероятность правильного перекрёстного назначения 1.
- R09: первый инженерный фильтр удаляет дизайнера с шансом 1/2. Только в этой ветви новичок может дойти до финала; второй фильтр выбирает между инженером и новичком и оставляет новичка с шансом 1/2. Итого 1/4. Если первым удалён новичок, конечный новичок невозможен.

В R09 гарантия второго «сохраняю дизайнера, если он присутствует» условна. Утверждение «оба гарантируют присутствие своего специалиста в финале» было бы другой, несовместимой с этим протоколом посылкой.

## P8. Раннее и позднее создание: одинаковые наблюдения

Для конечных скрытого состояния X и сообщения M:

    P(X,M)=P(X)P(M|X)=P(M)P(X|M).

Первую факторизацию можно реализовать генерацией X до M, вторую — M до X. Нулевые условные события задаются произвольно: они не влияют на совместный закон. При одном законе и одинаковых доступных решениях любая фиксированная стратегия имеет одинаковую вероятность успеха.

Это не утверждение о равенстве эффектов вмешательства. Два генератора имеют разное направление причинных стрелок. И время само по себе не запрещает статистической зависимости раннего исхода и позднего наблюдения: позднее может зависеть от раннего. Обратное причинное действие на уже неизменяемое прошлое в модели запрещено.

Фраза «эффект Монти существует тогда и только тогда, когда есть зависимость» слишком сильна. Зависимость может менять posterior, но не менять лучший выбор или не давать преимущества переключению. Числа определяются полным протоколом и целью.

## P9. Когда закон сжатия действительно доказан

Равномерная цель среди N объектов. Заранее выбрана защищённая группа Y размера k; её не удаляют. Среди остальных L=N-k объектов оставляют множество T фиксированного размера m>=1, никогда не удаляя цель. Правило эквивариантно всем перестановкам внешних меток; дополнительных сигналов не наблюдаем.

Если цель в Y, любое T имеет вероятность 1/C(L,m). Если цель j вне Y, допустимы только содержащие j множества T; по симметрии вероятность каждого 1/C(L-1,m-1). Для конкретного наблюдённого T нормировка равна

    k/[N C(L,m)] + m/[N C(L-1,m-1)] = 1/C(L,m).

Следовательно, каждая защищённая позиция имеет posterior 1/N, а каждая внешняя выжившая — L/(Nm). Масса группы Y остаётся k/N, внешней — L/N. Множитель одной внешней позиции относительно одной защищённой — L/m.

Без запрета удалять цель доказательство не работает. При случайном удалении одного чужого объекта без проверки оставшийся имеет исходный шанс 1/3, и цель может оказаться удалённой. Если дополнительно наблюдать, что удалённый был пуст, получаем уже другое условие и шанс 1/2. Эти два опыта нельзя смешивать.

## P10. Отбор говорит о том свойстве, от которого зависит результат

Пусть H — нужное свойство, p=P(H), E — наблюдаемый исход. Учитываем известный режим защиты в этих вероятностях. Обозначим u=P(E|H), v=P(E|не H). При положительной вероятности E:

    P(H|E)-p = p(1-p)(u-v)/[p u+(1-p)v].

Это следует из вычитания p из формулы Байеса. При 0<p<1 свидетельство увеличивает шанс H ровно при u>v; при u=v не меняет. «Случайность» внешнего толчка ничего не говорит о равенстве u и v.

Для безопасного типа с интенсивностью отказа 0 и опасного с интенсивностью lambda, при щите, умножающем интенсивность на r, survival likelihood равны 1 и exp(-r lambda t). Поэтому

    P(H|жив к t) = p/[p+(1-p)exp(-r lambda t)].

При интенсивностях alpha и gamma вместо нулевой/ненулевой Bayes factor выживания равен exp(r(gamma-alpha)t). Защита снижает диагностичность в этой модели при alpha<gamma и одинаковом множителе r; для произвольных щитов направление не универсально.

Для двух обычных одинаковых непрерывных часов и одного защищённого места, при первом взрыве C в точный t, likelihood пустых A и B пропорциональны f(t)S(t) и f(t). Поэтому P(B пусто|C первым в t)=1/(1+S(t)). Если время не сообщают, интеграл fS равен 1/2, интеграл f равен 1, и возвращается 2/3. Интервал времени требует интегрирования, а не подстановки его середины.

## Отдельно: содержание сообщения и протокол

Пусть сообщение m правдиво означает X∈A. На положительном prior протокольный posterior пропорционален P(X=x)P(m|x), наивный — P(X=x) для x∈A. Они равны тогда и только тогда, когда P(m|x) постоянно на совместимых состояниях с положительным prior. Это простой критерий для данного сообщения и носителя prior; общее CAR-утверждение по всем сообщениям требует оговорить весь механизм.

Критерий объясняет ошибку наивного пересчёта. Сам по себе он не доказывает научной новизны конкретной задачи и не определяет полезность информации для любого решения.
