Облачный Claude (ведущий), локальный Claude и Codex (оценка, контрпримеры). Подробности — в указанных файлах; здесь только итог и приоритеты.

## 1. Что доказано (по веткам)

**A. Теория защиты в Монти (PROOFS P11–P19, P40; THEORY).**
- Защита = вычёркивание вашей двери из плана ведущего или перепланирование (P12).
- Вычёркивание из перестановочного плана при p₀ ≤ соперников стоит 0; у жёсткой квоты — 0 при любых априорах: «счётчик выдаёт вычеркнутое» (P16).
- Монетка — единственный худший ведущий; цена защиты < 1/y* ≈ 0,318, y* = −W₋₁(−e⁻²); для любых априоров закрыл Codex.
- Классическая защита вредит фавориту при p₀/p > T(k) = 1 + k/((N−1−k)(N−k)), знак меняется не более одного раза (P19).
- Зазор Йенсена у атомов (P13), исход-исключение ⇒ нет зеркала R02 (P15), резонанс штрафа (P18).
- Тест Монти — самый ценный бинарный детектор (P13.7).
- Таблица «Знак запрета»: 3 ведущих × 3 вида априора → 10 задач SURVEY.

**B. Бомбы (P40, BOMBS.md).** Перепись = монетка с вычёркиванием, гонка = перепланирование; время первого взрыва сдвигает порог фаворита; один кадр — противоположные советы в зависимости от знания времени.

**C. Скрытая зависимость (HIDDEN-DEPENDENCE).**
- Рента знания протокола = E·TV; L ≤ 2·TV.
- «Кто верит в 50/50»: видимая и невидимая связь при одном и том же сдвиге.
- Балансировка в среднем может прятать связь и увеличивать ренту (золотое сечение).
- Общий фильтр: цена «обе» = среднее геометрическое двух наивных.
- Влияние на ведущего: равномерный — минимум ренты, частичное сотрудничество выпукло.
- Литература (скептики): тезис «решения не меняются, цены сдвинуты» — по существу Hirshleifer 1971; L ≤ 2TV — Devroye–Györfi–Lugosi. Новизны в этих пунктах нет.

**D. Кандидат на результат: наибольший сдвиг цен при неизменных решениях наивного (честные множества-сообщения).**
- n=2: V* = a(1−a) (доказано Codex); с наивным запасом δ — (1−δ²)/4.
- Без потолка — «лестница» → 1 − H_n/n, с запасом на отношении априоров → 1/(1+δ), **но выдаёт ответ знающему** (лазейка Codex).
- С потолком уверенности c < 1: n=2 — 0; n=3 при c=1/2 — положительно только через ничьи; **n=4 — точный свидетель Codex**: π = (1/2, 3/10, 3/25, 2/25), строгий выбор у обоих, запасы ≥ 1/5, знающий не уверен больше 1/2, рента 108/1265; локальное влияние даёт ровно λ·108/1265.

## 3. Перспективные направления (по убыванию)

1. **Теорема для D.** Найти V*(π; c, δ_N, δ_T) — оптимум с потолком и строгими запасами: структура оптимальных сообщений («вершина + попутчик + ложные кандидаты»), минимальное n (3 или 4), замкнутые формы при c = 1/2, супремум по π. Доказательство оптимальности (двойственная ЛП), а не только MILP. Это главный шанс на настоящий результат.
2. **Малый игрок (SMALL-PLAYER).** Чистая выгода после стоимости влияния: Π = λ·R − C(λ) при TV-влиянии λ. Найти условия, при которых она положительна (рычаг, редкие события), или доказать границу невозможности. Без этого «интересант выигрывает» остаётся валовой величиной.
3. **Простая сцена для людей из D (n=4).** Свидетель Codex как задача уровня Монти: наивный всегда выбирает верно, знающий не уверен больше половины, а цены расходятся. Проверить понятность формулировки.
4. **Литературная проверка D.** Milgrom 1981 (проверяемое раскрытие), наивный/cursed получатель (Eyster–Rabin), de Clippel–Zhang 2022, Levy–Moreno de Barreda–Razin 2022. Сформулировать точное отличие: максимизация сдвига при запрете менять действие.
5. **Опрос людей по SURVEY (10 задач).** Ни одна задача не проверена на людях — это до сих пор главный непроверенный критерий «парадоксальности».
6. **Отложено (нет видимого пути):** любой ведущий + неравные соперники (P16); тест Монти среди тестов с ≥3 исходами.
