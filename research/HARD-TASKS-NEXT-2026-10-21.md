## 1. Лучшие три вопроса для устойчивого предсказания

**Что есть.** Для f(α)=2α/(1+α) и hP=α,hE=1/2,hC=2/3 рассмотрена
постоянная смесь p=f+Σλj(hj−f), λj≥0,Σλj≤1.
Три точных ответа при α=0,1/4,1/2 восстанавливают все коэффициенты;
три минимальны в общем случае. Два вопроса достаточны, если активен
ровно один шаблон с неизменной неизвестной силой.

**Почему ценно.** Получить короткую и практически устойчивую батарею,
которая предсказывает ответы на новые параметры вместо дорогой сетки.

**Что трудно.** Устойчивость оценки λ и устойчивость прогноза функции
p — разные цели. Большая ошибка отдельных смешивающихся коэффициентов
может мало менять сам прогноз. Нужны явные критерии и глобальные границы.

**Задача другой модели.**
```text
Оптимизируй трёхпробную диагностику постоянной смеси эвристик.
Прочитай §§4–5 RESEARCH-TRACK-AND-NEXT-RESULTS-2026-10-21.md.

1. Пусть D_ij=h_j(α_i)−f(α_i), три α_i различны.
   Найди глобальный оптимум ||D^-1||_∞ для допустимых α_i∈[0,1].
   Сравни с известной батареей {0,1/4,1/2}, где норма равна 46.
   Повтори с запретом очевидных краевых проб: α_i∈[ε,1−ε]
   хотя бы при ε=1/10. Сетка — средство поиска, не доказательство.
2. Отдельно реши более прикладной дизайн: минимизировать худшую
   ошибку предсказания p(α) на всём рабочем интервале, если каждый
   из трёх исходных средних известен с ошибкой <=e.
   Выведи интерполяционный оператор и его норму; сравни оптимумы
   предсказания и оценки коэффициентов. Не отождествляй их.
3. Для независимых ограниченных ответов выбери распределение повторов
   между пробами при фиксированной полной цене. Дай гарантию
   прогноза на заранее отложенных α и границу её достижимости
   для явно выбранной шумовой модели.
4. Добавь проверку принадлежности симплексу λ и право отказа.
   Раздели ошибку оценивания и опровержение самой модели.
5. Верни одну готовую малую батарею, восстановление коэффициентов,
   доверительную область и три отложенных прогноза.

Это поведенческая модель. Совпадение коэффициентов с названиями
эвристик не доказывает психологическую причинность.
```

**Что принести.** Точный оптимум либо сертифицированный зазор до него,
сравнение двух целей дизайна, исполняемый расчёт и короткую батарею.

## 2. UNKNOWN без разрешения произвольных узких палаток

**Что есть.** Для всех L-липшицевых отклонений худшая цена не меньше
порядка Lη⁻³log(1/β), в том числе адаптивно. Константные смеси из
задачи 1 имеют лишь три параметра; универсальная сетка для них избыточна.

**Почему ценно.** Сохранить обнаружение неожиданного поведения и
уменьшить число запросов за счёт явно проверяемой структуры альтернатив.

**Что трудно.** Ограничение должно иметь содержательный смысл; нельзя
просто исключить из постановки любые ошибки, которые батарея пропускает.

**Задача другой модели.**
```text
Построй тест каталога постоянных смесей против широких отклонений.

Известный каталог P — симплекс функций из задачи 1.
Ответы A∈[0,1] независимы, среднее p(α), механизм неизменен.
Зафиксируй распределение новых задач ν, например равномерное.
Альтернатива UNKNOWN(η,ω): для КАЖДОГО q∈P
  ν{α:|p(α)−q(α)|>=η}>=ω.
В буферной зоне допускается неопределённый ответ.

1. Совмести трёхпробное оценивание с независимой случайной валидацией.
   Обеспечь вероятность неверного принятия/отклонения <=β.
   Не используй проверочные задачи для подгонки того же q без учёта
   переобучения. Явно учти неточность первоначального q_hat.
2. Выведи верхнюю и нижнюю цену по η,ω,β в одной шумовой модели.
   Укажи, какие логарифмы необходимы. Сравни с палатками, у которых
   ширина отклонения порядка η/L. При переносе прежней нижней границы
   на новый каталог докажи принадлежность альтернатив UNKNOWN(η,ω)
   относительно КАЖДОГО q, а не только исходного эталона. Палатка
   высоты ровно η превышает порог η лишь в одной точке: для положительной
   ширины нужен запас по высоте и отдельная проверка расстояния до P.
3. Покажи, как предположение о ширине получается из более предметных
   классов: ограниченного числа смен правила, минимальной длины
   режима либо ограниченной скорости изменения его веса.
   Укажи, что нельзя подтвердить конечными данными без допущений.
4. Добавь одну ошибку вне постоянного симплекса, которая совпадает
   с обучающей батареей. Проверь семейство её положений/параметров,
   а не одну удачную атаку.
5. Верни минимальный практически применимый протокол с явным бюджетом
   и уровнем отказа. Не обещай гарантии для всех неизвестных стратегий.

Цель — честный компромисс между дешевизной и классом обнаруживаемых
неожиданностей, а не опровержение уже доказанной KL-границы.
```

**Что принести.** Гарантию «обучение + независимая проверка», нижнюю
границу и точное описание того, какие ошибки остаются невидимыми.

## 3. Найти и предсказать сильную ловушку на новых формулировках

**Что есть.** Коробки и лампочка математически корректны. Известны
правильные ответы и несколько конкретных неверных упрощений.
Получена нижняя граница ошибки через недостающий контраст ответов.
Психологическая сила новых формулировок не измерена.

**Почему ценно.** Это прямой шаг к исходной цели проекта.

**Что трудно.** Математический разрыв не определяет частоту ошибки;
предъявление двух версий или просьба пересказать текст могут подсказать
решение. Модели могут знать структуру, а человеческая реакция отличаться.

**Задача другой модели / экспериментатора.**
```text
Построй проверяемый поиск простых ловушек с переносом на новые задачи.

1. Возьми два исходных кандидата: трёхбилетные коробки и лампочку.
   Зафиксируй полные условия, правильный ответ и ОДИН предсказанный
   неверный ответ для каждой версии. Проверь отсутствие неоднозначности.
2. Подготовь независимые переформулировки и контрольные задачи,
   сохраняющие численное ядро. Заранее отдели разработку и проверку.
3. Версии давай свежим решателям раздельно. До подсказок фиксируй
   численную вероятность и уверенность, затем краткое объяснение.
   Понимание условия проверяй отдельно, не выдавая его задним числом
   за знание, существовавшее до первого ответа.
4. Сравни обычное предъявление с рандомизированным вмешательством
   «сначала перескажи». Не считай пересказ прозрачным чтением Z.
5. По разработочной части предскажи ошибку на отложенных формулировках.
   Отчитай частоту конкретной ошибки, уверенность, контраст ответов
   и неопределённость. Не заменяй их одним произвольным общим баллом.
6. Верни один лучший сюжет уровня 5–7 класса и условие, при котором
   его следует признать неудачной ловушкой. Модельные данные и
   человеческие данные обозначай раздельно. Если данных нет,
   верни готовый пакет, не выдумывай выполненный эксперимент.

Сильный результат — заранее предсказанная ошибка на новых текстах.
Ещё одно правильное решение Байеса само по себе этот этап не закрывает.
```

**Что принести.** Готовый пакет либо реальные обезличенные ответы,
отложенный прогноз, анализ неопределённости и один честно отобранный
парадокс-кандидат. Научную новизну сюжета проверять отдельно.
