## 1. Что берём из текстов

**KL/JSD как определение отвергнуто.** Контрпример даёт задача 3+3:
P(богатый|серебро)=1/3 и при возврате, и при удалении, поэтому D=0, а цена
ошибки 1/9. Сравнивать надо ценности действий Q(a).

**Принята цепочка Φ→B→T→U, плюс пятый слой H (меню и горизонт).**
| Слой | Что | Где ломается |
|---|---|---|
| Φ разбор | текст → структура | 100/110, Q4–Q6 |
| B Байес | протокол → posterior | Монти, коробки, лампочка, обратный Монти, ревизоры, сертификат |
| T переход | наблюдение меняет мир | 3+3 без возврата |
| U выплаты | исход → выигрыш | ревизоры с выплатами |
| H меню (новое) | какие действия доступны дальше | защищённая дверь, право уйти, первый тест |

**Потеря сжатия против цены ярлыка.** В четырёх клетках 3+3: V_full=5/9,
V_g=1/2, L_g=1/18.
*Новое:* без признака returned оценки «свой» и «другой» в каждом цвете
**равны в точности** (S: 5/9=5/9, G: 4/9=4/9). Лучший решатель на сжатом
представлении безразличен, и направления ошибки сжатие не даёт. Значит,
3+3 строго попадает в `HEURISTIC_UNKNOWN`. Поле аргона
`IDENTIFIED_BY_ECOLOGICAL_PRIOR` объявлено, а не вычислено.

**Критерий «хуже монетки» пуст для двух действий.** Если действий два, то
Q(rand)=(Q*+Q̃)/2, откуда Δ_trap=R/2>0 автоматически при любой ошибке
ярлыка. Сравнивать нужно с **действием по умолчанию d**, то есть с тем, что
делает человек, отказавшийся считать (обычно «оставить своё»).

**Принимаем два вида UNKNOWN:** `NORMATIVE` (в условии не хватает факта) и
`HEURISTIC` (дешёвые правила тянут в разные стороны).

## 2. Главный инструмент: тройка (a*, ã, d)

| Тип | Условие | Пример | Свойство |
|---|---|---|---|
| A | ã=d≠a* | классический Монти (наивный 50/50 → остаюсь) | много ошибок, но ярлык не отличить от инерции |
| B | ã≠d=a* | 3+3 «серебро, удалить»; обратный Монти | ошибка требует активного ярлыка, поэтому задание диагностично |

Доли в популяции: ярлык π_s, отказ→d π_d, расчёт π_c, случайный выбор π_u.
Процент ошибок: e_A=π_s+π_d+π_u/2, e_B=π_s+π_u/2.
Отсюда **π_d=e_A−e_B**: задание типа A надо ставить в пару с заданием типа B.

Это прямо отвечает на вопрос из COMPUTATION-BARRIER: как отличить отказ
считать от уверенной ошибки.
*Объяснение наблюдений по 3+3:* в клетке «серебро, удалить» отказ плюс
«оставлю своё» даёт правильный ответ. Поэтому ловушка на этом тексте не
измерима в принципе.

## 3. Направление ошибки: культурно выученное правило

Вместо обучения игрушечного решателя (задание 06) брать ярлыки, направление
которых задано широко выученным правилом: «в Монти меняй», «сертификат
означает надёжно», «больше неисправностей — больше тревог», «подтверждения
складываются», «проверка без смены решения бесполезна». Каждое правило верно
на своём соседнем классе задач. Ловушка — минимальный выход за его границу.

**Проверяемое следствие:** знание правила можно спросить у участника.
Для пары «классический + обратный Монти» предсказан **перекрёст**: знающие
Монти ошибаются реже на классическом и чаще на обратном.

## 4. Семейство «ценность информации зависит от меню»

1. Защищённая дверь при обязательном выборе: ценность 0 (доказано).
2. Та же информация с правом уйти: выигрыш меняется втрое (доказано).
3. Бесполезный первый тест: один тест ничего не меняет, а стратегия из
   двух тестов даёт плюс.

Литература: Howard 1966, Radner–Stiglitz 1984 (ценность информации невыпукла).

*Поправка к чатгпт-тексту (прикидка).* Политика с выигрышем +3,55 оптимальна
только при ограничении «не больше двух тестов». Без ограничения при двух
плюсах (P(брак)=9/13) остановка даёт 69,2, а третий тест
(31/52)·96,4+(21/52)·57,1−2≈78,6. Продолжать выгоднее, оптимум —
последовательный тест. В тексте задачи нужно явно ограничить число тестов.

## 5. Кандидаты по порядку

**1. Обратный Монти ⚠** (помечен выше). Симметричный вариант: остаться даёт
2/3, перейти 1/3. Правило «меняй» теряет 1/3, наивный 50/50.
Вариант с priors 40/30/30: наивный тоже говорит «перейти» (4/7 против 3/7),
а правильно остаться (3/5 против 2/5).
- Область ловушки: b<a<2b, то есть 1/3<a<1/2.
- Устойчивость к выбору ведущего h: симметричный вариант верен при h<1,
  вариант 40/30/30 — при h<3/4.
- Тип B, направление задаёт выученное правило, расчёт дешёвый (не барьер).
- Риск: идея «обратного Монти» обсуждается в сети; ценность в измерении, не в новизне.

**2. Два ревизора.** При k согласных ревизорах P(своя)=1/(2^k+1). Это Монти
со смещённым ведущим, q=2^−k (Morgan и др. 1991); новизна только в сюжете.
- Согласие — улика: разойтись ревизоры могут, только если приз за своей дверью.
- С выплатами r (остаться) против 1 (перейти): при 2^(k−1)<r<2^k решение
  переворачивается на k-м ревизоре. При r∈(2,4) один ревизор → остаться,
  два → перейти.
- Устойчивость к h максимальна при r=φ²≈2,618; рекомендуем r=5/2,
  допустимые h∈(0,40; 0,63).
- Ломает и наивного, и копировщика чисел Монти (1/3:2/3).

**3. Опасный сертификат.** P(брак|сертификат)=2/5, без проверки 1/19, в
7,6 раза меньше. Если улучшить отбор (s_B 0,8→1), сертифицированные хуже
(5/11), а вся продукция лучше (4/43→5/83).
- Теорема A: сертификат хуже, чем отсутствие проверки ⇔ DOR отбора > t_G/t_B.
- Теорема B: шансы брака среди сертифицированных растут с s_B, а доля брака
  в продаже падает при t_B<1. Обе проверены на сетке.
- Регрет выбора «сертифицированный» 33/95. Механизм известен (verification
  bias, эффект Уилла Роджерса); сочетание двух переворотов сильное.

**4. Бесполезный первый тест.** Семейство 1/10<p<1/4. Ценен как третий член
семейства из раздела 4. Арифметика тяжелее, есть риск вычислительного барьера.

**5. Ровно одна против хотя бы одной тревоги.** 16/17 за одну неисправность
против 85/149 за четыре. Порог p>1−n^(−1/(n−1)), для n=4 это ≈0,37.
Слой Φ/B, хороший пример для генератора.

**Ниже по приоритету:** 3 «ДА» против 1 «НЕТ» (27/31 против 3/7; уже есть
в r0c), два бесполезных индикатора (6/7 и 2/29; синергия), успех на третьей
попытке.

## 6. Батарея из четырёх заданий: разделение стратегий

Задания: классический Монти | обратный симметричный | обратный 40/30/30 |
ревизоры k=2, r=5/2. Ответ кодируется 1=перейти, 0=остаться.

| Стратегия | Ответы | Ошибок |
|---|---|---|
| N полная модель | 1 0 0 1 | 0 |
| R «всегда меняй» | 1 1 1 1 | 2 |
| M копия чисел Монти | 1 0 0 0 | 1 |
| P слепота к протоколу | 0 0 1 0 | 3 |
| I инерция | 0 0 0 0 | 2 |

Все пять сигнатур различны. Вместе со случайной стратегией U это 6 векторов
на 16 комбинациях ответов, ранг 6, поэтому смесь идентифицируема.
Ядро из двух заданий (классический + обратный симметричный):
P(1,1)=R+U/4, P(1,0)=N+U/4, P(0,1)=U/4, P(0,0)=I+U/4.
Ограничение: стратегия P совпадает с I на ядре. Модель шума и эффект
порядка заданий требуют контрбалансировки.
