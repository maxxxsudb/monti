# Последний тест: точная граница бесплатности при асимметрии

Дата: 2026-10-16. Собственное математическое дополнение к P11/R01; исторический приоритет не проверен. Прочитаны research/PROOFS.md, THEORY.md, SHORTCUTS-2026-10-16.md. Чужие файлы не изменены.

**Сверка с параллельной веткой:** пока шла работа, в main вошёл P13 коллег. Общий критерий §1 и изолированный ноль при равных априорах уже получены там; их не считаем новым отдельным результатом. Дополнение этой записки — явная O(n)-классификация разных бинарных каналов, двухдверная численная карта и операционная подсказка, усреднённая по обоим сообщениям. Формулы согласуются с P13.

## 1. Общий критерий при разных априорах

Ровно одна цель, P(T=i)=π_i>0, сумма π_i=1. Проверки условно независимы. У проверки i законы g1_i,g0_i на конечном алфавите, g0_i>0; L_i=g1_i/g0_i, E0 L_i=1. Цель неизменна, выбрать один вариант обязательно, награда за правильный выбор одинаковая. Вариант k пока не проверен; проверены все остальные. Тогда

    V_full = E0 max_i(π_i L_i),
    V_without_k = E0 max(Z,π_k),
    Z=max_{i≠k}(π_i L_i).

Нормировки 1/n здесь нет: она уже включена в π_i. Последняя проверка k бесплатна ровно тогда, когда ни одно достижимое Z положительной вероятности не лежит строго между π_k min L_k и π_k max L_k.

Доказательство: условный прирост E0 max(Z,π_k L_k)−max(Z,π_k) — зазор Йенсена. Для функции max(Z,·) равенство нарушается строго тогда, когда носитель π_k L_k содержит значения по обе стороны Z. Для конечного носителя это эквивалентно min<Z<max. При равенстве Z одному из концов прирост нулевой.

## 2. Новое короткое следствие: разные бинарные тесты, всего n проверок порогов

Пусть каждый проверенный L_i принимает два значения m_i≤M_i, оба с положительной g0-вероятностью (неинформативный одноатомный тест допускается). Обозначим

    B=max_{i≠k}(π_i m_i),
    H_i=π_i M_i,
    A=π_k m_k, C=π_k M_k.

Все достижимые значения максимума Z образуют множество

    {B} ∪ {H_i: H_i>B, i≠k}.

В самом деле, при всех нижних исходах получаем B. Если есть верхние, максимум равен B либо одному из H_i. Каждое H_i>B достигается, когда именно i имеет верхний исход, остальные — нижний; независимость обеспечивает положительную вероятность.

**Итак, последний тест бесплатен ⇔ B∉(A,C) и ни одно H_i>B не лежит в (A,C).** Достаточно O(n) сравнений, не перебора 2^(n−1) отчётов. Это точная классификация для неодинаковых бинарных тестов и произвольных положительных priors.

Эквивалентно: либо B≥C; либо B≤A и каждое H_i лежит вне (A,C). При A=C тест неинформативен и всегда бесплатен; удобнее в этом вырожденном случае применять исходный критерий пустого интервала.

Не требуется одинаковая точность или симметрия ошибок разных каналов. Требуется двузначность LR проверенных тестов, а для проверяемого k достаточно знать его минимум и максимум: его собственный алфавит может быть многозначным. Это ещё одна точная граница переноса P11: «три значения ⇒ полезен» перестаёт быть универсальным при асимметрии priors/каналов.

## 3. Одинаковый бинарный тест: явные условия только на priors

Пусть 0<b<a<1, P(pass|цель)=a, P(pass|нецель)=b. Тогда

    m=(1−a)/(1−b), M=a/b,
    ρ=M/m=a(1−b)/[b(1−a)]>1,
    p=π_k, P=max_{i≠k} π_i.

### Если p≥P: пока не проверен один из фаворитов

Последний тест бесплатен ровно тогда, когда **для каждого i≠k либо π_i=p, либо π_i≤p/ρ**.

Равные фавориты могут конкурировать без добавочной ценности последнего теста. Но любой соперник с промежуточным prior p/ρ<π_i<p делает его строго полезным.

### Если p<P: пока не проверен не фаворит

Последний тест бесплатен ровно тогда, когда **P≥ρp**.

Доказательство: B=mP больше A=mp; поэтому бесплатность требует B≥C=Mp. Если это выполнено, любой достижимый Z≥B также вне интервала; если нет, уже событие всех нижних исходов даёт строгий прирост.

Границы включены: при π_i=p/ρ или P=ρp только ничья, строгого улучшения нет. При a=b все проверки неинформативны и бесплатны при любых priors.

### Нулевой нижний LR

При a=1, 0<b<1, m=0, M=1/b. Для положительных priors бесплатность последнего теста эквивалентна π_i≥π_k для всех i≠k, то есть **можно бесплатно не проверять любого наименее вероятного кандидата**. Всякая строго меньшая конкурирующая π_i создаёт излом между 0 и π_k M. Идеально специфичные тесты b=0 не охватываются g0>0: для них нужно отдельно учитывать события, невозможные под базовой мерой; предел ρ→∞ нельзя автоматически подставлять в классификацию.

## 4. Предельно простой парадокс

**Условие (3 предложения):** Из двух кандидатов ровно один профи; экзамен каждого независимо даёт правильный ответ «профи/не профи» с вероятностью 3/4. При равных шансах можно проверить только одного: второй экзамен совсем не повышает точность найма. Но если заранее известно, что А — профи с вероятностью 2/3, второй экзамен повышает точность найма с 3/4 до 13/16.

**Неожиданный вывод:** предварительная подсказка делает ранее бесполезную дополнительную проверку полезной. Никакого ухудшения от информации нет: добавленная информация меняет положение излома и тем самым предельную ценность другого отчёта. Предполагаемая человеческая ошибка — «чем больше знаем заранее, тем меньше пользы от оставшейся проверки» — требует опроса.

Короткий расчёт: при обоих одинаковых результатах экзаменов likelihood назначений одинаковы, и выбираем исходного фаворита А; два таких результата имеют суммарную вероятность 3/8. При разных результатах выбираем того, кого экзамены считают профи; совместная правильная масса этих двух ветвей 9/16. Итого

    V_two = 9/16+(3/8)(2/3)=13/16.

Один экзамен при prior 2/3 всё ещё должен определять выбор: положительный ответ за проверяемого, отрицательный за другого. Его точность 3/4. При prior 1/2 два дают 9/16+(3/8)(1/2)=3/4.

## 5. Полная карта для двух экзаменов точности 3/4

### Операционная реализация предварительной подсказки

Начальные шансы А и Б равны 1/2. Дополнительный источник называет настоящего профи с вероятностью 2/3; его ответ и оба экзамена независимы **при фиксированном настоящем профи**. Источник называет А или Б с одинаковой безусловной вероятностью 1/2; после любого ответа названный кандидат имеет posterior 2/3. Поэтому предыдущий пример реализуется без отбора благоприятного сообщения.

До начала всего эксперимента:

| Доступные сведения | Оптимальная точность |
|---|---:|
| Один экзамен точности 3/4 | 3/4 |
| Два таких экзамена | 3/4 |
| Подсказка 2/3 и один экзамен | 3/4 |
| Подсказка 2/3 и два экзамена | 13/16 |

Последние две строки усреднены по **обоим** сообщениям источника: каждый даёт одинаковые 3/4 и 13/16 после переименования фаворита. Следовательно, второй экзамен стоит ноль без подсказки и 1/16 с ней также ex ante, а не только условно в одной выбранной ветви. Подсказка сама не улучшает результат одного сильного экзамена, но разрешает ничьи двух сильных экзаменов. Безусловной независимости трёх сообщений нет: они связаны общей скрытой квалификацией.

Общая идея слабого сигнала, разрешающего ничьи сильных, известна и не представляется отдельным научным открытием. Содержательный результат записки — точная классификация границ бесплатности и её конкретная операционная иллюстрация.

### Формула по произвольному prior

Пусть p=P(A профи)≥1/2. При одном экзамене (любом из двух)

    V_one=max(3/4,p).

При двух

    V_two=max(p,(9+6p)/16).

Следовательно, ценность последнего

    Δ(p)=
      3(2p−1)/16,       1/2≤p≤3/4;
      (9−10p)/16,       3/4≤p≤9/10;
      0,                9/10≤p≤1.

При p=1/2 ровно ноль; при любом сколь угодно малом смещении от равенства строго положительна; максимальна при p=3/4 и равна 3/32; при достаточно сильном prior p≥9/10 снова ноль. Для p<1/2 симметрия p↔1−p. Здесь ρ=9, так что бесплатность полностью согласована с разделом 3: prior odds равны 1 или лежат вне (1/9,9).

Так возникает **два разных источника бесплатности**: точная симметрия (тест создаёт только ничьи) и сильное доминирование (тест не способен изменить лидера). Между ними тест полезен. Слово «фиксация» здесь допустимо лишь для неизменяемости оптимального действия после обоих исходов; физическое время генерации квалификации ничего само по себе не доказывает.

## 6. Проверка и статус

Точная рациональная проверка 1344 сочетаний: n=2,3,4; ненормированные priors из {1,2,3,4}^n; каналы (a,b)=(3/4,1/4),(4/5,2/5),(1,1/2),(1/2,1/2). В каждом случае прямой зазор Йенсена по всем исходам первых n−1 тестов совпал с условиями раздела 3, включая m=0 и неинформативный канал. Дополнительно прямое перечисление двух экзаменов подтвердило:

| p | Один экзамен | Два | Прирост |
|---|---:|---:|---:|
| 1/2 | 3/4 | 3/4 | 0 |
| 2/3 | 3/4 | 13/16 | 1/16 |
| 3/4 | 3/4 | 27/32 | 3/32 |
| 9/10 | 9/10 | 9/10 | 0 |

Общеизвестная основа — выпуклость ценности информации и полезность лишь при смене оптимального действия; это уже отражено в SHORTCUTS. В этой записке самостоятельно выведены явная O(n)-классификация для разных бинарных каналов, её закрытая форма по priors для общего теста и конкретная карта Δ(p). Существование точных предшественников этих формул не проверялось; ни один пример не объявлен научно новым. Общая идея взаимодополняемости информации также не нова. Математическая польза — готовая проверяемая граница, а не новое название для Байеса.
