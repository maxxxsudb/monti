## 2. Hochberg 1973 и Simon 1972 (NRLQ)
- Hochberg, M. (1973). "Generalized multicomponent systems under cannibalization", Naval Research Logistics Quarterly 20(4):585-605, DOI 10.1002/nav.3800200402. URL открыт: https://ideas.repec.org/a/wly/navlog/v20y1973i4p585-605.html. Уровень: только аннотация (пересказ).
  - Содержание по аннотации: теория Hirsch-Meisner-Boll применена к обобщённым когерентным системам, где компоненты работают на нескольких уровнях; теорема о представлении состояния системы через число рабочих частей каждого уровня; затем стохастическое поведение.
- Simon, R.M. (1972). "The reliability of multicomponent systems subject to cannibalization", NRLQ 19(1):1-14, DOI 10.1002/nav.3800190102. URL открыт: https://ideas.repec.org/a/wly/navlog/v19y1972i1p1-14.html. Уровень: только аннотация (пересказ). Это ДРУГАЯ статья, чем SIAM 1970.
  - Содержание: многосостоятельная модель надёжности, расширение модели Hirsch-Meisner-Boll; при отказе без запаса позиции с тем же типом детали "каннибализируются" так, чтобы нехватка пришлась туда, где вредит меньше; допускаются ограничения на каннибализацию; методы связи вероятностей уровней работоспособности со структурой, политикой, комплектом запчастей и надёжностью деталей.
- Модель (по аннотациям): скрыто/случайно - отказы деталей; наблюдается - состояние (число рабочих деталей); выбирается - политика каннибализации (откуда переставлять); цель - распределение/вероятность уровня работоспособности системы.
- Сравнение: в аннотациях нет ни выбора донора по порядку отказа целых блоков, ни последующей пересборки из деталей, ни байесовского вывода о цели/тестах. Эквивалента R01/R02/R03 в прочитанном нет. Это не доказывает отсутствие в полном тексте.
- Также открыта https://ideas.repec.org/a/inm/oropre/v25y1977i6p1032-1039.html (Khalifa, Hottenstein, Aggarwal, Oper. Res. 25(6):1032-1039, 1977): сравнение шести политик каннибализации симуляцией; Simon 1970 на странице не упомянут. Уровень: аннотация.

## 3. "The Test and Find Model"
- Grabchak M., Li X., Sonin I.M., "The Test and Find Model", arXiv:2608.29390v1, 29 августа 2026, math.PR. Открыто: https://arxiv.org/abs/2608.29390 (аннотация), https://arxiv.org/html/2608.29390v1 (HTML, через пересказ; PDF https://arxiv.org/pdf/2608.29390 вернул сжатый бинарник, текст не извлечён). Уровень: HTML через пересказ, не дословно, возможны неточности.
- Модель: k одинаковых объектов в n ящиках, не более одного на ящик, распределение размещения pi. Скрыто - размещение T. Наблюдается - результаты независимых несовершенных тестов (чувствительность a_i, специфичность b_i, обе >= 1/2) для ВСЕХ ящиков. Выбирается - до m меток на ящики. Цель - max ожидаемой награды: +c_i за верную метку, -d_i за неверную.
- Результаты (по пересказу): Теорема 1: ставить метку в ящик с R_i = c_i - (c_i+d_i)*alpha_i > 0, при избытке - m наибольших R_i; alpha_i = P(пусто | сигнал). Теорема 2: симметричный случай (равномерный prior), alpha_i через число нулей в сигнале.
- Совпадение с R01/R02: пересказ говорит, что случай k=1 общего решения не имеет (разобран лишь пример n=2); "ценность последнего теста" в статье НЕ рассматривается (все тесты делаются до решения). Отказ от метки (walk-away) встроен: метка ставится только при R_i>0. Правило порога alpha_i < c_i/(c_i+d_i) родственно нашему выигрышу +1/-2/0 (порог 2/3 вероятности "цель"), но множители "в n раз" и критерий "два значения l" в пересказе отсутствуют. Вывод: родственная постановка (несовершенные тесты, равные prior, отказ от метки), эквивалентного результата не найдено; полный текст не прочитан.
- Относительно R03: ничего эквивалентного (нет сборки из частей, нет выбора по порядку отказа).
- Другие работы по "шумные бинарные тесты, одна цель, равные prior": только из выдачи поиска, НЕ открывались (в качестве ориентиров, без утверждений о содержании): Assaf-Zamir 1985 (Ann. Statist. 13(3)), Posner-Rumsey 1966 / Zigangirov 1966 ("follow the leader"), arXiv 1804.05479, arXiv 2502.10551. Эти ссылки подтверждены лишь заголовками из поиска.

## 4. Mangara, "Model Development for Reliability Cannibalization"
- Mangara B.T., в: Voloşencu C. (ред.), System Reliability, InTechOpen, 20.12.2017. URL: https://www.intechopen.com/chapters/57246. Уровень: страница главы через пересказ (аннотация и описание модели), полный PDF не читал.
- Модель: k одинаковых линий из n последовательных компонентов, экспоненциальные времена жизни (rate lambda). При отказе линии её неотказавшие компоненты служат запчастями для остальных линий; варианты с короткими прерываниями (двухстадийная каннибализация). Скрыто/случайно - времена жизни; выбирается - допускать ли каннибализацию и прерывания; цель - вероятность выживания системы / коэффициент улучшения.
- Сравнение: по пересказу, правила выбора донора по порядку отказа текст не обсуждает. Эквивалента R03 нет; к R01/R02 отношения нет. Близкая лишь бытовая схема: "отказавшая линия отдаёт исправные части".

## Дополнение Claude (16.10): сырой текст The Test and Find Model

PDF распакован стандартным zlib (52 тыс. знаков текста). В аннотации и введении сказано прямо: DM «tests all of the boxes», затем ставит до m меток с наградой c_i за верную и штрафом d_i за неверную. Пропуск теста, непроверенные ящики, ценность последнего теста, Монти Холл в тексте не встречаются (поиск по not test / untested / fewer / skip / value of information / Monty). Вывод: TF — близкая постановка (шумные тесты всех ящиков плюс право не ставить метку, то есть аналог права уйти), но R01/R02/P11 в ней нет. Это проверка одной статьи, а не литературы в целом.
