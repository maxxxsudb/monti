## N1. Глобальный оптимум и тождество Фейера—Эрмита

Фиксируются функции `f(a)=2a/(1+a)`, `hP=a`, `hE=1/2`, `hC=2/3` и постоянные на всей оси коэффициенты смеси. После умножения каждой строки D на (1+a) получается квадратичный базис, поэтому матрица факторизуется через Вандермонда.

Для любой тройки **различных** `0≤a<b<c≤1` проверено:

- `R_P=2(1+b)/[(b-a)(c-b)]`;
- `R_E=6+2(2ac-a-c+1) R_P`;
- `R_C=6+(3/2)(3ac-a-c+1) R_P`.

В доказательстве верно, что увеличение ширины по крайним точкам уменьшает все строковые нормы, а оптимальный средний узел — `b*=sqrt((1+l)(1+u))-1`. В отдельных краевых случаях коэффициенты при `R_P` равны нулю, так что формулировку «строго положительны на всём [0,1]²» следует заменить на «неотрицательны»; это не меняет теорему.

Для `[0,1]` точный оптимум `6+4sqrt(2)=11.656854...`, для `[0.1,0.9]` оптимальный средний узел `sqrt(2.09)-1=0.445683...` и норма `18.410520...`.

Для удобной рациональной батареи `{0,2/5,1}`:

```
D^-1 = [[5/2, -35/6, 10/3],
        [-2,      0,   -4],
        [3,       0,    3]]
||D^-1||_inf = 35/3 = 11.666666...
```

Тождество в §1.4 `1-sum_i T_i(x)^2 = C * (x-a)(c-x)(x-b*)²/(1+x)²` при указанном положительном коэффициенте C проверено численно на различных `[a,c]`, но это **не означает**, что любой набор 3 узлов имеет такое свойство. Для оптимальных узлов оно позволяет доказать `sum_i T_i(x)^2≤1` на `[a,c]`. В узлах сумма квадратов равна 1, а значит для независимых гомоскедастических измерений при общих N повторах оптимальна схема `N/3` на каждый узел. **Если ответы имеют разную дисперсию в разных узлах, равномерность оптимальной уже не обязана быть:** это отдельное предположение.

## N2. Явный контрпример к вероятностному шагу и безопасная замена

Статья требует на раунде `ell` число ответов:

```
s_ell = ceil(16/(9 eta²) * ln(32 ell²))
```

И заявляет, что для точки с истинным отклонением ровно `eta` вероятность недооценить абсолютную невязку до `5 eta/8` не больше `1/(16 ell²)`.

При `eta=0.2`, `qhat=0.5`, истинной бернуллиевской вероятности `p=0.7`, `ell=5` получаем `s_ell=298`. Точное биномиальное вычисление:

```
P[Bin(298,0.7)/298 <= 0.625] = 0.003031446...
1/(16*5²) = 0.0025
```

Следовательно, **использованная в доказательстве оценка ложна даже для бернуллиевского оракула**. При `ell=6` получается `0.002414177... > 1/576=0.00173611...`.

Более того, если на очередном раунде удалось сохранить лишь точку с истинной невязкой `>eta/4`, из этого не следует, что финальное независимое подтверждение преодолеет порог `5eta/8`. Для доказательства требуется контролировать сохранение достаточно сильного нарушителя, а не просто «нехорошего» узла.

Отсюда нельзя заключить, что оценка `Theta(log(1/beta)/(omega eta²))` принципиально невозможна; однако **приведённый алгоритм и доказательство её не устанавливают**.

### Безопасный протокол с несколько более высокой ценой

Пусть `Lambda` — супремум суммы абсолютных интерполяционных весов по `[0,1]` при выбранных обучающих узлах. Независимые `[0,1]`-ответы стационарны. Параметры `0<eta≤1` и `0<omega<1`.

1. **Обучение:** на каждой из трёх точек по
   `n_tr = ceil(32 Lambda² / eta² * ln(18/beta))` ответов. Найти `qhat ∈ P`, минимизирующую максимальное отклонение на трёх обучающих средних. При `H0:p∈P` с вероятностью ≥`1-beta/3` получаем `||p-qhat||∞≤eta/4`.
2. **Отложенные точки:** независимо взять `M=ceil(ln(3/beta)/(-ln(1-omega)))` случайных α из ν. Для каждой получить по `n_val=ceil(32/(9eta²)*ln(6M/beta))` свежих ответов.
3. **Решение:** если есть точка с `|mean(α)-qhat(α)|>5eta/8`, ответ `UNKNOWN`; иначе `CATALOG` (можно отдельно разрешить `INCONCLUSIVE`).

При H0 и при H1=`UNKNOWN(eta,omega)` ошибки контролируются тремя событиями: промах обучения, промах по расположению валидационных точек и статистический промах валидации. Каждый из них имеет вероятность ≤`beta/3` по Хёффдингу и независимому выбору точек.

Гарантированная верхняя цена (без претензии на оптимальность):

`3 n_tr + M n_val = O(Lambda² eta^-2 ln(1/beta) + (omega eta²)^-1 ln(1/beta) ln(ln(1/beta)/(omega beta)))`.

**Атаки с четырьмя знакопеременными парами.** Их идея (степень 2 => не больше 2 корней, 4 пары оставляют минимум 2 без корней) содержательна, но построение расходует **4ω единицы длины плато**. Для равномерного ν на `[0,1]` оно в таком виде требует `4ω≤1`, а непрерывные переходы требуют даже `4ω<1`. При `omega=0.3` нужно 1.2 единицы плато: требуемой функции не существует. Ограничение «при любых eta≤1/4» не снимает ограничения на ω.

## R1. Исправленные причинные профили и два несовместимых определения

Источник задаёт прямую вероятность починки `gamma` и побочную `epsilon`, причём при совместных сбоях восстановление каналов независимо. Тогда под одиночным `I_Z` при `L+W` надо одновременно исправить L с вероятностью gamma и W с вероятностью epsilon, так что:

`P(исправить L+W | I_Z)= gamma*epsilon`, **не** `epsilon²`. Аналогично для `I_R`.

Источник ниже использует другую таблицу:

```
N:  (1, 1, 1)
L:  (gamma,epsilon,gamma)
W:  (epsilon,gamma,gamma)
E:  (epsilon,epsilon,epsilon)
LW: (epsilon²,epsilon²,gamma²)
```

В этой **табличной модели** при `gamma>epsilon≥0` истинный минимальный ℓ∞-зазор равен

`min{ gamma-epsilon, max[ epsilon*(1-epsilon), |gamma²-epsilon| ] }`.

В **структурной модели с независимой починкой** правильная строка LW равна `(gamma*epsilon,gamma*epsilon,gamma²)`, а минимальный зазор:

`min{ gamma-epsilon, max[ epsilon*(1-gamma), |gamma²-epsilon| ] }`.

Почему? Все расстояния, кроме пары E—LW, не меньше `gamma-epsilon`, а расстояние E—LW по ℓ∞ есть максимум двух указанных координатных отклонений. Остальные пары (N,L,W) не уменьшают минимум.

Пример `gamma=.7`, `epsilon=.49`: опубликованная формула даёт 0 (поскольку gamma²=epsilon). **Настоящее расстояние равно .21 для таблицы, и .147 для структурной модели.** Оба результата получены полным перечислением 10 пар.

Заявленная **минимальность трёх вмешательств при фиксированных gamma, epsilon** также неверна: при `gamma=.9`, `epsilon=.1` уже `(I_Z,I_R)` дают пять различных пар средних: `N=(1,1)`, `L=(.9,.1)`, `W=(.1,.9)`, `E=(.1,.1)`, `LW=(.09,.09)` при структурном определении. Три вмешательства могут понадобиться для равномерной идентификации, включая хирургический предел `gamma=1,epsilon=0`; это более слабое и другое утверждение.

Из численного различия пяти средних само по себе **не следует** идентификация внутренних механизмов людей: структура, независимость и размеры побочных эффектов требуют дополнительных проверок.

## R2. Исправление шумной бисекции

В присланном тексте при каждом шаге по знаку оценённого среднего всегда отсеивается половина отрезка. При истинном корне **сколь угодно близко к середине** сигнал `|w(m)-tau|` сколь угодно мал. Число ответов, рассчитанное только из длины L_s, не гарантирует правильного знака, даже если `w` монотонна и удовлетворяет `|w(x)-tau|≥mu|x-theta*|`. Значит указанная процедура и её гарантия не совпадают.

**Строгая замена — троичная логика с перекрытием (для неубывающего w).** На отрезке `[l,u]` длины `L`, середина `m`, получить оценку `what(m)` с ошибкой не более `mu*L/8`. Это обеспечивается

`n_s = ceil(32/(delta² mu² L²) * ln(2S/beta))`

независимыми `[0,1]`-ответами при `|h-f|≥delta`. Затем:

- если `what(m)−tau>mu L/8`, оставить `[l,m]`;
- если `what(m)−tau<−mu L/8`, оставить `[m,u]`;
- иначе оставить **центральную** половину `[m−L/4,m+L/4]`.

Доказательство: в первых случаях знак истинного `w(m)−tau` установлен; в третьем `|w(m)−tau|≤mu L/4`, а условие крутизны даёт `|m−theta*|≤L/4`. Во всех случаях истинная граница остаётся внутри нового отрезка, чья длина вдвое меньше. Через `S=ceil(log2((u0−l0)/(2eta)))` шагов радиус неопределённости ≤`eta`; ошибка всей процедуры ≤`beta` по объединению S доверительных событий. Полная цена `O(log(S/beta)/(delta² mu² eta²))` запросов, за `O(log(1/eta))` различных точек.

Это **исправленный доказанный алгоритм**, хотя не доказывает снятие всех логарифмов и не закрывает остальные режимы из большой задачи R2.

## R3. Ложная асимптотическая эквивалентность запаса наклона

В тексте одновременно написано:

`L_eff = sqrt(L²-(p*')²) asymp L-|p*'|`.

Равномерно по эталонам это неверно: отношение равно `sqrt((L+|s|)/(L−|s|))` и неограниченно растёт при `|s|→L`. Например при L=1, s=.9999 оно ≈141.4.

Для обычной скалярной палатки и линейного эталона локальный запас наклона — `L−|s|`. Формула для интегральной «точной цены» в R3 не выводится из указанной ложной эквивалентности; без самостоятельного верхнего алгоритма и соответствующей нижней границы она остаётся гипотезой. Частный экстремальный эталон `p*(x)=x` при L=1 действительно определяется двумя идеальными значениями на концах; этот частный факт корректен.
