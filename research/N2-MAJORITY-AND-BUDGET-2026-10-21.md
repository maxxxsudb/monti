# N2: доказанная цена без лишних логарифмов и меньший конечный бюджет

21 октября 2026. Новый алгоритм; прежний ошибочный Block-Halving не
объявляется исправленным одной заменой константы. Научный приоритет
не проверялся. Использованы элементарный отсев приблизительного максимума
и усиление надёжности независимыми голосами.

## 1. Модель и точный масштаб результата

P — прежний симплекс постоянных смесей f,prior,equal,classic.
Независимые ответы A∈[0,1], среднее p(x) стационарно. Новые x берутся
из заранее фиксированного ν независимо от обучающей выборки.

    H0: p∈P.
    H1: для каждого q∈P мера {x: |p(x)−q(x)|≥η} не меньше ω.

Вне H0∪H1 допускается любой ответ. Верхний алгоритм ниже работает
при 0<η≤1, 0<ω<1, 0<β≤1/4. Его детерминированная цена

    N=O(log(1/β)/(ωη²)).

Для равномерной ν на [0,1], 0<η≤1/4, ω≤1/100 нижнее семейство
[из предыдущего аудита](ALL-HARD-PACKAGES-REVIEW-2026-10-21.md)
даёт согласованную Ω-границу, включая адаптивность и остановку.
В этом диапазоне **minimax-порядок Θ(log(1/β)/(ωη²)) установлен**.
Это порядок, не точная конечная константа и не психологическая гарантия.

## 2. Обучение

Взять три узла, для которых пространство каталога воспроизводится
интерполятором с известной нормой ≤Λ0. Из n_tr ответов в каждом
получить средние, затем найти q_hat∈P, минимизирующую максимальную
невязку на трёх средних. Положим

    n_tr=ceil[32Λ0²η⁻² log(18/β)].

Под H0 с вероятностью ≥1−β/3 имеем ||p−q_hat||∞≤η/4.
Это прежнее доказательство: ошибка среднего ≤η/(8Λ0), проекция
увеличивает узловую ошибку не более чем вдвое, затем работает интерполяция.
Под H1 точность fit не нужна: важно, что q_hat принадлежит P.

Для рациональных узлов 0,2/5,1 можно строго взять Λ0=4/3:
левый внутренний пик не выше 1+4/15, правый — 1+9/28.
Это следует из √(7/5)−1≤1/5 и
(√2−√(7/5))²≤9/140 в точных формулах двух пиков.

## 3. Один блок с постоянной надёжностью

Пусть M — минимальная степень двойки не меньше 2/ω. Взять M новых
независимых x. Для фиксированного после обучения q_hat обозначим
d_i=|p(x_i)−q_hat(x_i)|. Вероятность наличия d_i≥η не меньше 1−e⁻².

### Отбор победителя с гарантированной истинной невязкой

На раунде ℓ осталось m_ℓ=M/2^(ℓ−1) кандидатов. В каждой точке взять
новые ответы в количестве

    e_ℓ=(η/8)(3/4)^(ℓ−1),   δ_ℓ=1/(16·2^ℓ),
    n_ℓ=ceil[(2/e_ℓ²) log(6/δ_ℓ)].

Сохранить половину с наибольшими оценками |A_bar−q_hat|.

**Лемма одного раунда.** С вероятностью ≥1−δ_ℓ максимум истинных
невязок сохранённой половины не меньше текущего максимума минус e_ℓ.

Доказательство: обозначим текущий максимум d*. Оценка его носителя
не ниже d*−e_ℓ/2, кроме события вероятности ≤δ_ℓ/3 по Хёффдингу.
Для любого кандидата с d_i<d*−e_ℓ вероятность оценки ≥d*−e_ℓ/2
тоже ≤δ_ℓ/3. По Маркову вероятность наличия m_ℓ/2 таких кандидатов
не больше 2δ_ℓ/3. Если все оставленные кандидаты плохие, а лучший
удалён, произошло хотя бы одно из этих событий.

Σe_ℓ<η/2, Σδ_ℓ<1/16. Поэтому с вероятностью ≥15/16 победитель
имеет d_winner≥max_i d_i−η/2. Если был кандидат ≥η, победитель ≥η/2.
Это именно та нижняя граница силы, которой недоставало прежнему алгоритму.

### Голос блока

В победителе взять свежие

    n_c=ceil[32η⁻² log32]

ответа. Голос UNKNOWN, если |A_bar−q_hat|>3η/8, иначе CATALOG.
Вероятность ошибки среднего на η/8 не больше 1/16.

Под H0 на хорошем обучении истинная невязка любого победителя ≤η/4:
вероятность голоса UNKNOWN ≤1/16. Под H1 вероятность такого голоса
не меньше (1−e⁻²)(15/16)²>3/4. Порог согласован с гарантией победителя.

## 4. Голоса вместо дорогого подтверждения всех победителей

Повторить блок независимо нечётное K раз, ответить большинством.
Условно на обучающих данных блоки независимы. Достаточно нечётного
K≥8log(3/β): ошибка голосования ≤e^(−K/8)≤β/3 по Хёффдингу.
Под H0 добавить β/3 за обучение; под H1 оценка равномерна по любому
q_hat∈P. Общая ошибка ≤β.

Не нужно ни подтверждать каждый блок до β/K, ни искать одного
победителя среди всех блоков с надёжностью 1−β.

Для конечных чисел в коде K уменьшено точными биномиальными хвостами.
Использована рациональная нижняя граница надёжности блока:

    z=M(ω+ω²/2), E24(z)=Σ_{j=0}^{24} z^j/j!,
    r=[1−1/E24(z)](15/16)²>3/4.

Она корректна, поскольку (1−ω)^M≤e^(−z)≤1/E24(z).
Найти минимальное нечётное K с обоими хвостами ≤β/3 для параметров
1/16 и r. Для неодинаковых вероятностей голосов используются те же
границы по стохастическому доминированию.

## 5. Полная цена, включая все этапы

Точный бюджет заданной реализации:

    N=3n_tr+K[Σ_{ℓ=1}^{log2 M} m_ℓ n_ℓ+n_c].

При подстановке параметров раунда

    Σm_ℓn_ℓ ≤ (128M/η²)[9log96+81log2]+2M,

поскольку отношение геометрической прогрессии 8/9<1.
M<4/ω, K=O(log(1/β)); и отбор, и подтверждение дают нужную цену.
Логарифма log(1/ω) и дополнительного log(1/β) в порядке нет.

Константы доказательного отсева велики. Можно заранее сравнить его
бюджет с простым выбором максимальной оценки после
n_flat=ceil[8η⁻²log(32M)] ответов на каждого кандидата. Последний тоже
гарантирует потерю максимума ≤η/2 с ошибкой ≤1/16. Выбор более дешёвого
метода **до получения данных** сохраняет доказательство и общий O-порядок,
поскольку цена минимума не больше цены доказательного отсева.

## 6. Практическое улучшение обычной проверки

Для умеренных параметров выгоднее прежняя независимая валидация,
но с другим балансом ошибок. Пусть после обучения ||p−q_hat||∞≤aη,
0<a<1. Валидационный порог — (1+a)η/2, допустимая ошибка среднего
— (1−a)η/2. Тогда достаточно

    n_tr(a)=ceil[2Λ0²/(a²η²) log(18/β)],
    M=ceil[log(3/β)/(−log(1−ω))],
    n_val(a)=ceil[2/((1−a)²η²) log(6M/β)],
    N_flat=3n_tr+Mn_val.

Три вероятности неудачи — обучение, промах всех новых x, статистическая
ошибка валидации — каждая ≤β/3. Под H1 q_hat∈P независимо от fit.

Без округлений N_flat=A/a²+B/(1−a)², где
A=6Λ0²η⁻²log(18/β), B=2Mη⁻²log(6M/β).
Минимум при a=A^(1/3)/(A^(1/3)+B^(1/3)), равен (A^(1/3)+B^(1/3))³.
После округлений это не обязательно точный целочисленный минимум.

процедура сохраняет оптимальный асимптотический порядок и не ухудшает
доступную конечную гарантию. Точный minimax-бюджет для данных чисел
не установлен.
