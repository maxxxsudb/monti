## 1. Общий адаптивный POMDP диагностики

**Что есть.** Для двух гипотез — точная ценность вопроса \(V=1/2-\epsilon\) и порог стоимости; для пункта о типе ведущего — детерминированный DP по 16 клеткам (адаптивная пара \(0{,}15\), один идентификатор \(0{,}10\)) и стохастический DP при \(T\le3\) (\(0{,}2\), первый вопрос Q2(1/4)). Доказан конечный горизонт \(T\le\lceil L_{\max}/c\rceil\). Открыт общий \(k>2\) со стохастическими проверками и непрерывным убеждением.

**Почему трудно.** POMDP с непрерывным убеждением вычислительно тяжёл; для \(k>2\) нет простого порога; нужны структурные теоремы или точные алгоритмы для малых \(k\), а не ещё один расчёт.

**Задача другой модели.**
```
Реши задачу оптимальной адаптивной диагностики.
Дано: конечное H={1..k}, априор π; конечный набор проверок θ с известными
P(a|h,θ) и стоимостью c(θ)>0; терминальные потери L(ĥ,h)∈[0,1]; горизонт T
или POMDP с остановкой. Политика адаптивно выбирает проверки и
останавливается; ценность — минимум ожидаемых стоимость+потери.
Вопросы:
1. Для k=4 и пункта о типе ведущего (три двери, выбран A; ведущий знающий
   с вероятностью α, иначе случайный; знающий всегда открывает B, если B
   пуста, иначе C; случайный открывает B/C поровну; наблюдение — B открыта
   и пуста; Q2=P(знающий|E)=2α/(1+α); четыре гипотезы: correct 2α/(1+α),
   prior α, equal 1/2, classic 2/3) посчитай точную оптимальную политику
   для T=1..5 при симметричном шуме ε=0.1 и проверках Q2(1/4), Q2(1/2), Q1.
2. Для k=3 и семейства бинарных симметричных проверок докажи или опровергни,
   что оптимальная политика — порог по апостериору (continuation interval).
   Если неверно — контрпример.
3. Охарактеризуй, когда жадная одношаговая информационная политика
   оптимальна; иначе — контрпример.
4. Докажи нижнюю границу на число проверок для гарантированной ожидаемой
   потери ≤ε.
Нужны теоремы/контрпримеры и точные расчёты, не только код.
```

**Что принести.** Теорему/контрпример к порогу, точный алгоритм для \(k\le4\), границу числа проверок, точную политику для пункта.

## 2. Многомерная геометрия столкновений и T-optimal дизайн

**Что есть.** Для аналитических предсказаний множество столкновений имеет меру нуль; для рациональных \(a_h=P_h/Q_h\) кросс-полином имеет степень \(\le2d\); для ленивого ведущего \(f=\alpha(q+1)/(1+\alpha q)\) выписаны кривые \(\alpha=1/(q+2)\), \(\alpha=2/(q+3)\); однопараметрический max-min \(\alpha^*\), \(\delta^*=(√17−3)/8\). Многомерная точная геометрия и глобальный max-min открыты.

**Почему трудно.** Нужна символическая алгебраическая геометрия (результанты, дискриминанты, компоненты связности) и полуалгебраическая оптимизация; сетка не заменяет доказательство.

**Задача другой модели.**
```
Дано: H конечно; рациональные a_h(θ)=P_h(θ)/Q_h(θ), θ∈R^d, степени ≤d0.
C={θ: ∃h≠h', a_h(θ)=a_h'(θ)}; δ(θ)=min_{h≠h'}|a_h(θ)-a_h'(θ)|;
max-min дизайн — max_θ δ(θ).
Вопросы:
1. Для d=2, k=4, степени ≤2 дай точный алгоритм построения C и числа
   компонент связности; докажи верхнюю границу числа компонент через d,k,d0.
2. Для ленивого ведущего f=α(q+1)/(1+αq), четырёх предсказаний
   f, α, 1/2, 2/3 найди точный max-min по (α,q)∈(0,1)^2; сравни с
   однопараметрическим 0.140388; оптимум на q=1?
3. Свяжи критерий с T-optimal design (Atkinson–Fedorov): что здесь нового
   для дискретных поведенческих гипотез, а что известно.
Нужны доказательства и алгоритмы; численная сетка — только иллюстрация.
```

**Что принести.** Алгоритм/границу для \(C\), точный max-min для двух параметров, сравнение с T-optimal.

## 3. Формальная семантика реляционных ловушек

**Что есть.** Исходная линия проекта выделяет **реляционную композицию**: корова производит молоко, человек пьёт молоко, но корова обычно пьёт воду; Моисей и ковчег. Сейчас это в основном проза и таксономия; формальной семантики, отделяющей ассоциативную подстановку от связывания ролей, нет.

**Почему трудно.** Нужна типизованная семантика (роли, аргументы, события), теорема о недопустимости вывода и минимальные пары, различающие механизмы; это не решается ещё одним списком примеров.

**Задача другой модели.**
```
Построй формальную семантику реляционных ловушек.
Дано: истинные факты produce(cow,milk), drink(human,milk), drink(cow,water);
ошибочный вывод drink(cow,milk).
1. Задай типизованный язык (сущности, роли, отношения, события) и правило
   композиции, сохраняющее роли.
2. Определи два механизма ошибки: (A) ассоциативная подстановка
   (cow→milk по силе связи) и (B) неверное связывание ролей (агент drink
   подменяется производителем молока). Докажи, какие выводы недопустимы.
3. Построй минимальную диагностическую батарею, различающую A, B и простое
   незнание; предскажи профили ответов для cow/milk, Moses/ark и контроля.
4. Сформулируй теорему о недопустимости вывода produce(x,y)∧drink(z,y)⇒
   drink(x,y) и контрмодель.
Нужны формальная грамматика/семантика, теоремы и проверяемые предсказания,
а не только таксономия.
```

**Что принести.** Формальный язык, теорему/контрмодель, минимальные пары, профили ответов.

## 4. Общая теория достаточности представления и диагностики

**Что есть.** Достаточность = уточнение разбиения = нулевая условная энтропия; идентифицируемость = дискретность разбиения; доминирование вопросов; collision set; блочная диагональ Фишера при target-invariance. Это набор специальных результатов и рамка, а не общая теорема.

**Почему трудно.** Нужно объединить теорию измерений, информацию и планирование экспериментов; определить количественную меру, применимую и к субъекту, и к диагностику; не свести всё к тавтологии «условная энтропия равна нулю».

**Задача другой модели.**
```
Формализуй общую теорию контринтуитивной диагностики.
Дано: пространство ситуаций X; представление Z=g(X); вопрос Q с ответом
f_Q; множество гипотез H; семейство проверок T_θ.
Определи достаточность (уточнение разбиения), идентифицируемость,
collision set, доминирование вопросов.
1. Докажи общую теорему двойственности между достаточностью Z для Q и
   идентифицируемостью H проверкой T_θ.
2. Дай количественную границу, связывающую H(f_Q|Z) и H(H|T_θ), или докажи,
   что такой общей границы нет; предложи аксиомы диагностической меры.
3. Охарактеризуй, когда вопрос диагностичен, а когда является контролем.
4. Покажи Monty-пункт и реляционную ловушку как частные случаи.
Нужна теорема/аксиоматика, а не очередная рамка.
```

**Что принести.** Теорему двойственности, границу/аксиомы, характеристику диагностичности, приложения.

## 5. Робастный minimax для компактных классов стратегий

**Что есть.** Для конечного класса аналитических стратегий collision set конечен и робастный зазор положителен (пример: \(0{,}020\)); непрерывный интервал \(\delta\in[0{,}02,0{,}20]\) даёт \(0{,}0099\); неограниченная пятая \(\alpha+\delta\) обнуляет зазор. Общий компактный класс не охарактеризован.

**Почему трудно.** Бесконечномерный minimax, топология класса, цена робастности; нужно отделить компактные классы с положительным зазором от классов, где противник покрывает все точки.

**Задача другой модели.**
```
Дано: класс P аналитических стратегий p(α) на (0,1); робастный зазор
max_α min_{p≠q}|p(α)-q(α)|.
1. Охарактеризуй компактные классы P, для которых зазор положителен;
   докажи теорему существования/цены робастности.
2. Покажи, почему неограниченный класс α+δ (δ∈(0,1−α)) даёт ноль;
   можно ли его регуляризовать, чтобы получить положительный зазор.
3. Дай контрпример к положительности для некомпактного класса без
   тривиального совпадения стратегий.
Нужны теоремы и контрпримеры, не только численная сетка.
```

**Что принести.** Теорему для компактных классов, регуляризацию/контрпример, цену робастности.
