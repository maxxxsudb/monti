## Исправления присланного clean_master

### 1. Полная готовность и отсутствующий пакет

Начальная декларация «все ВП-2/3/4 полностью решены» снята.
`master_verification_suite.py` не предоставлен и не найден в проекте.
Не подтверждаем количество 13 122 и формулировки «проверено в §... скрипта».
Добавлен собственный исполняемый файл с фактическим выводом.

### 2.2. Минимальность вмешательств

Из исходной таблицы следует: для пяти классов достаточно I_Z,I_R,I_Z+I_R.
Три бинарные пробы необходимы по числу кодов. Четвёртая не требуется.
Отдельный каталог совместных сбоев может потребовать другую батарею.

### 2.3. Масштаб TV

Порог ρ<1−α не следует из абсолютного TV-возмущения.
Контрпример p0=0,1,p1=0,2,ρ=0,1 разрешает успех 0,2 вместо заявленного
предела 0,11. Рабочая граница: зазор ≥(Δ0−a−b)_+ для наблюдаемых
профилей. Формула (1−α−ρ)Δ0 сохранена только при явно иной модели
смеси «исправленный/неисправленный» с вероятностями переключения.

### 3.1. Слепая зона и статистическая скорость

Равенство средних не означает равенства распределений. Нужен критерий
Kf=Kh, а не только f=h. Точный minimax-порядок для всех каналов нельзя
определять только через TV: в редком раскрывающем канале информативная
выборка имеет размер порядка nd. Приняты только доказанные верхние
оценки конкретной оценки по среднему и критерий идентифицируемости.

### 3.2–3.4. Бисекция, серая зона и смысл Монти

Бисекция имеет указанную гарантию при оракуле сравнения и наличии
единственной границы. При шуме нужны правило ранней остановки и отступ.
Липшицевость даёт сеточную точность по значению; без условий пересечения
уровня не гарантирует точную геометрию всех островов.
Область A_rule={1} для ответа 2/3 на вопрос о ТИПЕ ведущего неверна:
при α=1 правильный ответ о типе равен 1. Совпадение 2/3 при α=1/2
является численным совпадением, а не применимостью классического вывода
о местоположении приза.
Заявление о трёх независимых наблюдаемых метриках ослаблено:
вес w на совпавших каналах неидентифицируем, отношение post/pre может
быть >1, а изменение частоты не равно индивидуальной устойчивости.

### 4.4. Универсальная нижняя граница UNKNOWN

Для L=0,8,η=0,1,p0=0,1+0,8x достаточно двух точных крайних проб:
любая допустимая q, совпавшая на концах, совпадает всюду.
Это опровергает универсальные «минимум пять». Палатка на непостоянном
эталоне может увеличить константу Липшица до 2L.
Граница сохранена для постоянного эталона с запасом диапазона значений,
как пример худшего случая; не как утверждение о каждом каталоге.

### 4.3. Компактность, вычислимость и девятиточечный пример

Компактность классов не предоставляет вычислимый оракул расстояния.
Общая верхняя гарантия UNKNOWN условна на возможность такого расчёта.
Трубки в C([0,1]) без общей регулярности не обязаны быть компактными.
У p_adv константа Липшица 52/25, а не ≤2.
Сетка из девяти точек обнаруживает именно этот пример; универсальная
гарантия с L=52/25,η=1/10 требует 43 точки по приведённой формуле.
Не переносим успех на одной атаке на все неизвестные стратегии.
Утверждение об O(k−1) пробах отбора одного из бесконечных классов
также снято: пример N+1 для двух классов его опровергает.

### 8.2. Поточечный свидетель недостаточности

Если один слой g содержит разные истинные ответы, механизм ошибается
хотя бы в одной точке слоя, но может быть верен в выбранной x0.
При калибровке хотя бы одной точки каждого слоя сохраняется глобальная
эквивалентность «существует недостаточный слой ⇔ существует ошибка».

### 1.4. «Теорема о чётности»

Разные k: общая формула доказана в PROTOCOL-THEORY.md через границы
положительных вероятностей. Нечётный n и общий k: формула тоже доказана
достижением той же верхней границы. Для чётного n получены достижимые
ветви и конечное подтверждение до 12, но нет полноценного исключения
остальных составов. Формула помечена гипотезой, не общей теоремой.
