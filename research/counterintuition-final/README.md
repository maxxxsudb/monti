# Контринтуитивность и диагностика: действующий свод

20 октября 2026. Результат сверки `solution-hard-new-2.md`, материалов
`20-10-27 codex`, нового `counterintuitiveness_and_diagnostics_clean_master.md`
и приложенной к нему рецензии. Этот каталог — точка входа и действующие
формулировки. Исходники сохраняются как история, их заявления о полной
готовности не переносятся автоматически.

## Главное

**Дополнение 21 октября:** [проверка новых решений и три законченных
доказательства](../NEW-SOLUTIONS-REVIEW-2026-10-21.md) — точный порог
различимости в модели исправлений, полная цена поиска монотонной
границы и шумовая нижняя граница UNKNOWN. Также уточнён короткий
физический кандидат с лампочкой. Общие задачи за пределами этих моделей
остаются открытыми.

Есть готовая короткая задача: одинаковая белая фотография даёт разные
ответы, если поменять одно слово в правиле остановки. Для пяти билетов
это **10/11 против 1/2**; при неизменном априоре 1/4 — **10/13 против 1/4**,
то есть меняется даже наиболее вероятная коробка.

Математическое ядро этого примера проверено. Предсказание, что человек
обязательно ошибётся, и научная новизна сюжета пока не установлены.
Восстановление реальных внутренних причин ошибки по ответам остаётся
отдельной исследовательской задачей.

## Воспроизведение

Из корня репозитория:

```powershell
python sims/protocol_loss_verify_20261020.py
python "research/20-10-27 codex/protocol_enumeration.py" --max-n 5
python "research/20-10-27 codex/deep_five_tasks_verify.py"
python sims/new_solutions_verify_20261021.py
```

Независимый скрипт проверяет 210 вероятностей через упорядоченные
траектории, 676 случаев ковариационного критерия, три режима ограничений
перебора, общую формулу-кандидат до n=12, минимальную батарею вмешательств
и обе модели Q1 точным DP до T=5.

`master_verification_suite.py`, на который ссылается присланный master,
в предоставленных материалах и репозитории не найден. Заявление о
13 122 выполненных им проверках не подтверждено. Наш скрипт не заменяет
его под прежним именем и не подтверждает все его заявленные результаты.

## Следующий содержательный шаг

[Оставшиеся задачи для передачи другой модели](../HARD-TASKS-REMAINING-2026-10-20.md):
причинный диагноз, предсказание границ ошибок, цена робастной батареи
и конструктор новых простых парадоксов.

Сначала предъявить версии задачи независимым решателям, фиксируя первый
ответ до подсказок. Затем проверить перенос на новые формулировки.
Если устойчивой предсказуемой ошибки нет, остаётся корректная учебная
задача и полезная теория отбора; сильная контринтуитивная ловушка ещё
не получена. Более сложная математика сама по себе этого не меняет.
