# Контринтуитивность и диагностика: действующий свод

20 октября 2026. Результат сверки `solution-hard-new-2.md`, материалов
`20-10-27 codex`, нового `counterintuitiveness_and_diagnostics_clean_master.md`
и приложенной к нему рецензии. Этот каталог — точка входа и действующие
формулировки. Исходники сохраняются как история, их заявления о полной
готовности не переносятся автоматически.

## Главное

**Текущий фокус, 25 октября:** [вычислительный барьер и выбор после отказа считать](../COMPUTATION-BARRIER-CURRENT-2026-10-25.md).
Прежний [пилот на 40 участниках](../CHEST-PILOT-40-2026-10-21.md) подготовлен,
но его немедленный запуск отложен; сильная ловушка ещё не установлена.
[Закрытие геометрии огибающих с доверительными интервалами](../CORRECTED-CHEST-REVIEW-AND-NOISY-ENVELOPES-2026-10-21.md)
не решает универсальную стохастическую R3 и не требует 25 тысяч вопросов для пилота.

**Новый INSIGHT:** [точный двухточечный оптимум обнаружения постоянной смеси и контроль переноса](../DEEP-NEXT-REVIEW-2026-10-21.md).
Различать геометрический зазор, число ответов и установленную силу ловушки.

**Последнее завершение:** [два глобальных оптимума сундуков и точный бюджет фиксированной схемы N2](../EASY-CLOSURES-2026-10-21.md).
Рациональные точки требуют 25 082 ответа, оптимальные — 24 751.
[Простой кандидат с чистыми процентами](../FOCUS-PARADOX-FIVE-COINS-2026-10-21.md).

**Новый результат N2:** [независимое доказательство оптимального порядка](../N2-MAJORITY-AND-BUDGET-2026-10-21.md)
через контролируемый отсев и большинство. Практическая верхняя гарантия
снижена далее до 24 751 ответа при η=.2,ω=.2,β=.05; универсальная точная конечная цена неизвестна.
[Проверка нового продолжения](../FOCUS-FOLLOWUP-REVIEW-2026-10-21.md)
даёт полный критерий сундуков и исправляет VOI; общий R3 остаётся открытым.

**Последнее дополнение:** [проверка двух пакетов всех HARD](../ALL-HARD-PACKAGES-REVIEW-2026-10-21.md).
Приняты общий оптимум N1 и тождество суммы квадратов; точный порядок
N2 в том присланном пакете не был закрыт; выше приведено последующее собственное доказательство. Общий R3 остаётся открытым. Получен частный крайний тест с ценой
Θ(η⁻¹log(1/β)) для Bernoulli-оракула и [новый фокус сундуков](../FOCUS-PARADOX-CHEST-2026-10-21.md).

**Новые принятые решения:** [оптимальная тройка, проверяемый UNKNOWN и четырёхпробный тест](../NEXT-TASKS-SOLUTION-REVIEW-2026-10-21.md).
Исходный скрипт воспроизведён; распределение повторов дополнительно
сертифицировано рациональными интервалами. Экспериментальная часть
пока остаётся подготовленным пакетом, а не измерением ловушки.

**Текущий маршрут:** [цель, новые выводы и критерии следующего этапа](../RESEARCH-TRACK-AND-NEXT-RESULTS-2026-10-21.md).
Добавлены граница ошибки через недостающий контраст, две пробы для
одного постоянного режима и три — для постоянной смеси. Эти выводы
условны относительно класса ответов; психологическая сила требует данных.

**Закрытие 21 октября:** [глобальная формула коробок и точный minimax](../GLOBAL-BOX-AND-MINIMAX-2026-10-21.md).
Формула общего лимита доказана для всех n в объявленной грамматике;
риск фиксированного девятиответного эксперимента сертифицирован точно:
**4,2788194213%**.

**Дополнение 21 октября:** [проверка новых решений и три законченных
доказательства](../NEW-SOLUTIONS-REVIEW-2026-10-21.md) — точный порог
различимости в модели исправлений, полная цена поиска монотонной
границы и шумовая нижняя граница UNKNOWN. Также уточнён короткий
физический кандидат с лампочкой. Общие задачи за пределами этих моделей
остаются открытыми.

Есть готовая короткая задача: одинаковая белая фотография даёт разные
ответы, если поменять одно слово в правиле остановки. Для пяти билетов
это **10/11 против 1/2**; при неизменном априоре 1/4 — **10/13 против 1/4**,
то есть меняется даже наиболее вероятная коробка.

Математическое ядро этого примера проверено. Предсказание, что человек
обязательно ошибётся, и научная новизна сюжета пока не установлены.
Восстановление реальных внутренних причин ошибки по ответам остаётся
отдельной исследовательской задачей.

## Воспроизведение

Из корня репозитория:

```powershell
python sims/protocol_loss_verify_20261020.py
python "research/20-10-27 codex/protocol_enumeration.py" --max-n 5
python "research/20-10-27 codex/deep_five_tasks_verify.py"
python sims/new_solutions_verify_20261021.py
```

Независимый скрипт проверяет 210 вероятностей через упорядоченные
траектории, 676 случаев ковариационного критерия, три режима ограничений
перебора, общую формулу-кандидат до n=12, минимальную батарею вмешательств
и обе модели Q1 точным DP до T=5.

**Обновление 21 октября:** `master_verification_suite.py` и сертификат
получены, исходный запуск воспроизведён. 13 122 ковариационные проверки
подтверждены. [Аудит покрытия](../MASTER-VERIFICATION-AUDIT-2026-10-21.md)
показывает, какие другие утверждения проверяются лишь частично или
просто печатаются. Прежние математические исправления сохраняются.
