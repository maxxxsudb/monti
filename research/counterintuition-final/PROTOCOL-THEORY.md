# Потеря протокола: доказательства и границы генератора

Обозначения B/W везде означают остановку на первом чёрном/белом,
с обязательной остановкой не позже общего лимита k. E — белый последний
билет. Это устраняет путаницу букв А/Б, которые менялись между исходниками.

## 1. Критерий значимости протокола

Пусть S конечно, μ_s>0, Y=y(S), a_s=K0(E|s), b_s=K1(E|s).
Ненулевые неотрицательные векторы a,b имеют нормировки A=Σμa>0, B=Σμb>0.
Для данного априора распределения Y после E совпадают тогда и только
тогда, когда для каждого z:

    B Σ_{y(s)=z} μ_s a_s = A Σ_{y(s)=z} μ_s b_s.

Для всех априоров полного носителя эквивалентный критерий:

    a_s b_t = b_s a_t для всех y(s)≠y(t).

Доказательство: раскрыть разность из первого равенства в однородный
квадратичный полином по μ. Его межслойные коэффициенты должны быть нулём;
внутрислойные члены сокращаются. Обратное следует из того же раскрытия.

Структурно это означает: либо a=λb, λ>0, либо объединение их носителей
лежит в одном слое Y. Эти случаи могут пересекаться; слово «ровно одно»
в присланном master лишнее. Постоянная цель всегда относится ко второму.
Равенство апостериоров всего S требует пропорциональности a,b; равенство
одной цели при конкретном априоре допускает компенсацию внутри слоёв.

Для бинарного Y введём

    ρ_s=μ_s(a_s+b_s)/(A+B), t_s=b_s/(a_s+b_s), q=B/(A+B).

Состояния с a_s+b_s=0 опускаются. Тогда

    P1(Y=1|E)−P0(Y=1|E) = Cov_ρ(Y,t)/[q(1−q)].

Доказательство: P1=Eρ[Yt]/q, P0=Eρ[Y(1−t)]/(1−q); вычесть.
Меняется ответ тогда, когда относительное изменение отбора связано
с целью. Самого факта различия протоколов недостаточно.

## 2. Вероятность и действие — разные потери

Если забытый протокол оставляет возможными вероятности l≤u, то

    min_r max(|r−l|,|r−u|)=(u−l)/2, r*=(l+u)/2.

Для покупки билета за c с выплатой Y сожаление равно нулю, если обе
вероятности лежат по одну сторону c. Если l<c<u, то:

    детерминированное minimax-сожаление = min(c−l,u−c);
    рандомизированное = (c−l)(u−c)/(u−l).

Во втором случае покупать с вероятностью (u−c)/(u−l).
Это получается уравниванием двух сожалений t(c−l), (1−t)(u−c).
Без заданного распределения протокола это minimax, а не байесовский posterior.

## 3. Усиление через априор и его цена

Если E гарантировано при H, а при L имеет вероятность s для B и 1 для W,
при P(H)=π имеем

    pB=π/[π+(1−π)s], pW=π.

Наиболее вероятная коробка меняется тогда и только тогда, когда

    s/(1+s) < π < 1/2.

Дифференцирование pB−π даёт единственный максимум:

    π*=√s/(1+√s), max(pB−pW)=(1−√s)/(1+√s).

Предел при s→0 равен 1. Но при этом P(E|B,π*)=√s→0.
Большой условный разрыв достигается на всё более редком наблюдении;
это не бесплатный почти стопроцентный выигрыш на всех испытаниях.

Для пятибилетного переворота π=1/4 при независимой симметричной ошибке
передачи цвета ε:

    pB(ε)=10(1−ε)/(13+14ε), pW(ε)=1/4.

Строгий переворот сохраняется ровно при ε<7/34. На границе pB=1/2.

## 4. Скрытый случайный протокол и правильное число по неверному правилу

Если B/W выбираются независимо честной монетой и не сообщаются,
усреднять нужно правдоподобия до нормирования. При равном априоре коробок:

| Число билетов / лимит | Байес | «Один случайный билет» | Среднее готовых ответов |
|---|---:|---:|---:|
| 3 / 2, L=2 белых | 3/5 | 3/5 | 5/8 |
| 5 / 3, L=3 белых | 20/31 | 5/8 | 31/44 |

Для k=2 среднее AND/OR равно среднему двух индикаторов, поэтому
½[P(E|B2)+P(E|W2)]=w/n. Это маскирует неправильную эвристику.
Правильный posterior самого B после E: 2/5 для трёх и 11/31 для пяти.

Ответы на этот дополнительный вопрос у ошибочных механизмов должны
задаваться отдельно: из одного неправильного правила для коробки нельзя
логически вывести, что человек обязательно ответит 1/2 про протокол.
В пятибилетном случае три идеальные численные модели уже разделяются
основным вопросом, но минимальный зазор всего 5/248 ≈2,02 п.п.
При шуме или округлении одного вопроса может оказаться недостаточно.

## 5. Грамматика и точная конечная минимальность

Две коробки по n билетов, составы 0≤w0<w1≤n, равный априор, цель — w1.
Случайные извлечения без возвращения. F_k — ровно k извлечений; W_k/B_k —
до первого соответствующего цвета либо до k. Сообщается только последний
цвет. В каждом сравниваемом протоколе E должно быть возможно при обоих типах.

    q(F_k,w)=w/n,
    q(W_k,w)=1−C(n−w,k)/C(n,k),
    q(B_k,w)=C(w,k)/C(n,k),
    p=q(w1)/[q(w0)+q(w1)].

Для C(a,k) при a<k используется ноль. Сжатие по вектору q —
наблюдательная эквивалентность для этого сообщения, а не изоморфизм
полных скрытых траекторий.

| n | Разные лимиты разрешены | Общий k, любые F/W/B | Общий k, только смена W↔B |
|---:|---:|---:|---:|
| 1 | 0 | 0 | 0 |
| 2 | 1/6 | 1/6 | 0 |
| 3 | 1/4 | 1/4 | 1/4 |
| 4 | 5/14 | 24/77 | 24/77 |
| 5 | 9/22 | 9/22 | 9/22 |
| 6 | 19/42 | 40/91 | 40/91 |
| 7 | 17/36 | 17/36 | 17/36 |
| 8 | 69/142 | 55/114 | 55/114 |

Первые пять строк независимо проверены перебором упорядоченных
извлечений; остальные — точным перебором комбинаторных ядер.
В данной грамматике три билета минимальны для разрыва ≥1/4,
пять — для разрыва ≥0,4. Это не минимальность по всем возможным механизмам.

Число сравнений зависит от канонизации: глобально одинаковые каналы
могут стать одинаковыми лишь на выбранной паре составов. Счётчики
53/36 для n=4 или 360/225 для n=6 не являются противоречием оптимумов.

## 6. Что доказано для любого n, а что пока проверено конечно

Пусть Cn=C(n,⌊n/2⌋). В грамматике с разными лимитами максимум равен

    Δcross(n)=(Cn−1)/[2(Cn+1)], n≥2.

Доказательство верхней границы: каждое положительное q≥1/Cn,
q(w1)≤1, а q не убывает по w. Поэтому posterior лежит между 1/2 и
Cn/(Cn+1). Граница достигается при w0=kB=⌊n/2⌋, w1=n и kW=n−w0+1.
Для нечётного n=2m−1 можно взять w0=kB=kW=m; тот же максимум
достигается при общем лимите. При n=2 общий лимит F2/W2 также даёт 1/6.

Для чётного n=2m≥4 в master предложено равенство

    Δsame(2m)=max{C(C−2)/[(C+1)(2C−1)], (C'−1)/[2(C'+1)]},
    C=C(2m,m), C'=C(2m,m+1).

Обе ветви действительно достигаются: w0=k=m либо w0=k=m+1, w1=n.
Однако присланное доказательство не исключает все остальные пары
составов и k: оптимизация сразу ограничивается этими конструкциями.
Асимптотическое сравнение ветвей не восполняет этот пропуск.
**Статус общей формулы для чётных n — гипотеза; подтверждена точным
перебором n=4,6,8,10,12.** Общая верхняя граница Δcross доказана.
Точка смены ветвей n=8 подтверждена на этих конечных случаях.

Минимальность меняется при разрешении информированного выбора,
возвращения билетов, произвольной рандомизации или другого априора.
Никакой из этих вариантов не опровергает таблицу для указанной грамматики.
