# Задание07. Конкуренция коротких правил и честный UNKNOWN

Репозиторий https://github.com/maxxxsudb/monti . Исходный кандидат3+3
имеет ключи для (S,убрать),(S,вернуть),(G,убрать),(G,вернуть):
own,other,other,own; зазор каждой клетки1/9.
Игнорирование returned с восстановлением true даёт other,other,own,own;
восстановление false — own,own,other,other.
Проверка: `sims/single_silver_certificates_20261025.py`.

Задача — не считать первый произвольно выбранный неверный путь доминирующим.

1. Реализовать библиотеку конкурентов: результаты06 при наличии,
   оба восстановления, константы, дешёвое правильное решение. Ручные
   и обученные правила помечать отдельно. Оценивать минимум стоимости
   правильного решения только внутри объявленной библиотеки.
2. Вычислять массу каждого ответа при заданных весах. Весам указывать
   происхождение: результат обучения/заданный prior/неизвестны.
3. Для множества допустимых весов W проверить устойчивое доминирование
   неверного ответа: min_W[его масса−масса конкурента]>0 для каждого
   конкурента. Если W — весь симплекс и есть правила с разными ответами,
   устойчивого доминирования нет. Возвращать UNKNOWN.
4. Проверить частный результат: веса двух противоположных правил λ,1−λ;
   при λ∈[l,u] ошибка устойчива только l>1/2. Не выдавать придуманное W
   за измеренное распределение людей. Дать чувствительность по W.
5. Выдать для каждого кандидата профиль всех четырёх клеток и область
   весов, меняющую прогноз. Отделить устойчивость к перефразированию
   от устойчивости к изменениям протокола.

Выход: `sims/competing_strategies/`,
`research/results-2026-10-25/07-COMPETING-INTUITIONS-RESULT.md`.
Успех: проверяемый прогноз или честная неидентифицируемость; не нужно
обязательно найти «сильную» ошибку. Не собирать человеческие данные в этой задаче.
