## 1. Теорема о потере протокола и генератор простых парадоксов

**Приоритет: первый. Прямой путь к исходной цели.**

**Дополнение 20 октября:** начальный этап выполнен и записан в
[PROTOCOL-LOSS-HANDOFF-2026-10-20.md](PROTOCOL-LOSS-HANDOFF-2026-10-20.md).
Выведены критерии сохранения ответа, minimax для вероятности и действия.
Получен кандидат «белый билет сразу / дойти до белого»: **3/4 против 1/2**,
с областью параметров и минимальностью только внутри узкого семейства.
Общий генератор и сила ловушки ещё не проверены. **Для передачи другой
модели использовать обновлённое задание из §4 файла передачи**, а не
запускать исходную задачу заново.

**Что есть.** Один наблюдаемый финал может получаться разными способами отбора. Для двух протоколов уже известна точная ошибка смешивания условных ответов с априорными весами:

    p(α) − q(α) = α(1−α)(a−b)(u−v) / [αa+(1−α)b].

Есть примеры «перепись/гонка», защищённый выбор/прошедший отбор, дождь/крыша. Не хватает конструктора, который из структуры потери информации выдаёт короткую задачу с доказанным механизмом и сильным кандидатом на интуитивную ошибку.

**Почему это может изменить проект.** Вместо ручного перебора историй получим способ систематически строить пары задач: внешне почти одинаковых, но с разными правильными ответами. Можно будет искать минимальный носитель парадокса.

**Почему трудно.** Разные ответы у двух протоколов получить легко. Трудно одновременно обеспечить простой сюжет, честные условия, одинаковый поверхностный вид и устойчивость к небольшим изменениям параметров. Большой разрыв вероятностей сам по себе не означает сильную человеческую ловушку.

**Задача другой модели.**
```text
Построй конструктивную теорию простых ловушек, возникающих при потере
информации о протоколе наблюдения.

Дано: конечное пространство скрытых состояний S с априором μ;
цель Y=y(S); два явно известных протокола K0(o|S), K1(o|S);
событие наблюдения O=o, имеющее положительную вероятность при обоих.
Полная задача сообщает протокол и наблюдение. Поверхностное
представление g сохраняет наблюдение, но стирает протокол.

1. Выведи необходимые и достаточные условия
   P0(Y|o)=P1(Y|o) и условия различия; отдельно разбери равенство
   для одного априора и для всех априоров полного носителя.
   Покажи, что меняется, когда цель — только одна функция Y,
   а не всё скрытое состояние.
2. Для бинарной Y обозначь ответы p0,p1. Докажи точную
   minimax-ошибку единого численного ответа, зависящего только от g,
   относительно двух протоколов. Затем реши аналог для решения
   "купить билет за c / отказаться", выплата равна Y.
   Отдели ошибку вероятности от реального сожаления по действию.
3. Задай конечную грамматику допустимых механизмов отбора:
   случайное исключение, осведомлённое исключение, защита выбранного,
   остановка после k событий, наблюдение в фиксированный момент.
   Укажи ограниченные размеры состояния и число шагов.
   Предложи точный перебор с устранением изоморфных переименований,
   который находит минимальные пары с |p0−p1|≥1/4.
   Минимальность докажи хотя бы в выбранной конечной грамматике.
4. Дай один лучший кандидат: две версии условия по 60–100 слов,
   различающиеся одним правилом; точное решение, явную предполагаемую
   эвристику, контрольную версию и объяснение для 5–7 класса.
   Никаких пропущенных правил отбора и скрытого изменения цели.
5. Найди область параметров, где разрыв сохраняется, и объясни,
   почему кандидат не является только переименованием классического
   Монти Холла в рамках указанной модели изоморфизма.

Не выдавай предполагаемый неверный ответ за установленную реакцию
людей. Не называй найденный сюжет неизвестным без проверки приоритета.
```

**Что принести.** Теорему о сохранении/потере ответа, точный конечный генератор и **один готовый простой парадокс-кандидат** с контрольной парой.

**Что не считать решением.** Ещё одну формулу Байеса без нового кандидата; другую декорацию тех же трёх дверей; «человек точно ошибётся» без испытания.

## 2. Теорема о различении причин ошибки с помощью вмешательств

**Приоритет: второй. Центральный пробел в нашей диагностике.**

**Что есть.** Потеря существенной информации, неверное правило и ошибка исполнения могут давать одинаковые ответы. Пересказ не является прямым измерением внутреннего представления. Для совпадающих функций поведения обычная батарея бессильна.

**Почему это может изменить проект.** Получим границу между «мы заметили ошибку» и «мы имеем основания назвать её механизм». Если механизм удаётся различить, можно адресно искать следующие ловушки и проверять объяснение.

**Почему трудно.** Подсказка одновременно меняет внимание, представление и способ решения. Произвольные скрытые механизмы можно перепараметризовать так, что все наблюдения совпадут. Нужны явные ограничения на то, что именно делает вмешательство.

**Задача другой модели.**
```text
Построй теорию идентификации причин ошибки, а не только ответных профилей.

Дано: задача X, скрытое представление Z=g(X), выбранное правило R,
вычисленный ответ A=ψ(Z,R,U), где U — шум исполнения.
Диагност наблюдает X, ответ A и, при запросе, пересказ S.
S задан отдельным каналом P(S|X,Z,R,A); НЕ полагать S=Z.

Рассмотри три семейства:
L — существенное отношение теряется при построении Z;
W — оно доступно, но выбирается неподходящее правило;
E — представление и правило корректны, ошибка возникает при исполнении.

1. Докажи наблюдательную неидентифицируемость без ограничений:
   построй разные механизмы с одинаковыми распределениями (A,S)|X.
2. Задай минимально достаточные структурные ограничения и меню
   вмешательств: выделить отношение; назвать условие применимости
   правила; снять вычислительную нагрузку. Для каждого вмешательства
   явно укажи, какие каналы оно может менять, а какие сохраняет.
   Эти ограничения — допущения модели, а не факты о психике.
3. Докажи необходимое и достаточное условие различимости семейств
   по распределениям ответов после доступных вмешательств.
   Реши один небольшой нетривиальный класс полностью:
   минимальная батарея, доказательство минимальности, шум.
4. Ослабь идеальность вмешательств: разреши побочное изменение
   других каналов с бюджетом ρ в TV. Найди порог ρ,
   после которого диагноз больше не гарантирован.
5. Переведи результат в одну конкретную задачу о протоколе отбора
   и её контрольные варианты. Укажи наблюдение, которое опровергнет
   предлагаемую интерпретацию механизма.
6. Отдельно учти обучение от первого вопроса: что идентифицируется
   на свежих независимых участниках, а что — в одном диалоге?

Если без дополнительных предпосылок причинный диагноз невозможен,
это полноценный результат. Не заменяй доказательство таблицей
профилей, выбранных так, чтобы они заранее различались.
```

**Что принести.** Теорему невозможности, достижимую при явных допущениях теорему идентификации и небольшой эксперимент, способный опровергнуть диагноз.

**Что не считать решением.** «После подсказки исправился — значит забыл условие». Исправление может иметь несколько причин.

## 3. Геометрия серой зоны: как находить границу применимости, которую субъект не различает

**Приоритет: третий. Переход от отдельных задач к поиску целого семейства ловушек.**

**Что есть.** Наша рабочая гипотеза: знакомые признаки запускают полезный способ решения, но его точные условия применимости представлены грубо. Субъект может знать правило и не иметь устойчивой границы его использования.

**Почему это может изменить проект.** Вместо измерения частоты ошибок на готовой подборке научимся находить область будущих ошибок и предсказывать их на ещё не показанных задачах.

**Почему трудно.** Граница зависит от контекста, а изменение ответа не обязательно означает переключение правила. Двух правильных крайних ответов недостаточно для правильной зависимости между ними. Без регулярности поведения конечные измерения не дают гарантий между точками.

**Задача другой модели.**
```text
Разработай метод обнаружения невидимой для субъекта границы
применимости правила.

Дано: параметризованное семейство полностью определённых задач
x(θ,c), θ∈[0,1]^d, c — один из конечного набора контекстов.
Известны правильный ответ f(θ) и ответ конкретной эвристики h(θ).
Контекст c по определению не меняет f.
Задай отдельно:
  A0={θ:f(θ)=h(θ)} — совпадение численных ответов;
  A_rule — область обоснованной применимости правила.
Эти множества НЕ обязаны совпадать.

Вне A0 начни с наблюдаемой модели:
  P(A∈·|θ,c)=[1−w(θ,c)]K_f(·|θ)+w(θ,c)K_h(·|θ),
где шумовые ядра известны, w неизвестна.
Смысл w — вес ответного режима внутри этой модели,
не автоматически вероятность внутреннего мыслительного процесса.

1. Докажи, где w идентифицируется, а где нет.
   Выведи зависимость точности оценки от расстояния между K_f и K_h.
   Объясни, почему точки совпадения ответов плохо диагностируют
   знание условия применимости.
2. При явном ограничении регулярности w найди верхнюю и нижнюю
   границы числа запросов для локализации области w≥τ с точностью η.
   Начни с d=1 и монотонного w; затем укажи, что ломается без
   монотонности. Не предполагай резкую ступеньку без обоснования.
3. Раздели три наблюдаемых характеристики:
   распространённость неправильного режима;
   величину ошибки/сожаления;
   устойчивость после нейтрального напоминания об условиях правила.
   Зафиксируй распределение задач, относительно которого они измеряются.
   Не вводи произвольную взвешенную сумму как универсальную шкалу.
4. Построй проверку влияния контекста на w при неизменном f:
   рандомизация, независимые пробы, контроль порядка и переноса.
   Предусмотри проверку адекватности самой двухрежимной модели.
5. Дай одно семейство из расширения Монти Холла с непрерывным θ:
   выведи f,h,A0,A_rule; предложи адаптивный выбор проб;
   укажи заранее отложенные задачи для проверки предсказаний.

Результат должен предсказывать ошибки на новых параметрах,
а не только хорошо описывать уже увиденные ответы.
```

**Что принести.** Теорему идентифицируемости и сложности запросов для ограниченного класса, метод поиска серой зоны и проверяемый прогноз на новых задачах.

**Что не считать решением.** Подгонку плавной кривой по готовым ошибкам; отождествление любой уверенной ошибки с одним механизмом.

## 4. Минимальная робастная батарея с правом признать «механизм неизвестен»

**Приоритет: четвёртый. Делает диагностику пригодной за пределами заранее выбранных четырёх моделей.**

**Что есть.** Конечное число попарно непересекающихся компактных классов непрерывных ответных функций можно разделить конечной батареей с положительным зазором. При общей липшицевости уже есть грубая оценка через сетку; при независимом ограниченном шуме — оценка числа повторений.

**Почему это может изменить проект.** Получим короткую проверку с гарантией и честным отказом от диагноза. Сейчас классификатор легко «обнаруживает» одну из наших гипотез просто потому, что других вариантов ему не предложили.

**Почему трудно.** Разделение известных классов не гарантирует распознавания неизвестного. Неизвестная функция может совпасть на всех заданных вопросах и отличаться в другом месте. Адаптивность может помогать, но не устраняет эту проблему без ограничений на альтернативы.

**Задача другой модели.**
```text
Реши задачу короткой робастной диагностики с открытым набором причин.

Дано: Θ=[0,1]; известные непустые компактные классы
P1,...,Pk⊂C(Θ,[0,1]), попарно разделённые в sup-норме на Δ>0.
Все функции L-липшицевы. Стратегия p неизменна в эксперименте.
Вопрос в θ даёт независимый ответ Y∈[0,1] со средним p(θ);
известна положительная стоимость c(θ), ограниченная сверху и снизу.
Гипотеза UNKNOWN:
  dist∞(p,∪Pi)≥η,
причём неизвестные p тоже принадлежат заданному L-липшицеву классу.
Промежуточную зону 0<dist∞<η явно исключить из гарантии либо
разрешить в ней отказ; не обещать невозможного.

1. Построй алгоритм с исходами 1,...,k,UNKNOWN и ошибкой ≤β
   равномерно по допустимым стратегиям. Дай верхние границы цены,
   числа различных вопросов и повторений.
2. Докажи нижнюю границу: сколько стоит искать локальное отклонение,
   которое может скрываться между вопросами?
   Сопоставь её с верхней границей по L,Δ,η,β.
3. Установи, когда адаптивность даёт выигрыш над фиксированной
   батареей. Дай явное семейство с растущим выигрышем либо
   докажи ограничение выигрыша для выбранного класса.
4. Реши один небольшой пример для семейств
   f(α)=2α/(1+α), prior=α, постоянных ответов и допустимых
   искажений этих стратегий. Пересекающиеся семейства
   предварительно отдели или честно объяви неидентифицируемыми.
5. Проверь отказоустойчивость: добавь стратегию, специально
   совпадающую с известной на старых тестах, но отличающуюся
   между ними. Покажи, что новая процедура её обнаруживает
   с заявленной гарантией.

Не решай только конечный перебор четырёх фиксированных кривых.
Не называй UNKNOWN конкретной психологической причиной.
```

**Что принести.** Алгоритм с проверяемой гарантией, нижнюю границу и короткую работающую батарею, которая умеет отвергнуть весь заданный каталог.

**Что не считать решением.** Высокую точность классификации только на тех стратегиях, на которых подбирались вопросы.

## Порядок работы и критерий успеха

Сначала **1**: вернуть исходному поиску конкретный простой парадокс-кандидат.
Параллельное по смыслу направление — **2**: установить пределы интерпретации ошибок.
Затем **3**: предсказывать новые точки срыва правила.
**4** полезна после появления содержательно обоснованных классов из 2–3.

Каждый ответ другой модели должен содержать:

1. Точную модель, допущения и отдельно заявленную теорему.
2. Доказательство либо явный контрпример.
3. Воспроизводимый расчёт, если приведены численные оптимумы.
4. Один конкретный результат для нашего проекта.
5. Границу между доказанным, предполагаемым и требующим данных.

Критерий высокой ценности: результат либо даёт новый простой кандидат
с контрольной парой, либо предсказывает ошибки на новых задачах,
либо устраняет принципиальную неоднозначность диагноза.
Более сложная формула без одного из этих эффектов — низкий приоритет.
