## 1. Последняя одинаковая проверка не повышает точность выбора

Есть n >= 2 вариантов, ровно один правильный, исходные вероятности равны. Каждый вариант можно проверить один раз одним и тем же бинарным тестом. У правильного вероятность положительного результата a, у остальных b, где 0 <= b <= a <= 1. При фиксированном положении правильного варианта результаты независимы. После проверок обязательно выбираем один вариант; оцениваем только вероятность правильного выбора. Проверка не меняет сами объекты.

Пусть P_k — наибольшая средняя точность после проверки k заранее выбранных вариантов. Тогда для 1 <= k <= n-1:

    P_0 = 1/n
    P_k - P_(k-1) = (a-b)(1-b)^(k-1)/n
    P_n - P_(n-1) = 0

Эквивалентно, для m = min(k,n-1):

    P_k = [a * sum(j=0..m-1, (1-b)^j) + (1-b)^m] / n

При m=0 сумма пуста и равна нулю. В частности:

    P_n = P_(n-1)

Пропустить можно любой один заранее выбранный тест. Это не утверждение, что результат не содержит информации: условные вероятности меняются, но оптимальная средняя точность выбора — нет.

Доказательство: среди проверенных выгоднее выбирать прошедшего; если прошедших нет — непроверенного. После проверки последнего прежний выбор остаётся оптимальным при обоих исходах: последний либо сравняется с прошедшими, либо с провалившимися. Поэтому его результат можно игнорировать без потери точности.

Для a=1 и b=1-q, где q — вероятность отсеять неправильный вариант:

    P_k = (1 + q + ... + q^min(k,n-1))/n

Практический смысл: при этих предпосылках одну проверку можно сэкономить без потери точности. Неравные начальные вероятности, разные тесты, зависимые результаты, дополнительная информация или другая цель требуют нового расчёта.

Проверки: rounds/r5-claude-lasttest.md, rounds/r5-k1.md; sims/r5_last_test.py, sims/r5_last_test_ext.py, sims/r5_k1_breaks.py. Общее выражение выше также выведено независимо из оптимального правила выбора 2026-10-15.

## 2. Право отказаться делает ту же проверку ценной

Сохраняем частный случай a=1, b=1-q. Правильный выбор приносит +1, неправильный -2, отказ 0. U_k — максимальный средний выигрыш при k проверках, без учёта цены самих проверок.

    U_n = q^(n-1)
    U_(n-1) = q^(n-1)/n + (n-1) q^(n-2) max(2q-1,0)/n

Поэтому для любого n >= 2 и 0 < q <= 1/2:

    U_n / U_(n-1) = n

При q=0 оба выигрыша нулевые, отношение не определено. При q>1/2 дополнительное слагаемое положительно, множитель n уже неверен.

Один пример для обеих частей: n=3, q=1/2. При обязательном выборе две и три проверки дают одну точность 7/12. При праве отказаться средний выигрыш возрастает с 1/12 до 1/4. Утроение относится к среднему выигрышу при заданных награде и штрафе, а не к вероятности найти цель.

Проверки: rounds/r5-p2.md; sims/r5_p2_coin_monty.py (точный перебор и моделирование).

### Известность первых двух результатов

Принцип нулевой ценности информации, которая не меняет оптимального решения, известен. Близкая конкретная модель независимых бинарных проверок, равных априоров, наград и штрафов: Grabchak, Li, Sonin, The Test and Find Model, 2026-08-29, https://arxiv.org/html/2608.29390v1 . В постановке этой работы проверяются все объекты. Само наличие более общей модели не устанавливает, что сравнение n и n-1 тестов и указанное равенство уже опубликованы. Приоритет именно этих утверждений остаётся открытым.

## 3. Менее надёжная деталь может чаще давать рабочую сборку

Три компьютера случайно расставлены: полностью исправный, с плохим блоком питания, с плохим процессором. Один A откладываем без проверки. Из двух других мастер отбраковывает неисправный D, оставляя B. Если оба неисправны, с вероятностью r он отбраковывает компьютер с плохим процессором. Диагноз игроку не сообщает. Блоки питания переставляются без повреждений; процессор A остаётся на месте.

    P(питание B исправно) = 1-r/3
    P(питание D исправно) = (1+r)/3

    P(сборка: процессор A + питание B работает) = (2-r)/3
    P(сборка: процессор A + питание D работает) = (1+r)/3

При любом 1/2 < r < 1 блок питания D сам по себе хуже, но сборка с ним лучше. При r=1/2 качество питания B равно 5/6, D равно 1/2, но обе сборки работают с вероятностью 1/2.

Причина: дополнительная исправность питания B приходится на случаи, когда процессор A неисправен. При выборе детали для сборки имеет значение её исправность одновременно с процессором, а не только отдельно от него.

Проверки: rounds/r4-boundary-k1.md; sims/r4_boundary_donor_k1.py (точный перебор и по миллиону опытов для r=1/2 и r=1). Обобщение по r следует из трёх равновероятных типов A.

Законы совместной вероятности и границы надёжности систем известны. Возможная новизна здесь — конкретная простая процедура отбора и сборки, создающая разворот качества; подтверждения приоритета пока нет.
