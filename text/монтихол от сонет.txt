Обобщённая теория расширенного парадокса Монти Холла
Итоговая консолидированная работа. Содержит весь существенный материал: статическое ядро, причинный слой, их объединение, генератор парадоксов и практическую диагностику.

Часть 0. Постановка задачи
N объектов. Ровно один несёт искомое свойство τ (цель), априори равномерно:

P(τ = i) = 1/N
Наблюдатель без информации помечает k объектов как «свои» (группа Y). Остальные n = N − k объектов образуют группу O. Процесс отбора Φ оставляет из O подмножество survivors S, |S| = m.

Вся статическая часть модели — это одна функция, ядро правдоподобия:

K_i(s) = P(S = s | τ = i)
Из неё по Байесу при равномерном априоре:

P(τ = i | S = s) = K_i(s) / Σ_r K_r(s)
Это единственный первичный объект. Всё остальное — частные случаи или производные от K_i(s).

Часть 1. Статическое ядро (Read-Monty)
1.1. Точный критерий сохранения массы группы
Пусть A(s) = Σ_{i∈Y} K_i(s), B(s) = Σ_{j∈O} K_j(s). Тогда

P(τ ∈ Y | s) = A / (A + B)
Чтобы это равнялось «естественному» k/N (то есть чтобы отбор внутри O не менял суммарную вероятность группы Y), необходимо и достаточно:

Условие сохранения массы:

A(s)/k = B(s)/(N−k)
Полная обменность (exchangeability) K_i(s) по индексам внутри каждой группы — это достаточное, но не необходимое условие. Точный тест — именно равенство выше. Если у механизма отбора есть скрытое предпочтение к конкретным исходам (не только к их количеству), это условие нарушается, и вся дальнейшая арифметика неприменима без пересчёта с нуля.

Контрпример, показывающий, что дело серьёзное. N=4, Y={1}, O={2,3,4}, m=2. Правило ведущего: если τ=1→показывает {2,3}; τ=2→{2,3}; τ=3→{2,4}; τ=4→{3,4}. Наблюдаем S={2,3}. По Байесу P(τ∈Y|S) = 1/2, а не 1/4 — расхождение в два раза, не погрешность.

1.2. Инвариант при полной симметрии
Если условие выше выполнено строго обменным образом:

P(τ ∈ Y | s) = k/N
P(τ = j | s) = (N−k) / (N·m)   для каждого survivor j
1.3. Два разных числа, которые легко путать
Коэффициент сжатия (геометрия):

C = (N−k) / m
Смысл: во сколько раз каждый survivor «тяжелее» одного элемента вашей группы — по чистой комбинаторике деления групповой массы на m равноправных носителей.

Фактический Bayes factor (информация):

R_(j:y)(s) = P(S=s | τ=j) / P(S=s | τ=y)
где j — конкретный survivor, y — конкретный ваш объект.

R = C только при полной симметрии. В общем случае это два разных объекта: C — чистая геометрия отбора, R — реальная информационная сила конкретного наблюдения. Путать их — источник грубых числовых ошибок (см. ниже, п.1.5).

1.4. Биты и их точная композиция
I = log2(R_eff)
Композиция бит не требует условной независимости, только последовательного пересчёта:

R_total = Π_t [ P(E_t | H1, E_<t) / P(E_t | H0, E_<t) ]
I_total = Σ_t I_t
Это тождество телескопической цепочки условных правдоподобий — точное, не приближение.

1.5. Что можно и что нельзя считать через сигмоиду
Формула

P = 1/(1 + 2^(−I)) = R/(1+R)
даёт условную вероятность «τ=j при условии, что τ обязательно один из двух: j или y» — то есть корректна только для строго бинарного обмена «это конкретное на то конкретное».

Она не даёт абсолютную вероятность конкретного survivor победить во всём поле из N объектов, если m>1 или k>1. Для абсолютной вероятности используйте прямо p_j = (N−k)/(Nm) без всякой сигмоиды.

Пример ошибки на реальных числах: N=100, k=20, m=5. C=16. Сигмоида даёт 16/17≈94.1% — это неверный ответ на вопрос «какова вероятность конкретного survivor». Верный ответ: (100−20)/(100·5)=16%. 94.1% — это ответ на другой вопрос: «если бы выбор стоял строго между этим survivor и одним конкретным вашим боксом, кто выиграл бы» — легитимный вопрос, но другой.

1.6. Точный нулевой критерий (закон Д, исправленный)
I_(j:y)(s) = 0  ⟺  P(S=s | τ=j) = P(S=s | τ=y)
Работает без вырождений при любом m (в отличие от прежней версии, ломавшейся при m=1).

1.7. Частные случаи — таблица
Модель	Формула R (=2^I)	Комментарий
Классика (k=1, m=1)	N−1	ведущий всегда избегает раскрывать цель
Обобщение k/m	(N−k)/m = C	справедливо только при полной симметрии
Частичная осведомлённость q	q(N−2) + 1	ведущий знает истину с вероятностью q, иначе действует вслепую
Щит β (минное поле)	(N−1)·S_N(β), S_N(β) = Γ(N−1)Γ(2−β) / Γ(N−β)	защищённая ячейка взрывается с интенсивностью (1−β) вместо 1
Общий принцип: q, β — это не отдельные теории, а разные физические истории того, как получилось конкретное значение R между двумя якорями: R=1 (полностью слепой отбор) и R=R_max (полностью осведомлённый).

Часть 2. Причинный слой (Write-Monty)
2.1. Момент фиксации и смешанная вероятность
Пусть λ(t) = P(τ уже фактически определён к моменту t) — доля случаев, где реальность уже «застыла». Тогда:

p(t,u) = λ(t)·p_F + [1−λ(t)]·p_O(t,u)
где p_F — вероятность в уже зафиксированной части, p_O(t,u) — вероятность в ещё открытой части, зависящая от действия u.

2.2. Причинная сила
В логарифме шансов J = log(p/(1−p)):

F_u = ∂J/∂u ∝ (1−λ)·κ_u + (p_F − p_O)·∂λ/∂u,     κ_u = ∂p_O/∂u
Два разных механизма воздействия: сдвинуть направление ещё открытого будущего (первый член) или изменить скорость его фиксации (второй член).

2.3. Окно максимальной силы
Если чувствительность системы к действию сама зависит от времени, κ(t), то:

F(t) ∝ [1 − λ(t)]·κ(t)
Слишком рано: κ≈0 (система ещё не сцеплена с действием). Слишком поздно: 1−λ≈0 (будущее уже застыло). Максимум — где-то между. Точка максимума:

d/dt[ln κ(t)] = h(t),     h(t) = −d/dt[ln(1−λ(t))]  (риск фиксации)
2.4. Причинная работа и плечо
W = J_after − J_before = ln(R)  = I·ln2
Статическая величина I — это в точности накопленная причинная работа к моменту λ=1. Каузальное плечо:

L = W / Z    (Z — затраты: время, деньги, внимание)
Leverage(t,u) = S(t)·κ(t,u) / Z(t,u),   S(t) = 1 − λ(t)
Часть 3. Формальный фундамент объединения
3.1. Мартингальная природа I
Последовательность апостериорных p_t, получаемых только условием (без вмешательства), образует мартингал:

E[p_(t+1) | F_t] = p_t
(теорема Дуба). λ=1 — момент остановки этого мартингала (stopping time). По теореме об опциональной остановке, после стоп-момента дальнейшее наблюдение больше не сдвигает среднее — только накапливает I (дисперсию/уверенность), не меняя p_F.

3.2. Точное доказательство F≡0 при λ=1
Если λ=1, то p(t,u)=p_F тождественно, независимо от u. Значит:

λ = 1  ⟹  F_u ≡ 0  для любого u
Это не приближение — алгебраическое следствие того, что после фиксации p не зависит от u. Любое наблюдаемое «изменение вероятности» после фиксации есть изменение оценки p_F наблюдателем (движение по оси I), а не изменение самого p_F (оси F).

3.3. Теорема неэквивалентности
I_A = I_B   ⇏   F_A = F_B
Структурное основание: I — накопленная мартингальная вариация от чтения (оператор condition); F — локальный дрейф, доступный записи (оператор do), пока мартингал не остановлен. Это разные по природе операторы на одной мере, поэтому их числовые следствия независимы. Именно это гарантирует, что (I,F) — настоящая плоскость, а не одна ось с двумя именами, то есть что пространство парадоксов вообще не пустое.

3.4. Закон насыщения убеждения
dP/dI = ln2 · P(1−P)
Максимум чувствительности — ровно в точке безразличия P=½. По мере роста I каждый следующий равный по силе бит даёт всё меньший сдвиг субъективной вероятности, хотя доказательная сила (в битах) растёт линейно.

3.5. Антисимметрия и её правильная интерпретация
I_(B:A) = −I_(A:B)
Одно и то же свидетельство не может одновременно поддерживать A против B и B против A в рамках одной модели механизма. Если два наблюдателя расходятся в знаке — они расходятся не в трактовке факта, а в модели P(E|H) — то есть спор нужно вести о механизме генерации доказательства, а не о самом факте.

Часть 4. Единая карта — генератор парадоксов
4.1. Ключевой факт
Каждая ситуация с двумя «одинаково выглядящими» вариантами описывается точкой на плоскости (I, F):

I — сколько бит наблюдение уже сказало о том, что произошло;
F — сколько причинной силы ещё доступно, чтобы изменить то, что не произошло.
4.2. Четыре квадранта
F низкая (закрыто)	F высокая (открыто)
I низкая	Тупик: ничего не знаем и ничего не можем. Парадоксов нет.	Окно мягкого настоящего. Мало доказательств, система пластична. Слабое действие здесь сильнее мощного действия позже.
I высокая	Зона вскрытия (Read-Monty). Классика после открытия двери. Картина ясна, но влиять уже поздно — люди по инерции ищут «кто виноват», как будто F всё ещё высок.	Редкий максимум. Много знаем и ещё можем сильно менять — самое ценное и самое короткое состояние.
Типичная траектория по умолчанию — диагональ из левого-нижнего/правого-верхнего угла: F↓, I↑ одновременно. Знание часто покупается именно ценой закрывающегося окна воздействия.

4.3. Алгоритм генерации парадокса (5 шагов)
Найти снимок-двойник. Два состояния X_A, X_B, одинаковые по непосредственно наблюдаемым признакам.
Проверить валидность. A(s)/k = B(s)/(N−k)? Если нет — это не Монти-структура, формулы неприменимы без переработки.
Эпистемическая ось. Сравнить P(S=s|τ=A) и P(S=s|τ=B). Различие — источник I.
Причинная ось. Для каждого — λ_A, λ_B? Если наблюдатель молчаливо приписывает λ=1 там, где на деле λ<1 (или наоборот) — источник F-асимметрии.
Собрать формулировку. Шаблон: «X_A и X_B неразличимы по оси, которую человек привычно отслеживает, но различны по оси, которую он не отслеживает».
4.4. Диагностический чек-лист (приземление в практику)
При встрече с реальной ситуацией «два похожих исхода» — задавать по порядку:

Есть ли у механизма отбора скрытое предпочтение к конкретным исходам сверх количества? (иначе — стоп, не Монти-задача)
Прошли ли два варианта один и тот же тип отбора, или один был защищён/протестирован иначе?
Реально ли действие сейчас изменит итог, или итог уже физически предрешён, и действие лишь изменит представление о нём?
Двигаюсь ли я по диагонали F↓,I↑ — покупаю ли уверенность ценой закрывающегося окна?
Если ответ на (3) — «предрешено», усилия нужно переносить с объекта на сбор информации о нём. Если «открыто» — откладывание ради дополнительной уверенности само имеет причинную цену, и её нужно считать явно.

Часть 5. Сжатый список законов
A. Закон доли, а не размера. R зависит только от (N−k)/m, не от абсолютного N. Огромная выборка при пропорциональном сужении не даёт преимущества большего, чем маленькая.

B. Закон валидности. Без A(s)/k=B(s)/(N−k) вся арифметика группы неверна не приближённо, а категориально — нужен пересчёт с нуля, а не поправочный коэффициент.

C. Закон разделения C и R. Совпадают только при полной симметрии. C — геометрия сжатия, R — фактическая информационная сила. Путать их — типичный источник грубых числовых ошибок при переходе от k=m=1 к общим k,m.

D. Закон композиции без независимости. Биты складываются через условные правдоподобия точно, независимость не требуется.

E. Закон нулевого критерия. I=0 тогда и только тогда, когда P(E|H1)=P(E|H2) — без вырождений, для любого m.

F. Закон необратимости. λ=1 ⟹ F≡0 тождественно. После фиксации любое воспринимаемое воздействие есть движение по оси I (оценка), а не по оси F (реальность).

G. Теорема неэквивалентности. I_A=I_B не влечёт F_A=F_B. Формально — следствие разной природы операторов condition и do на одной мере.

H. Закон насыщения. dP/dI=ln2·P(1−P), максимум чувствительности в точке безразличия; десятое подтверждение почти ничего не меняет субъективно, хотя несёт столько же бит, сколько первое.

I. Закон антисимметрии. I(B:A)=−I(A:B); расхождение сторон в знаке evidence — это расхождение в модели механизма, а не в интерпретации факта.

J. Закон разъезжающейся диагонали. По умолчанию рост I сопровождается падением F — мир становится понятнее часто именно потому, что перестаёт быть управляемым.

Приложение. Что сознательно не включено и почему
Из более ранних версий модели исключены как избыточные (не добавляющие структуры сверх изложенного выше), но упоминаются для полноты:

«Размерность отбора» d и степенные асимптотики по N — частный взгляд на закон A через показатель степени, не отдельная теорема.
Причинное трение ρ, каузальный барьер B, причинная мощность P_c, коэффициент обратной связи g — стандартный аппарат динамики с обратной связью (линейная релаксация, бистабильность), полезный язык, но не специфичный для структуры Монти Холла: то же самое верно для любой системы вида dJ/dt=f(J,u).
Обширные списки бытовых аналогий (яйца, батарейки, SD-карты и т.п.) — иллюстрации закона B/C, не новое содержание; генератор из части 4.3 воспроизводит их по требованию систематически, без необходимости хранить список.
