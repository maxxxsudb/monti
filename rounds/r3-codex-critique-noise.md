# П1 — независимая критика двустороннего шума

Проверен `rounds/r3-codex-task-noise.md`. Собственный точный перебор: `sims/r3_p1_noise_exact.py`, рациональная арифметика всех 8 исходов. Новая симуляция не нужна: исходный автор уже выполнил по 10^6 испытаний, а эта проверка независимо устанавливает точный максимум.

## 1. Основные числа верны

При одном равновероятном профи, одинаковых тестах g=.9,b=.1, условной независимости и маскировке провалов A,B с вероятностью h:

| h | Независимо найденный максимум |
|---|---:|
| 0 | 21/25 = .84 |
| 1/4 | 39/50 = .78 |
| 1/2 | 18/25 = .72 |
| 3/4 | 33/50 = .66 |
| 1 | 3/5 = .60 |

Таблица автора при h=0 и h=1/2 соответствует найденным максимумам. Речь именно о максимальной общей вероятности правильного найма по всем возможным отчётам, а не условной вероятности одной ветви. Все числа .84→.72→.60 подтверждены.

### Явная оптимальная политика

Обозначим третьего кандидата C (в исходном русском тексте это В). Для 0≤h≤1:

- C прошёл → выбрать C.
- C провалился, прошёл только один из A,B → выбрать прошедшего.
- C провалился, прошли A и B → они равноправны, выбрать любого.
- Провалились все → все равноправны, выбрать любого.

При h=0 дополнительные ничьи допускают другие оптимальные правила. При h=1 некоторые исходы невозможны; после провала C выбираем A/B.

Это следует из likelihood factors: незамаскированный положительный результат имеет g/b, замаскированный — `[g+(1−g)h]/[b+(1−b)h]`, который между 1 и g/b; отрицательный обоих типов имеет `(1−g)/(1−b)`. Поэтому C с положительным результатом не слабее A/B с положительным.

### Более сильный точный результат

При **любых** 0≤b<g≤1, uniform prior и одинаковых независимых тестах, маскировке именно двух тестов с одним общим параметром h:

`V(h) = [1+(g−b){2−b−h(1−b)}]/3`.

Для вывода можно выбрать детерминированные tie-break: при Cpass взять C; при Cfail сначала Apass→A, иначе Bpass→B, иначе C. Вероятность верного выбора равна

`[g+(1−b)g_h(2−b_h)+(1−g)(1−b_h)^2]/3`,

где `g_h=g+(1−g)h`, `b_h=b+(1−b)h`; квадратичные по h члены сокращаются. Отсюда

`V(0)−V(h)=h(g−b)(1−b)/3`.

Падение строго при h>0 и информативном тесте g>b. Значит конкретные .9/.1/.5 не подогнаны для появления эффекта: это открытое семейство параметров. Равенство при g=b или h=0 естественно.

## 2. Стирание одного теста действительно не снижает accuracy

Независимый перебор при стирании A даёт **21/25**, как без стирания. Рассуждение автора по factor 1 правильное, но нуждается в явно перечисленных предпосылках.

Более того, вывод верен для **любого числа n≥2** кандидатов при тех же предпосылках: ровно один профи, равномерное prior, одинаковые бинарные тесты, условная независимость, цель — выбрать одного и получить 1 только за правильного.

Доказательство: если среди n−1 оставшихся результатов есть pass, выбираем одного из прошедших. Скрытый кандидат без теста не может быть лучше: у него factor 1 против g/b>1. После восстановления его теста pass лишь создаёт ничью с уже выбранным прошедшим, а fail оставляет прежний выбор лучшим. Если все n−1 провалились, выбираем скрытого кандидата: factor 1 больше отрицательных; его fail лишь создаёт ничью со всеми, а pass сохраняет выбор. Таким образом, одно и то же правило по сокращённой информации можно выбрать оптимальным для **каждого** полного исхода. Усреднение не теряет точности.

Это не означает отсутствия информации в удалённом тесте: posterior, уверенность и оптимальная log-loss могут измениться. Равенство относится к этой специальной задаче точного выбора и 0–1 loss. Нельзя объявлять два эксперимента эквивалентными по Blackwell из равенства одной полезности.

## 3. Когда тезис про один стёртый тест неверен

### Неравные prior

Пусть P(Apro)=.8,P(Bpro)=P(Cpro)=.1, все тесты по-прежнему g=.9,b=.1 и независимы. Тогда точный оптимум:

- полный отчёт: **9387/10000 = .9387**;
- A стёрт: **819/1000 = .819**.

Значит равномерное prior существенно. Здесь неизвестный кандидат не имеет factor 1 с равным исходным весом: высокая исходная вероятность A и его собственный fail/pass могут действительно менять победителя решения.

### Неодинаковые качества тестов

При uniform prior пусть только тест A информативен (g_A=.9,b_A=.1), а B,C — монетки (g=b=.5). Тогда полный оптимум **3/5**, стирание A даёт **1/3**. Существенно, что все тесты имеют один и тот же likelihood ratio положительного и отрицательного исхода.

### Коррелированные ошибки при тех же маргинальных .9/.1

Пусть с вероятностью .9 итог тестов равен индикатору квалифицированного кандидата (100,010,001), а с вероятностью .1 **все три бита одновременно инвертируются** (011,101,110). У каждого теста маргинально g=.9,b=.1, как в исходной задаче.

Полный отчёт однозначно распознаёт профи по позиции единственного отличающегося бита → **1**. После стирания A пары BC=00 или11 распознают A, а BC=10 или01 различают B/C лишь с точностью .9 → общий оптимум **(1+2·.9)/3=14/15**. Удаление одного теста теряет **1/15**. Условная независимость критична; одинаковые marginal pass-rates её не заменяют.

### Другая функция потерь/действия

Если оценивается калибровка вероятности, log-loss, разные стоимости ошибочного найма, возможность нанять нескольких или отказаться от всех, доказательство про создание только ничьей не переносится. Например, после двух pass восстановление третьего результата меняет posterior даже когда не меняет лучший адресат. Не утверждаю строгого уменьшения для каждой альтернативной utility — только отсутствие доказанного равенства.

### Изменение квалификации или особое правило помощи

Обучение, которое превращает дилетанта в профи, меняет целевое T; это другая задача. Помощь, чья вероятность зависит от T сверх исходного результата, не является общим для гипотез каналом garbling. Разный h для профи и дилетанта, дополнительный сигнал «ему помогали» или доступный журнал ремонта также требуют нового kernel.

## 4. Robustness основного снижения .84→.72

Основное направление неравенства сохраняется при любой потере данных, которая удовлетворяет `P(Z|X,T)=P(Z|X)` и не меняет T, доступные решения и полезность. Решение по Z можно имитировать, имея X: в этом смысле исходный отчёт не хуже. Для строгого падения требуется уничтожить различие, которое меняет оптимальное действие; стирание одного iid теста с uniform prior этого не делает, стирание двух здесь делает.

Обязательные условия для coldprompt:

1. Ровно один профи, все трое априори равноправны.
2. Экзамены независимы **условно на том, кто профи**; одно общее g=.9,b=.1.
3. Помощь A,B назначена заранее, не по качеству кандидатов или чужим результатам.
4. Каждый первоначальный fail независимо маскируется с вероятностью .5; исходный pass не меняется.
5. Работодатель не видит исходных результатов и отдельных признаков маскировки, только итоговые три бита; процедуру знает.
6. Квалификация не меняется; все варианты найма доступны, payoff одинаков — 1 за профи, 0 иначе.
7. Спрашивается максимальная **общая** accuracy по всем отчётам.

Фраза «помогают сдать экзамен» без этих уточнений может означать обучение, выдачу ответов всем, помощь лишь после определённой неудачи или неизвестный канал. Тогда .72 не обязана сохраняться.

## 5. Вердикт П1

**Численной ошибки не найдено.** Это сильнее исходного идеального теста: двусторонний шум и помощь двум действительно снижают оптимальную точность, причём эффект существует не только в выбранной точке параметров. Частный тезис о безвредности стирания одного теста тоже верен и даже обобщается на n, но лишь при существенных условиях выше.

Теоретический механизм — известная деградация эксперимента через garbling; оригинальность конкретного простого примера требует отдельной проверки. Правильные ответы Arena не служат отказом по человеческой контринтуитивности: она пока не измерена.
