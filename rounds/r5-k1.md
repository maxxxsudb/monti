# Раунд 5 — К1: критика K-5 «Последний экзамен/скан бесполезен»

Скрипт: `sims/r5_k1_breaks.py` (точный перебор Fraction по всем подмножествам тестируемых + MC 10^6 контроль; запущен, ~50 с).

## 1. Проверка доказательства и формулы — ВЕРНО (с уточнением области)
- Формула (1/N)Σ_{j=0}^{min(k,N−1)} f^j: перепроверена вручную (k=1: (1+f)/N) и перебором — совпадает. Контроль N=3, f=1/2: 1/3, 1/2, 7/12, 7/12.
- Теорема (1 эксперт, равные априоры, a≠b): верна. Чистое доказательство через отношения правдоподобия: у прошедшего LR=a/b≥1, у проваленного (1−a)/(1−b)≤1, у непроверенного ровно 1 ⇒ непроверенный всегда «между»; его тест переводит его в ничью либо с группой «прошли», либо с группой «провалили», argmax не меняется. **a<b не ломает** (переименовать pass↔fail). Замечание: «доказательство в одну строку» через «первого прошедшего» годится только для a=1; общий случай держится на LR-аргументе.
- Устойчиво (неожиданно для меня): 2 эксперта из 4 при цели «назвать ВСЮ пару» — последний тест всё равно 0 (.1667 .2500 .3750 .4583 .4583); неизвестное число экспертов (каждый эксперт с p=1/3, нанять одного) — 0; цель «уволить точно не эксперта» — 0.

## 2. Где ЛОМАЕТСЯ (граница эффекта, точно)
| Условие | точность/выигрыш при k=0..N | вклад последнего |
|---|---|---|
| Неравные априоры, a=1 (нет ложных отказов), .5/.3/.2 | .50 .65 .70 .70 | **0** (если не тестировать наименее вероятного) |
| Неравные априоры + двусторонняя ошибка: a=.8, b=.5, ½/¼/¼ | .5000 .5250 .5625 .5750 | **1/80** (MC .5755 vs .5750) |
| то же, a=.8, b=.2 | .500 .600 .720 .752 | **4/125** |
| максимум по сетке N=3: a=.8, b=.1, .70/.15/.15 | … .795 → .8786 | **0.084** |
| Цель — апостериор, а не выбор (лог-скор, бит), равные априоры | −1.585 −1.333 −1.093 −0.896 | **+0.197 бит** (почти как другие тесты) |
| то же, Брайер | −.667 −.583 −.489 −.417 | **+0.072** |
| Право отказа: +1 эксперт, −2 неэксперт, 0 отказ, a=1, b=½ | 0, 0, 1/12, **1/4** | **+1/6 — последний тест самый ценный, утраивает выигрыш** |
| то же, штраф −1 | 0, 0, 1/4, 1/4 | 0 |
| право отказа, штраф −1, a=.9 | 0, 0, .150, .175 | 1/40 |

Выводы: «0» — артефакт трёх условий одновременно: (i) вынужденный выбор с 0-1 потерей, (ii) симметричные априоры ИЛИ отсутствие ложных отказов, (iii) нас интересует решение, а не знание. Апостериоры при 2 и 3 тестах разные — любой собственный скоринг это видит. Вредным последний тест для байесовца быть не может (Блэкуэлл: VOI≥0); вред — только при цене теста или эвристике.
Проверка c=2 вручную: после 2 тестов нанимать выгодно лишь если оба провалились (кандидат 3 наверняка) → 1/3·1/4=1/12; после 3 тестов — если ровно один прошёл: P=1·¼=1/4.

## 3. Новизна — ИЗВЕСТНО по механизму (ценность информации), конкретного примера в литературе не нашёл
- Принцип «информация, не меняющая решения, стоит 0» — стандарт теории ценности информации (Howard 1966, «Information Value Theory», IEEE Trans. SSC; Raiffa–Schlaifer 1961). Авторы сами это признают (r5-claude-lasttest.md, стр. 38). Теорема = «последний результат не меняет argmax» ⇒ VOI=0 — прямое применение, без нового механизма.
- Теория поиска: объект в одном из n ящиков, вероятность пропуска (overlook) — Kadane 1967 (DTIC AD0649850), Bayesian search theory; «Test and Find» (arXiv 2608.29390: ящики, тесты с ложноположительными/ложноотрицательными, награда за верную метку и штраф за неверную — ровно наш вариант с отказом/штрафом, где эффект ломается). Явного утверждения «последний шумный тест бесполезен» не нашёл.
- При a=1 — фольклор «из N достаточно проверить N−1» (взвешивания/дефектная монета, first-success). Новое у K-5 лишь то, что это переживает шумный тест с двусторонней ошибкой — но это следует из одной строки про LR.
- Вердикт: строгое ИЗВЕСТНО по чёрному списку — нет (VOI там нет), но критерий (e) «не сводится к известному механизму» — **не проходит**: механизм = VOI=0, общеизвестный.

## 4. Связь с Монти — НЕ_МОНТИ (слабая аналогия)
В Монти суть — информированный/ограниченный ведущий, чей выбор двери зависит от положения машины. В K-5 нет ведущего и нет отбора: тесты экзогенны, независимы, одинаковы для всех. «Непроверенный = защищённая дверь» значит только «его LR=1» — это есть в любой задаче с ненаблюдённым объектом. Критерий (a) не выполнен.
Как сделать «монтихоловее» без потери простоты: «Вы выбрали дверь 1. Ведущий сканирует детектором две ДРУГИЕ двери (вашу никогда — как в шоу). Стоит ли доплатить за скан своей двери?» Стратегия: менять на пищащую, если такая есть; шанс 7/12 с доплатой и без. Это копирует форму Монти (ваша дверь неприкосновенна, решение «менять»), но механизм остаётся VOI, а не информированный ведущий.
Сильнее как пара-контраст (K-5b): «…но если можно уйти ни с чем, а коза стоит −2: без третьего скана EV=1/12, с ним 1/4». Тот же скан: при вынужденном выборе бесполезен, при праве отказа утраивает выигрыш. Контринтуитивнее, но формулировка тяжелее (СЛОЖНО на грани).

## 5. Оценки
ОШИБКА — нет. ИЗВЕСТНО — по механизму (VOI). НЕ_МОНТИ — да. ИНТУИТИВНО — частично: для a=1 «нанять первого прошедшего, последнего тестировать незачем» быстро видно; для двусторонней ошибки — не очевидно (нужен опрос людей). СЛАБО — эффект ломается от неравных априоров с a<1, права отказа, любого скоринга вероятностей.

**Голос: ПРОТИВ** — верно и изящно, но это VOI=0 без информированного фильтра (НЕ_МОНТИ), и ноль держится только при вынужденном выборе (с правом отказа последний скан утраивает выигрыш).

## Финальный голос (после ответа предлагающего и Arena-рецензии)
**ЗА** (меняю с ПРОТИВ). Формулировка «Монти-монетка» снимает НЕ_МОНТИ: информированный ведущий, который никогда не открывает машину, — это фильтр, сохраняющий цель; отображение на детектор точное (открыта коза ⇔ «провал», q=f; (1+q+q²)/3 сходится с моим перебором). Контраст с классикой (там защита вашей двери = 2/3 против 1/2, здесь 0) и пара (1)+(2) (1/12 → 1/4) — уже не голый VOI=0.
Условия ЗА: публиковать только парой (1)+(2); в условии явно оговорить равные априоры и вынужденный выбор в (1); критерий (c) — только после опроса людей; название «Lazy Monty» не использовать.
