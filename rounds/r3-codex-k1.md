# Раунд 3 — К1: новые задания D и C

## 1. Надёжные бомбы: число верно, точное отображение найдено

Три клетки A,B,C, пустая равномерна, остальные содержат бомбы. A полностью защищена; каждая другая бомба независимо взрывается до фиксированного утра с вероятностью p. Наблюдение E: C взорвалась, B не взорвалась.

Правдоподобия E при пустых A,B,C соответственно p(1−p),p,0. Поэтому P(пустая B|E)=1/(2−p), P(пустая A|E)=(1−p)/(2−p). Для p=.9 ответ **10/11≈90.909%**, «91%» допустимо только как округление. Без защиты, при наблюдении «только C взорвалась, A и B целы», оба допустимых положения пустоты имеют likelihood p(1−p); ответ 1/2 для 0<p<1. При p=1 без защиты событие имеет нулевую вероятность, условный ответ не определён.

**Конкретное известное отображение:** [Rosenthal, Monty Hall, Monty Fall, Monty Crawl, 2005/2008, §4, Monty Small](https://www.probability.ca/jeff/writing/montyfall.pdf), p.5. В его параметрической версии при призе за A ведущий открывает C с вероятностью q; при призе за B — обязательно C; при призе за C — не C. Likelihood открытия C равны (q,1,0), posterior B=1/(1+q). Положить q=1−p: бомбовые likelihood равны p·(q,1,0), общий множитель p сокращается. Совпадает весь posterior по исходному положению пустоты для этого сообщения, не только одно число. Ровно опубликован **Monty Small**, а Crawl — его предел q=0. Называть произвольное p непосредственно Crawl неточно.

Физическая реализация и смысл скрытого молчания отличаются от прихоти ведущего. Однако для поставленного условного числового вопроса это известный протокол выбора сообщения. При строгом критерии «не сводится» **ПРОТИВ финального принятия**.

Важно: полное распределение всех возможных ночных наблюдений не совпадает с одношаговым guaranteed-goat Monty Small. Здесь бывают ноль и два чужих взрыва; отображение относится к предъявляемой условной задаче E. Для изучения решений по всем сообщениям эти ветви надо сохранять.

## 2. Поздний первый взрыв и медиана

Пусть обычные независимые часы бомб имеют непрерывное распределение с плотностью f(t), survival S(t); A полностью защищена. E_t: первый взрыв именно C в момент t. При пустой A density=f(t)S(t), при пустой B density=f(t), при пустой C — ноль. Значит P(A пустая|E_t)=S/(1+S), P(B пустая|E_t)=1/(1+S).

При t в медиане S=.5 получаются **1/3 и 2/3**. Позже медианы switch>2/3; раньше — между 1/2 и 2/3. Формулы верны в точках с положительной плотностью; «для любого распределения» требует оговорки про непрерывность и отсутствие одновременных взрывов. При атомах/общих причинах появления таймера формула может измениться.

**Точное отображение к первичному Monty Small:** для наблюдения в конкретный t положить q=S(t). Тогда плотности пропорциональны (q,1,0). Новое время — наблюдаемая переменная, определяющая эффективную склонность фильтра, а не новый Байесов механизм. Без времени, если дождаться первого взрыва и запомнить только C, likelihood равны (1/2,1,0), возвращается стандартный Монти. **ПРОТИВ финального принятия:** известное параметрическое раскрытие плюс survival-сигнал; точную ранее опубликованную взрывную формулировку не утверждаю.

Критическая оговорка к r0d_timed.py: для временных интервалов Monte-Carlo надо сравнивать с интегралами likelihood по интервалу, а не с точечной формулой в середине; особенно последняя корзина содержит весь хвост t≥2.75. Медиана первого наблюдаемого взрыва не равна медиане отдельной бомбы. В формулах используется именно последняя.

## 3. Частичный амулет плюс время: разворота к stay нет

Явная модель: A-бомба, если она там, имеет интенсивность a=1−β, обычные B/C — интенсивность 1, независимые экспоненциальные часы, 0≤β≤1. Наблюдение E_t — первый взрыв C в момент t, значит A и B до t не взрывались.

Density при пустой A: exp(−2t); при пустой B: exp(−(2−β)t). Отсюда **P(A пустая|E_t)=1/(1+exp(βt))** и P(B пустая|E_t)=exp(βt)/(1+exp(βt)). Производная stay равна −βexp(βt)/(1+exp(βt))²≤0. Поздний взрыв никогда не советует оставаться при β>0; при β=0 обе вероятности всегда 1/2. Причина: собственное молчание диагностично, но слабее молчания полностью незащищённой B.

Обобщение: пусть protected survival=S_A(t), ordinary=S(t). Тогда stay=S/(S+S_A), d ln(stay/switch)/dt=h_A−h. Если защита действительно уменьшает hazard потраекторно во времени, h_A≤h, разворота нет. Если амулет после истечения срока даёт hazard выше обычного, разворот возможен, но его создаёт пересечение заранее заданных hazards, то есть известный survival likelihood; нужны дополнительные условия.

Отображение Monty Small: q=S/S_A; для настоящей защиты 0≤q≤1, и posterior stay=q/(1+q). **ПРОТИВ финального принятия:** та же параметрическая схема раскрытия, заявленный поиск особого β с поздним предпочтением stay имеет отрицательный результат.

Если наблюдение не «первый взрыв», а «C взорвалась к фиксированному t и остальные целы», тот же результат получается после сокращения общего P(C взорвалась к t). Если игрок знает лишь «к моменту первого чужого взрыва он выжил», но не его время — надо интегрировать, не подставлять среднее t.

## 4. Два игрока с полными амулетами

N=4, пустая равномерна; A,B защищены, C,D обычные. **Без времени**, дождались первого чужого взрыва, им оказался D: likelihood при пустых A,B,C,D равны (1/2,1/2,1,0). Значит P(A пустая)=P(B пустая)=1/4, P(C пустая)=1/2. Утверждение D корректно при этом протоколе: это n-дверный Монти с группой из двух защищённых элементов.

**Надёжные бомбы, фиксированное утро:** D взорвалась, C цела; likelihood p(1−p),p(1−p),p,0. Поэтому **P(сосед B пустой)=(1−p)/(3−2p)**, P(C пустая)=1/(3−2p). При p=.9 сосед пуст с вероятностью **1/12≈8.333%**, C пустая **5/6≈83.333%**. Защищённые игроки уже не сохраняют априорные 1/4. Совпадение с untimed-моделью появляется лишь при p=.5.

**Первый D в точный t:** веса S,S,1,0; сосед=S/(1+2S), C=1/(1+2S). При экспоненциальных бомбах t=ln10, S=.1: сосед 1/12, C=5/6.

Конкретный статический фильтр с тем же posterior: информированный ведущий не трогает A,B и цель; при пустых A/B показывает D с вероятностью q, при пустой C — обязательно D, при пустой D — никогда D. Веса (q,q,1,0), q=1−p либо S(t). Это n-дверное обобщение предпочтения сообщения Monty Small, не Берксон. Сам n-дверный протокол — известный; точную публикацию двух амулетов не нашёл. **ПРОТИВ финального принятия:** сводится к известному фильтру по меткам, контринтуитивность не измерена.

## 8. Дополнительное задание: ресурсный «пас» разворачивает выбор

**Условие (3 предложения).** Единственный приз лежит за A с вероятностью 1/2, за B или C — по 1/4; вы выбираете A. Информированный ведущий обязан открыть доступную чужую козу: независимо от приза с вероятностью 2/3 ему доступна только дверь B, а с вероятностью 1/3 недоступна ни одна; бюджет вам не показывают. Если допустимого открытия нет, он говорит «пас», после чего вы можете окончательно выбрать любую дверь.

**Вопрос:** ведущий сказал «пас»; с какой вероятностью вы выиграете, выбрав B?

**Ответ: 1/2.** До сообщения A была единственным оптимальным выбором (1/2 против 1/4). После паса оптимальной становится B (1/2 против 1/3 у A и 1/6 у C). Ответ не 0 или 1: пас имеет две скрытые причины — отсутствие любого бюджета или недоступность единственной козы, потому что доступная B содержит приз.

Точный расчёт: P(pass|Z=A,B,C)=(1/3,1,1/3). Совместные массы (1/6,1/4,1/12), P(pass)=1/2; posterior (1/3,1/2,1/6). Для общего шанса нулевого бюджета s при таких априорах posterior B=1/(1+3s), A=2s/(1+3s), C=s/(1+3s); выбор действительно разворачивается от A к B при s<1/2.

**Конкретная проверка известности:** первичная работа [Mueser & Granberg, The Monty Hall Dilemma Revisited, May 1999, раздел The Host's Protocol and the General Solution](https://econwpa.ub.uni-muenchen.de/econ-wp/exp/papers/9906/9906001.html) уже вводит p_ij с j=0 для отказа ведущего открыть любую дверь и допускает неравные априоры. Наш протокол буквально задаёт столбец p_i0=(1/3,1,1/3), а единственный иной возможный столбец открытия B — (2/3,0,2/3). Никакого нового информационного канала относительно опубликованной схемы нет: ограничение бюджета реализует уже разрешённый state-dependent refusal.

Это сильнее голого «любой Байес известен»: в первичном источнике явно есть ровно канал «ведущий ничего не открывает» и его зависимость от положения приза. Точная бюджетная история может быть новой формулировкой, но механизм уже покрыт опубликованным расширением. **Голос К1: ПРОТИВ финального принятия как нового парадокса; подходит для холодной проверки понятности.**

**Холодный вопрос для Arena:** «Приз за A с вероятностью 1/2, за B,C по 1/4. Вы выбрали A; ведущий знает приз и обязан показать доступную чужую пустую дверь: с вероятностью 2/3 независимо от приза ему доступна только B, иначе ни одной, и доступность скрыта. Он не открыл ни одной двери, потому что не смог: какова вероятность приза за B?» Ключ: 1/2.

**Критический вопрос для Arena:** «Есть ли механистическая разница между бюджетным пасом и матрицей Mueser–Granberg p_i0=(1/3,1,1/3)? Покажите точное отображение; отличайте новый бытовой сюжет от нового протокола. Проверьте также необходимость априорного фаворита для утверждения именно ‘разворот выбора’, а не просто новая асимметрия».
