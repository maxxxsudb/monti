## 0. Главный дискриминант (по нему решаются почти все бытовые пункты)

Монти = раскрытие (а) **не может попасть в ваш выбор** И (б) **не может попасть в приз** (информированный ведущий или физический запрет). Тогда выбор раскрываемого зависит от положения приза → 2/3.
Авторское правило ИС («твой выбор защищён + один признак отбора» и «прошлое уже зафиксировано») — **необходимое, но не достаточное**. Если невыбранный вариант проверяется вслепую и проверка *могла* найти приз — это Monty Fall, ответ **1/2** (MC 0.4996). Все пункты ИС сводятся к 5 протоколам (`r0d_everyday.py`):

| Протокол | P(stay) точно | MC |
|---|---|---|
| (а) ведущий знает, обходит ваш выбор и приз | 1/3 | 0.3333 |
| (б) один из двух невыбранных проверен вслепую | 1/2 | 0.4996 |
| (б′) всегда проверяют конкретный №3 | 1/2 | 0.5010 |
| (в) проверили ОБА невыбранных, сообщили только об одном плохом | 1/3 | 0.3329 |
| (г) «одно из двух других плохое», какое — не названо | 1/3, переключаться некуда (0 бит) | 0.3333 |
| (д) первый выбор «самый вероятный» P=0.6, ведущий информирован | 0.6 (stay лучше!) | 0.6001 |
| (д′) то же, проверка вслепую | 0.75 | 0.7504 |

Замечание к (в): формально Монти, но реальный проверяющий, проверив оба, сказал бы всё (→ определённость). 2/3 держится только на **намеренном утаивании** — для «бытовых» сцен неправдоподобно.
Замечание к (д): в ИС первый выбор часто «самый вероятный на мой взгляд» (врач, жюри, пациент, машина). Тогда P(stay)=p, и при p>1/2 оставаться лучше даже при честном Монти.

## 4. Критерий сохранения массы — вердикт и следствия

1. Как равенство он **верен и тривиален**: это Байес, переписанный для двух групп. Нового содержания нет.
2. Утверждение «обменность достаточна» (СН) **неверно**. Нужна ещё target-preservation. Контрпример — Monty Fall. Обменность без неё даёт сдвиг массы *к* своей группе (1/3 → 1/2).
3. В среднем по наблюдениям масса группы **всегда** k/N (полная вероятность / мартингал). Поэтому любое «нарушение» на одних s компенсируется на других (в контрпримере СН: 1/2 с вер. 1/2, 0 иначе). Это ИЗВЕСТНО.
4. Единственное простое числовое следствие: **один выживший против всей своей группы**. Выживший тяжелее всей вашей группы ⇔ N−k > k·m. Пример: держите 3 двери из 10, ведущий открывает 5 из 7 чужих, остаются 2. Одна чужая дверь = 35% > ваши три вместе = 30% (MC 0.3495 / 0.3006). Это КАНДИДАТ, но слабый: ИЗВЕСТНО как «Монти с k выборами» (чёрный список: «n дверей»). Пр 4 / Кн 3.

## Топ-3 кандидата (из аудита + мои)

1. **«Надёжные бомбы» (Монти без ведущего)** — `r0d_reliable.py`, `r0d_timed.py`. Три ячейки, две бомбы. Ваша бомба (если вы на ней) заглушена амулетом. Каждая незаглушённая бомба за ночь взрывается сама с вероятностью p. Утром взорвалась только №3. Шанс, что пустая — №2: **1/(2−p)**, P(stay)=(1−p)/(2−p). При p=0.9 — **91%** (MC 0.910), при p=0.5 — ровно классические 2/3, при малом p — 50%. Без амулета ответ всегда 1/2 (MC 0.50). Механизм Монти есть: защита делает ваше «молчание» недиагностичным, а молчание №2 — диагностичным. Ведущего нет, физика сама обходит пустую клетку. Непрерывная версия: первый взрыв в момент t, P(stay)=S(t)/(1+S(t)) для **любого** распределения времени жизни. В медиане ровно 1/3, при t→0 — 1/2. Пр 4 / Кн 4. **Риск:** формула изоморфна Monty Crawl q/(1+q) при q=1−p. Отличие: в Crawl информацию несёт прихоть ведущего, здесь — несработавшая вторая «коза». Ещё риск «информативное молчание» из `астра.txt`.
2. **Амулет-неоднозначность / «защиты недостаточно»** (из ИС №6, №7, №29). Вы защищены, проверяется вслепую один из двух других, он пуст → 1/2, а не 2/3. Задача-ловушка для знающих Монти: большинство «грамотных» ответят 2/3. Пр 5 / Кн 3. **Риск:** ИЗВЕСТНО: Monty Fall (чёрный список).
3. **Один чужой выживший тяжелее всей вашей группы** (N−k>km; 3 из 10 против 1 из 2 выживших: 35% vs 30%). Пр 4 / Кн 3. **Риск:** «n дверей / несколько выборов».

## Штурм (без критики)

- **Надёжность против Монти:** чем надёжнее «козы» умеют себя раскрывать (p→1), тем сильнее переключение. Классический Монти — частный случай p=1/2. Вопрос для Arena: «бомбы срабатывают в 90% случаев» — ответ 91%.
- **Тухлые яйца по запаху:** ваше яйцо в герметичном пакете (щит), из двух открытых одно завоняло, другое нет. Та же формула (1−p)/(2−p) — бытовая обёртка кандидата 1.
- **Поздний первый взрыв:** «первая бомба рванула позже медианы — бегите; раньше медианы — почти монетка». Медиана как точка, где Монти «ровно классический».
- **Частичный амулет (β) + время:** при частичной защите ваше собственное молчание тоже становится уликой. Есть ли β, при котором поздний взрыв советует *оставаться*? Проверить знак d/dt.
- **Два игрока с амулетами** (N=4, у каждого свой щит, взорвалась одна чужая): каждый сохраняет 1/4. Выживший = 1/2. При «надёжных бомбах» что будет с вероятностью, что пусто у соседа-игрока?
