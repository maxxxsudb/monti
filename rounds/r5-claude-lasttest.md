# Раунд 5 (Claude, модератор-предлагающий): K-5. «Последний экзамен бесполезен»

Происхождение: исправленная «Шпаргалка» из аудита A (помощь = щит, P=1/(2−f)) → замечание «помощь не меняет точность найма» → обобщение.

### K-5. Последний экзамен
Условие: Из трёх кандидатов ровно один эксперт. Эксперт тест всегда проходит, неэксперт — с вероятностью 1/2. Вы нанимаете самого вероятного эксперта по итогам тестов.
Вопрос: на сколько процентных пунктов тестирование всех троих лучше, чем тестирование только двоих?
Интуитивный ответ: «несколько пунктов» (тест шумный, третий результат должен помогать).  Верный ответ: **0** (обе стратегии дают 7/12).
Механизм Монти: непроверенный кандидат = защищённая дверь (фильтр его не трогает). Защита одного объекта ничего не стоит; цена появляется только при защите второго.
Отличие от известных: при идеальном тесте (f=1) «последнего можно не проверять» — тривиальное исключение; здесь тест шумный, апостериорные вероятности при 2 и 3 тестах РАЗНЫЕ, а точность — та же.
Проверка: sims/r5_last_test.py — точный перебор (Fraction) + Монте-Карло 4·10^5, N=2..5, разные f: совпадает.

### Общая формула
N кандидатов, один эксперт, неэксперт проходит с вероятностью 1−f, проверено k:
  P(верный найм) = (1/N)·(1 + f + … + f^min(k, N−1)).
Каждый тест добавляет f^k/N, **последний — ровно 0**.
Эквивалент: одному кандидату можно тайно дать шпаргалку (гарантированный зачёт) без потери точности; помощь второму стоит f^(N−1)/N.

### Доказательство в одну строку
Стратегия «проверять в случайном порядке и нанять первого прошедшего» даёт (1/N)Σ_j f^(j−1) (эксперт на месте j, все до него провалились) — это совпадает с оптимумом Байеса при k ≥ N−1, а последнего кандидата эта стратегия не тестирует никогда (если N−1 провалились, его берут без теста).
Алгебраически: A=(1−f^(N−1))/(1−f); точность при N−1 тестах = (A + f^(N−1))/N, при N тестах = (fA + 1)/N; разность = A(1−f) + f^(N−1) − 1 = 0.

| Модель | точность при k=0..N | вклад последнего теста |
|---|---|---|
| 1 эксперт, a=1, b=1/2, N=3 | .3333 .5000 .5833 .5833 | 0 |
| двусторонняя ошибка a=0.9, b=0.5 | .3333 .4667 .5333 .5333 | 0 |
| a=0.99, b=0.5 | .3333 .4967 .5783 .5783 | 0 |
| 2 эксперта из 4, a=1, b=1/2 | .5000 .6667 .7083 .7083 .7083 | 0 (и предпоследний тоже!) |
| 1 эксперт N=4, a=1, b=1/3 | .2500 .4167 .5278 .6019 .6019 | 0 |

**Теорема (1 эксперт, любой тест с a ≥ b):** результат последнего теста никогда не меняет Байес-оптимальный выбор ⇒ ценность последнего теста = 0.
Доказательство: точность = Σ_o max_i P(i, o). Если среди N−1 есть прошедший j — при любом исходе последнего j остаётся максимизатором (прошедшие равны). Если прошедших нет — при «прошёл» лучший последний, при «провалил» все равны и последний тоже максимизатор. Один и тот же argmax при обоих исходах ⇒ Σ_r max = max Σ_r ⇒ нулевая ценность.
Это частный случай принципа «информация ценна, только если может изменить решение» (VOI) — критикам: оценить, делает ли это результат ИЗВЕСТНЫМ.

## Простая формулировка-кандидат (дверная, для опроса людей)
За одной из трёх дверей машина. Детектор над дверью с машиной пищит всегда, над пустой — с вероятностью 1/2. Можно просканировать две двери или все три, потом выбрать одну.
Насколько третье сканирование повышает шанс выиграть? **Ответ: 0** (7/12 в обоих случаях). Детектор, который иногда ошибается и на машине, — всё равно 0.
