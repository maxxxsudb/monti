# Раунд 5 — П2: проверка и формулировка K-5 «Монти-монетка»

Скрипт: `sims/r5_p2_coin_monty.py` (точный перебор Fraction по машине × подмножествам открытых коз, N=2..8; замкнутая формула для любого N, сверена с перебором; MC 2·10^5).

## 1. Проверка — ВСЁ ПОДТВЕРЖДЕНО
| N=3 | A (ваша дверь доступна) | Б (защищена) | (1+q+q²)/3 | MC A / Б |
|---|---|---|---|---|
| q=1/2 | 7/12 | 7/12 | 7/12 | .5835 / .5826 |
| q=1/3 | 13/27 | 13/27 | 13/27 | .4814 / .4806 |
| q=9/10 | 271/300 | 271/300 | 271/300 | .9039 / .9034 |
| право уйти (+1/−2/0), q=1/2 | **1/4** | **1/12** | — | .2494 / .0830 |

Обобщение (точно, проверено N≤8 перебором):
- Вынужденный выбор: A = Б = (1−q^N)/(N(1−q)) **при любом N и q** — защита стоит 0 и при 100 дверях (q=1/2: 0.0200 = 0.0200).
- С правом уйти: A = q^(N−1), Б = q^(N−1)/N (+ слагаемое при q>1/2). **При q ≤ 1/2 доступ к вашей двери умножает выигрыш ровно в N раз** (N=3: ×3, N=10: ×10). Но абсолютные значения быстро исчезают (N=10: 0.002 vs 0.0002) — для удивления большое N не помогает, N=3 лучше.
- Почему 0 (одна строка для школьника): в A все закрытые двери «одинаково выжили» (машина выживает всегда, коза — с вер. 1−q) — у вашей нет особого статуса; в Б ваша дверь «не проходила проверку», её шанс между выжившими и открытыми, и она никогда не лучшая (если есть другая закрытая) — выбор тот же, выигрыш тот же.

## 2. Предложение финальной формулировки (П2)
**Основная (ответ — одно число, 0):**
> За одной из трёх дверей машина. Ведущий знает где и над каждой дверью с козой — **включая вашу** — бросает монетку и открывает её при «орле»; машину он не открывает никогда, после чего вы выбираете любую закрытую дверь. На сколько процентных пунктов упадёт ваш шанс, если запретить ему трогать вашу дверь?

Ответ: **0** (7/12 и там, и там). Почему вопрос так: он задаёт людям «естественную» опору — «ведущий открывает больше дверей → больше информации → запрет вредит» (или наоборот, из классики: «защита моей двери — то, что даёт 2/3»). Обе интуиции дают ненулевой ответ. Вопрос «сколько стоит запрет» лучше, чем «каков шанс» (7/12 — не удивляет само по себе).

**Эпилог (опционально, второй вопрос):** «А если можно уйти, не открывая (машина +1, коза −2)?» — тот же запрет **уменьшает выигрыш втрое** (1/4 → 1/12). Как отдельный вопрос с одним числом: «во сколько раз?» → 3. Я бы давал как продолжение, а не как основной парадокс: усиливает, но удваивает длину.

Что НЕ советую: N=100 (ноль тот же, но звучит как «очевидно, одна дверь из 100 ничего не значит» — удивление слабее); формулировку через тесты/кандидатов (теряет Монти-узнаваемость).

Для опроса (c): задать основную формулировку 5–10 людям без подсказки; варианты ответа свободные; удачей считать ≥60% ненулевых ответов.

## 3. Критерии
- (a) Монти — **да, с оговоркой**: знающий ведущий (машину не открывает — без знания была бы иная задача), раскрытие = выживание через информированный фильтр. Оговорка К1 справедлива: нет «выбора, какую дверь открыть», фильтр независимый.
- (b) Простота — **да**: 3 предложения, ответ 0; 7/12 на салфетке.
- (c) Контринтуитивность — **не проверено, нужен опрос людей.**
- (d) Верность — **да**: перебор = формула = MC (независимо от П1 и Arena).
- (e) Новизна — **частично**: механизм VOI=0 известен; конкретная задача не найдена (Arena, П1, К1). Риск остаётся.

**Голос П2: ЗА** — числа верны независимо, формулировка в 3 предложения с ответом «0» и контрастом с классикой; эпилог ×3 даёт остроту; (c) решит опрос.
