# Раунд 6 — К1: физическая модель сжатия вероятностной массы

## Вердикт по трём секциям шара

Схема корректно иллюстрирует **сохранение и концентрацию массы двух групп**, если буквально обеспечить такие условия:

- Изначально в A,B,C находится одинаковое **количество газа** — по 1/3 общего количества. Одного равенства видимых объёмов недостаточно без одинаковых давлений и температур.
- A герметично отделена от обеих других секций. Тогда количество газа в A остаётся 1/3. Фиксатор, который только ограничивает её размер или форму, этого не обеспечивает: газ может утекать через остающийся канал.
- B,C образуют собственный герметичный контур; A к нему не подключена. Количество газа в этом контуре остаётся 2/3.
- C полностью сплющивают, оставляя её газу путь в B; передавливание не должно перекрыть этот путь раньше вытеснения газа. В пределе остаточного объёма C→0 газ контура оказывается в B.

Тогда **количество газа** A:B действительно 1:2. Но видимая «надутость» A:B не обязана быть 1:2. Гибкая оболочка, её натяжение, температура и давление могут различаться; реальный фиксатор может ограничивать объём, не сохранять количество вещества. Если сообщаются все три секции, зажим C распределит газ также в A — выбранная группа перестанет сохранять массу.

### Что именно нельзя отождествлять

| Физическое свойство | Соответствие |
|---|---|
| Количество вещества / масса газа | Может изображать вероятностную массу |
| Объём газа | Изображает массу только при одинаковой фиксированной плотности |
| Давление | Не вероятность; оно может выравниваться при разных количествах газа |
| Высота/толщина/надутость секции | Не надёжная шкала вероятности без калибровки |
| Герметическая граница A | Сохраняет массу выбранной группы в модели |
| Выдавливание C в B | Реальное перемещение вещества; в обычном Монти приз не перемещается |

Сжимаемость газа не разрушает сохранение массы, но разрушает автоматическое чтение **объёма как массы**. Выражение «зажим закрепляет вероятность 1/3» также слишком сильное: в настоящей задаче Монти неизменность вероятности группы следует из протокола раскрытия и симметрии, а не из одного запрета трогать выбранный объект. При другом отборе одного такого запрета недостаточно.

## Лучше: несжимаемая жидкость в цилиндрах

Три одинаковых вертикальных цилиндра A,B,C с одинаковым сечением и подвижными поршнями содержат по 100 мл одной жидкости. A изолируют двумя закрытыми кранами, B и C соединяют отдельной трубкой; поршень C опускают до дна, а B может принять весь вытесненный объём. После этого A содержит **100 мл**, B — **200 мл**, C — **0 мл**: вероятность изображают долей общего объёма, а высота столба в одинаковых цилиндрах даёт наглядную шкалу.

Это существенно честнее обычного воздушного шара: жидкость почти несжимаема, одна плотность позволяет читать объём как массу, отдельные контуры физически обеспечивают инвариант 1/3 и 2/3. Идеализация предполагает отсутствие утечек и пренебрежимо малый остаточный объём трубок; физическая сила на поршне и давление не входят в шкалу вероятности.

**Простое соответствие:** «100 мл выбранного варианта заперты отдельно; 200 мл двух остальных остаются в своём контуре. Когда один из этих вариантов исключён допустимым фильтром, весь их вес приходится на оставшийся».

Ограничение той же схемы: физически можно так же вытеснить жидкость при произвольном исключении C. Это покажет 1:2 даже там, где правильный Байес даёт 1:1. Следовательно, это **визуализация уже обоснованного перераспределения веса**, а не устройство, которое само доказывает нужный протокол Монти.

## Самая точная наглядная модель: три равных груза сценариев

Если нужно показать не только геометрию массы, но и почему информация меняет решение без перемещения приза, лучше три одинаковых шарика/груза. Каждый представляет **целый исходный сценарий**, а не содержимое одной конкретной двери:

1. Приз исходно за выбранной A: стратегия stay выигрывает.
2. Приз исходно за B: информированный ведущий убирает C; стратегия switch выигрывает.
3. Приз исходно за C: ведущий убирает B; стратегия switch выигрывает.

Грузы не сливаются и не теряют веса: один кладётся на чашу stay, два — на чашу switch. Поэтому веса стратегий 1:2. После реального раскрытия ни машина, ни исходный сценарий не перемещаются; меняется известное игроку соответствие между оставшейся чужой дверью и выигрышной стратегией.

Это точное соответствие для **безусловного успеха стратегии** при guaranteed-goat протоколе. Для posterior после конкретно названной двери нужно дополнительно учесть правило выбора козы. При симметричном выборе и сообщении «открыта C» сценарий A даёт это сообщение с вероятностью 1/2, сценарий B — с вероятностью 1, сценарий C — с вероятностью 0. Поэтому для названного сообщения грузы правдоподобия должны быть **половина, один, ноль**, после нормировки опять 1/3 и 2/3. При предпочтении ведущего веса будут другими.

## Короткий вывод для применения

Для образа **«защищённая масса + сжатие чужого пространства»** подходят жидкостные цилиндры; газовый шар требует уточнения, что сохраняется количество газа, а не надутость. Для объяснения **«почему раскрытие даёт информацию и при этом не переносит приз»** точнее равные грузы сценариев. Эти две модели показывают разные стороны задачи; один механический зажим не заменяет информированный фильтр.
